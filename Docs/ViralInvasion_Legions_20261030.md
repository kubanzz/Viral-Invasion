# 免疫军团与治疗点争夺 · 2026-10-30

本轮把临时召唤改为可积累、可损失的军团，配合病毒争夺治疗点与有限抗体爆发，形成“部署—驻守—抢救—反攻”的循环。已接入工作区源码与离线构建，双击 `Start-Game.cmd` 游玩。

## 当前规则

| 系统 | 实施数值与操作 |
|---|---|
| 军团部署 | Q 部署，整局最多两支；满两支或部署冷却中，Q 指挥准星附近的现有军团。保留真实移动、绕障及接触攻击。 |
| 成员成长 | 基础侦巡每团 1 体；免疫灯塔Ⅰ/Ⅱ/Ⅲ阶每团 3/4/5 体。连续挑战的免疫成长也能增员，普通编制最多 5 体。升级仅补入新增编制，不自动补满阵亡成员。 |
| 常驻与生命 | 成员不会因时间、清波或更换协议而消失；初始生命 60，灯塔升级后 72/84。升级按原生命比例提高上限，不洗掉已有伤势。全团阵亡后空出部署位；跨器官保留驻军与生命，两处共用两个军团位。 |
| 病毒威胁 | 基础移动速度 64→70；战役普通攻击对玩家伤害 7→8、对组织 4→4.5。保留前摇和躲避窗口，病毒可实际击杀免疫细胞；部分普通病毒会争夺附近治疗点。连续挑战沿用已有随波伤害曲线。 |
| 新治疗点 | 正式心脏、肺部各新增两处，保留中心组织抢修。病毒在 145 范围内感染，单体持续 12 秒占领，多体最多 2.5 倍速度。部分感染在敌人离开后缓退，完全占领后保持感染。小地图以绿/黄/红加号显示状态。 |
| 快速抢救 | 距治疗点 150 内，工具 3 点击：立刻清除未满的感染，恢复玩家 25 耐久；每处冷却 4 秒。治疗遵循连续挑战的真实最大生命。 |
| 感染后夺回 | 完全占领后，同样的治疗操作额外消耗 2 份研究样本，再净化并回血；样本不足或未满足距离/冷却时明确提示且不扣样本。 |
| 注射抗体 | 每局 2 支，按 R 或点击“注射抗体”。所有存活成员各裂变一次，母体和子体均保留注射前当前生命的 2/3；子体继续常驻。8 秒内移速 ×1.4、攻击 ×1.5，附近病毒优先攻击军团。强化期间不能重复注射；无军团时不消耗。 |
| 第二支抗体 | 前次强化结束后可再次裂变。两支抗体使普通 5 体军团最多达到 20 体；仍然只有两个部署位。扣血代价与优先受击使爆发时机需要选择。 |

病毒已经开始的攻击仍按原来锁定的位置结算，注射不会把已经落下的攻击转移走。普通敌人、精英及其范围/冲锋攻击会依据实际接触、危险几何和视线伤害军团；固定母巢阶段及飞行病毒载荷继续执行自身机制。

## 体验目标

开局先部署一团保护常走路线，再根据敌群与治疗点位置选择第二团。看到治疗点感染进度上涨时，可以先抢救，避免之后付出研究样本。敌群逼近时用抗体换取火力和牵制窗口，同时利用移位或冲刺减少军团损失。清波保留驻军，下一波继续积累；损失也会延续。

军团显示真实生命条，抗体强化显示金色外圈和剩余时间；HUD 显示两军团容量、现存成员及抗体次数。治疗点显示感染进度、可用状态和夺回代价，操作手册与成长卡同步更新。
