## 实现边界

`GameSession(seed, { campaign: true, firstTrait })` 在现有固定步长会话中接入 `BattleDirector`；移动、碰撞、扫描、射线、三工具及暂停生命周期继续共用。正式入口为心脏切片，显式训练参数仅供 G0 回归。

- `src/game/battle.ts`：六节点有向传播、可切换隔离闸、源生产/清除、AI 与攻击前摇、两次有预警变异、压力及心跳冲流。
- `src/game/battleConfig.ts`：24 活跃单位上限、6 秒传播间隔、8 秒变异预警、三分支能力/代价/反制及脉冲参数。
- `src/game/battleTypes.ts`、`types.ts`：实体、网络、压力、阶段、提示历史及效果状态。
- `src/render/battleVisuals.ts`、`renderer.ts`：三种轮廓、晶壳缺口、裂殖落点预告、潜伏扰动、危险与流向绘制。
- `src/ui/battleHud.ts`、`main.ts`：感染/稳定/组织独立指标、能力/代价/反制、目标、心跳充能及可回看的战术记录。

G1 胜利明确为“心脏切片复测”：清除两源及两名变异精英、组织 ≥50、感染 <35，再主动靠近复测台按 E。它不代表 G3 的双器官、融合母巢和 10–15 分钟完整局已经完成。
