# 工作区素材更新与动作缺口

素材权威目录是本项目的 `asserts/`，`art-selection.json` 是游戏实际选材清单。开发启动与构建前会读取本目录生成 `.art-generated/`；不会自动读取旧机器目录，也不会以 `VI_ART_SOURCE` 环境变量覆盖本地文件。原始素材和已有选材应保留，新素材使用新文件名。

更新素材后运行 `npm run art:sync`，查看 `.art-generated/art-sync-report.json` 的 `unknownCandidates`（未登记候选）和 `pending`（选中但仍有待办的素材）。新文件不会仅因出现而自动成为游戏素材；需核对透明边、尺寸、锚点、朝向和游戏内效果，再由选材清单显式绑定。已绑定文件如果直接替换，同步会重建对应图集；带 `expectedSha256` 的绑定会拒绝未经审核的替换。建议用新文件名提交候选，避免覆盖原图。运行中的开发服务在同步后刷新，离线发行包需要重新构建。`node scripts/art-sync.mjs --check` 只核对生成物是否与当前输入一致。
