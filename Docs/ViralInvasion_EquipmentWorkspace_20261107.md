# 装备仓库与锻造台 · 2026-11-07

装备整备采用暖色生物幻想界面，统一为左侧型号或实例列表、右侧单件详情和固定操作区。手机横屏优先，桌面沿用相同信息结构。

## 页面与操作

| 页面 | 功能 | 默认行为 |
| --- | --- | --- |
| 装备仓库 | 武器、模组、整理 | 武器页选中当前装备；选择另一把后点击装备，已装备武器的主操作为试用 |
| 锻造台 | 修复强化、定向打造 | 优先待修复武器；无待修复且有可打造配方时定位配方，否则显示当前武器强化 |

- 普攻、三个战技、大招、完整数值与获取说明只在选中装备的二级详情显示。
- 模组页呈现三个槽位与选中模组的实际效果，沿用同型号最高品质生效的规则。
- 整理按实际库存实例分解，先显示回收收益与保护原因。同型号副本标注“配装使用此型号”，不会全部称为已装备。
- 修复显示品质变化、保留强化与伤害变化；同时可修复和强化时才显示操作切换。
- 定向打造每次显示一个配方。首次选择型号时采用最高可负担品质，全部不足时选择最低允许品质；手动品质选择按型号记忆。
- 不足材料直接显示缺口；修复、强化、打造和分解在原位置反馈结果并更新资源。
- 右上角关闭返回营地；二级详情可返回概览。Escape 先退出二级详情或试用，再关闭页面；页签支持方向键与 Home/End，Tab 焦点保留在当前面板内。

## 实现与兼容

- `campEquipmentHud.ts` 负责两页的单件展示；`campEquipmentState.ts` 负责纯展示状态与默认选择；`campEquipment.css` 的样式只作用于装备页面。
- `CampPresentation.equipment` 接入当前页签、目标、配方品质与详情状态。仓库和锻造分别记忆选中项与滚动位置，试用往返恢复，本次营地访问结束后重置。
- `campDecomposeEligibility` 同时用于界面与存储层，保持原来的分解保护、错误码及资源收益。
- 装备经济、强化上限、传说首抽解锁、存档格式、建筑靠近交互以及其他营地页面沿用现有规则。
- 常态移除重复的底部返回栏；保存异常时保留提示和“重试保存”。按钮至少 44×44px，辅助文字至少 12px。
