# 微区攻防 · v0.25.0

## 目标与本版范围

修复自主验收发现的单源计数、Boss阶段读数、固定出生等待与旧发布包问题，并落实清源后仍需拦截、净化、保护稳态锚的有限攻防。

感染源摧毁后不会复活，源头附加增援仍会停止。后续携疫队来自任务原有基础敌群预算，不提高基础敌人总量，也不无限补生。Boss附近现有节点距离较远，本版不增加要求横穿地图的Boss感染事件。

## 有限携疫队

- 正式任务第2波起，每波将4个原有普通敌人名额替换为1支队伍：1名携疫者和3名护卫。
- 首关仅沿北线推进；其余任务按波次交替北南。携疫队与源头附加队分开记账，毁源只取消尚未出生的源头附加队。
- 队伍仍有真实来袭预警、行军、占点和伤害，携疫者有标记，可途中拦截。清源后依然可能先后侵染前线、营养凝露，并继续向稳态锚推进。
- 保留人口、位置和同线路队伍约束；预警不会因为加速投放而被跳过。携疫者死亡不会另加补充预算。
- 波次结束仍需清理实际残敌。母巢决战不创建新的普通波次携疫队，最后净化阶段不继续制造新队伍。

## 净化与保护

- 正式任务中实际完成一次节点净化后，获得15秒感染保护。保护按模拟时间计算，暂停冻结，返回游戏后继续。
- 保护期间专职侵染者与普通病毒不能累积该节点感染，界面不显示虚假的失守倒计时；活敌仍可移动、攻击和被击杀。
- 保护到期后恢复正常感染规则，不把节点永久化。感染源的永久摧毁规则保持。
- 仍使用3秒净化、150交互范围、伤害打断和进度保留；健康凝露的治疗收益与Q驻防继续有效。

## 进度与投放

- 第一关只计有效西源，未击破时为0/1；另外两关为0/2，不把未参与任务的东源当作玩家战果。
- 清剿阶段显示真实总波数与本波剩余；母巢阶段显示决战与真实血条阶段；最后净化显示残敌和待收复节点，避免母巢仍活着却显示“余敌0”。
- 阶段路径与单个当前行动目标保持同步，桌面和手机消费同一份数据。
- 正式任务清空移动敌群时允许提前迎来下一批，已有敌群存在时沿用正常节奏。提前投放不跳过名额，不突破人口上限，不取消携疫队与分裂的真实预警。

## Boss大招

母巢实际损失最大总血量的1%，增加2点大招能量，满100可释放。计算真实扣除的HP，护膜、阶段封顶挡掉的伤害不计。大招及其后代伤害不回充，母巢尾刀不叠加结构击杀奖励。玩家、普通技能与真实军团伤害共享贡献。

桌面与手机均使用0.25.0版。历史0.24.0包保留；README当前入口改为0.25.0，固定手机HTML/ZIP同步本版。发布前检查源清单、输出hash及ZIP解码后的逐字节一致性，并验证断网冷启动。

规则回归、有限预算与实际阶段转换、三尺寸HUD/角色标记、离线包验证登记在 `artifacts/battle-pacing-v025/`。自动模拟与供态画面不等于真人趣味性或实体iPhone验收；本版不宣称已完成实体手机测试。

最终验证：完整规则集覆盖2604项；首次14项失败经特效测试host/资源断言同步和长模拟单独复查后全部恢复，无遗留失败。两项长模拟使用`VI_SLOW_SIM_TESTS=1`增加墙钟执行时限，原有模拟步数、12波重放及所有断言保持。类型检查通过；实际渲染三尺寸18场景通过，手机提示卡高约84像素，读数与教学通知保留4像素间隔，携疫标记移到脚下以避免顶栏遮挡。

有限队列的即时清空探针由约102/170/253秒降到39/66/96秒，基础240/400/600个名额保持；此探针用于测量调度下限，不能当作真人通关时间。白枪实际输入首关仍成功。独立组合探针确认毁源后携疫者真实占点、移动/F净化获得15秒保护、暂停冻结、到期恢复感染、清完有限敌群成功。

桌面ZIP独立解码后与dist逐字节匹配；版本化与固定手机入口内容一致，3个ZIP均完成校验。Chrome/Edge分别在1366×768、844×390、667×320断网冷启动、三维加载与实际移动共6例通过，0页面错误、0外网请求。本次发布保留可构建的旧开场，尚在制作的新影片已由开场聊天隔离，不阻塞关卡包。
