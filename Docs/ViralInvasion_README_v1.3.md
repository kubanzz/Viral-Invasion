## 本次新增的正式决策

- **游戏视角**：3/4 斜俯视伪 2.5D，不是纯 90° 顶视、横版跳台或真 3D。
- **玩法空间**：游戏碰撞/AI/战斗都保持二维 XY；WASD 八向自由移动 + 鼠标 360° 瞄准，不引入跳跃和重力。
- **美术方向**：手绘 2D 生物幻想为主，病毒童话化、可爱但危险；克制使用霓虹生物朋克高光。器官空间纵深、剪影可读性优先于堆砌特效。
- **新项目独立性**：不读取、复制或修改旧心脏巡游仓库；用户提供的参考截图不得擅自当作项目贴图。
- **规则不推翻**：病毒双向进化、抗体研究、心肺差异、跨器官追击与 10–15 分钟单局仍是玩法基线。

## 使用方法

1. 新建与旧工程无关的 `Viral-Invasion/` 工作目录，并把全部 6 份 Markdown 放进 `Docs/`。
2. 在这个**新目录**启动 Codex，发送 `ViralInvasion_Codex_StartHere_v1.3.md` 的正文。
3. 第一轮只做 **G0：实际可玩训练场 + 3/4 低保真视觉基线 + 双向坐标一致性 + 可离线打包**；这一轮不要求制作完整精细场景。
4. G0 验收时先确认 `VIS-01`–`VIS-04` 和 `AC-M02-05`、`AC-M02-06`；视角走偏应该立刻纠正，不要等全部功能开发后再重画。
5. 之后依次推进 G1 → G4。每次都在追踪矩阵中填写真实脚本/截图/视频/试玩证据，不能提前标注“通过”。

## 目标工程栈和美术管线

- **目标工程栈：TypeScript + Phaser 开源框架**；美术及逐帧动画采用 **Krita**。本地开发继续使用 Vite、Vitest、Playwright；esbuild classic/IIFE 发行必须实际用 Chrome/Edge `file://` 断网验证。
- **当前与目标分开记录**：当前源码仍为原生 Canvas 实现，Phaser 迁移待实施。先通过最小离线兼容原型，再增量替换表现层，保留确定性玩法模拟、碰撞规则和 DOM HUD。
- Phaser 承担资源加载、精灵图集动画、相机和表现特效；使用开源框架能力，不要求购买商业编辑器或 Spine 授权。Krita 承担分层修图、连续帧制作和 PNG 序列导出。
- **素材根目录沿用 `asserts/`**，保留 `.kra`、透明 PNG、帧序列及图集描述。流程为“统一设定 → 关键姿态 → 连续帧修整 → 图集 → 游戏内验证”；锚点、时序、分层和验收详见[美术规范 §7](ViralInvasion_ArtDirection_VisualAcceptance_v1.3.md#7-资产制作与-phaser--krita-管线)。
- 渲染：远景组织 → 地形 → 角色接地阴影 → Y 排序实体 → 前景遮挡 → 战斗特效 → HUD。
- 资产：G0 程序化 3/4 造型与有机路径，G1–G2 再补手绘风格生物纹理与感染体形态，G3 补肺部气泡/膜/气流，G4 打磨可读性与性能。
- 无需 3D 引擎或云服务；发行包含所有本地资源。
