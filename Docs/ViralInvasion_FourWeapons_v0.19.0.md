# 四武器与击杀大招 v0.19.0

2026-11-06。现有蜂巢针枪、回旋刃弓强化123，新增传说枪「霆链·裁决铳」和近战刀「赤曜·斩疫刃」。每把武器均有独立普攻、123战技与4大招。

## 操作与充能

- 桌面按4沿鼠标方向释放大招；手机右侧独立4按钮显示能量，指向型大招支持拖动预览、松手释放及拖出取消。移动、普攻和大招瞄准独立。
- 100能量可释放：普通病毒+2，裂殖子体+1，精英+12，感染源/巢穴/母巢+20。玩家、军团和协议的真实击杀均有效；训练靶、事件目标和弹体无效。
- 每个身体只记一次，大招及派生伤害不回充。跨波保留能量，返营/重开清零。失败受理不扣能量，暂停冻结模拟与特效。
- F净化、Q驻军、R抗体、E弹射、Space冲刺保持各自职责。安全试武器支持普攻、123、4、充满能量和近身群靶。
