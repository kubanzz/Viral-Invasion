# v0.14.0 心脏攻防：脚下驻军、玩家弹射与智能病毒

本轮延续2400×1500七区双线和实际军团接防。玩法改动只作用于心脏挑战；共用射击表现与角色反馈服务其他场景。原批准图、既有冻结美术和v0.13发布归档保留。没有提交或推送要求。

## 操作与规则

- **Q／手机驻军**：即时在脚下部署，不依赖瞄准。150内自动绑定最近健康节点，否则留守原地；满两支后改派最近军团，现有细胞真实行军，不恢复人数、耐久或攻击冷却。离岗立即影响对应源护膜。
- **免疫弹射炮**：固定在(1070,720)，110内按住E或手机按钮拖动选落点，松开把玩家射出；取消不消耗装填。1100射程、0.75秒飞行、落地240半径260伤害、24秒装填，玩家留在落点。合法落点最多吸附60，不能落入障碍。飞行不接受地面操作或地面攻击，已有感染继续扣血；不伤友军、主源和最终母巢，也不直接净化区域。
- **接触感染**：地面真实碰撞及冲刺扫掠触发8秒感染、每秒1耐久。接触不附加瞬伤，刷新不叠层、不推迟掉血节拍。健康生命泉150内每秒回3，连续1秒没有新的传染接触或攻击才清除感染。
- **生命泉污染**：普通病毒身体接触36半径泉实体，每只每秒2.5个百分点，最多计3只；与侵染者每秒10取较大值。无人污染时每秒回退10。泉边污染者会暂停泉净化；前线仍由专职侵染者占领。约三分之一普通出生单位在所属前线失守后主动抢泉。

## 智能敌人及有限预算

黏液法师68耐久、移动60，保持300—400距离，450内锁定落点；0.9秒前摇、0.45秒飞行、每5秒投掷。75半径黏液持续3秒，普通移动×0.72，无额外伤害或定身；全场最多2片，包含前摇预约。离开、冲刺或弹射可脱离。

筑巢者136耐久、移动60、建造3秒，一生一巢；只在真实感染且可达的位置施工。小母巢170耐久，每4秒孵2只，共6只；库存及倒计时可见。幼体24耐久、移动180，攻击前摇0.45秒、间隔1.5秒、伤害4，优先追玩家，不裂殖、不筑巢。

第2波一名法师，第3波一个筑巢包，第4波起最多两名法师及一包。均替换原普通名额，与交接四人小队独立。一个筑巢包为1筑巢者+1巢+6幼体。建筑和孵化预约、裂殖预约与活体统一纳入48人口；孵化转换预约，不重复加人口。击杀父体或拆源幂等取消未出生库存，已出生敌人不消失；巢与幼体阻挡清波，黏液不阻挡。继续守卫使用边缘有限增援。

普通射弹使用短双色胶囊，能量弹使用圆润实心弹体；军团使用局部咬击，取消追踪长连线。治疗显示范围高亮、局部微粒、真实合并回血数字和解除感染扩散环，低特效仍保留状态。弹射只绘制一个抬升的玩家及随动武器、地面影和真实落点。
