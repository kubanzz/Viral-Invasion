# v0.15.4 · 净化断供与源膜简化

2026-11-05。玩家已净化前线并部署军团，仍会因为军团等级、下一队出生时机、侵染者是否被指定军团命中而无法解除源膜。玩家快速清怪反而可能失去接防资格，本轮取消这组门槛。

## 当前规则

- 第3波双源苏醒。西源关联北侧生命泉、北线前沿；东源关联南侧生命泉、南线前沿。
- 同线生命泉与前线归属均为健康时，感染供能切断，源膜立即解除。无需军团等级、驻军人数、命中记录或等待反扑。
- 节点受到污染但尚未失守时不复膜；任一关联节点真正失守才恢复护膜。收复后重新解膜，感染源已有伤害始终保留。
- 军团仍开局可用。两线守点可固定升阶，军团帮助守住净化区域；改派或阵亡本身不恢复源膜。
- 母巢出场和救援结算均移除历史接防记录门槛。原有清波、残敌与预约裂殖、节点健康、最后净化和死亡优先规则继续生效。
- 历史状态中的接防字段保留读取兼容，不参与当前玩法判定；不再生成接防验证事件。

## 反馈

战况用“净化生命泉 → 净化前线 → 攻击感染源”代替五步接防。源头标记与攻击受阻提示直接指出尚未净化的节点；完成断供后提示护膜解除，节点失守时提示供能恢复。菜单、帮助、配装、升级提示、结果页和手机说明使用同一套规则。
