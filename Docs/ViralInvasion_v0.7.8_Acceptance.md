# v0.7.8：编队、可反制招式与持续联动技术候选

本轮继续落实用户提出的地图拥挤、进化无感、攻击单调和免疫辅助不明显，并遵循优先可玩性、持续成长、爽快感的授权。设计依据为 `DesignDoc_v1.3/ViralInvasion_GDD_v1.3.md` §1–2 双向进化与短循环、§4 可识别且可反制的病毒、§5 抗体联动、§6 器官规则、§9 人口预算。连续挑战按用户后续持续成长目标扩展，原器官战役保留。

## 当前可试玩结果

- 空间：沿用已扩大的 2400×1500 心脏与肺部、分区设施、跟随镜头和导航图。本轮让敌群形成正面双潮、交叉夹击、聚群猎场、侧翼点射四类实际编队，群体之间有接敌间隙；修复隔墙停步、肺南边界嵌入和冲锋结束后敌我重叠停机。普通波休整与预警合计 3 秒，新点射体与精英首次登场仍保留 8 秒预警。
- 成长：每波获得现有九类战斗强化，扇射、贯穿、裂解新星、冲刺斩、Q爆发和免疫军团会改变真实攻击。每 5 波另获免费协议重配，优先提供尚缺的联动伙伴。经验成长结束后仍可补齐显影围猎或共振连锁；三槽和Ⅲ阶上限保留，满阶后可作有代价的调校。所有选择暂停模拟，先处理协议再处理战斗强化；放弃协议不扣掉战斗成长。
- 免疫：预装灯塔可召集三体小队。小队存续且召集冷却中，再按 Q 可重定向集结区域；细胞从当前位置实际赶路，保留 ID、剩余寿命和咬击冷却，不额外消耗组织。与异常显影搭配后优先围猎标记体，伤害经公共受理路径结算。
- 战斗：第 3 波起加入有限点射支援；精英按性状使用锁向冲锋、双固定落点、组织腐蚀。射线横移躲开；冲锋让路后利用两秒恢复破绽；裂殖避开两个落点；Q 能打断正在引导的组织腐蚀。范围裂解实际击退也能中断。普通体保持 68 耐久，未为强迫受伤添加无敌、血量底线或按玩家输出缩放血量。
- 判定：预警提交后位置、瞄准、落点固定，暂停不推进。射线绘制和伤害共用裁剪端点；冲锋只在实际经过的身体线段造成一次伤害，不沿整条预警提前命中；并发前摇与冲锋合计最多 3 个，人口及裂殖预约合计最多 24。战术提示靠近预警路线，避免文字在拥挤时漂到顶部。
