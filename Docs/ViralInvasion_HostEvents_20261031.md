## 抽取、危机与清理

- 使用与敌群/成长独立的局内 seed 随机流。模拟时间 75/240/420/600 秒四槽，每槽最多选取一次，最多等待 60 秒，过期跳过。
- 首次成功事件限定绿色；之后先过滤依赖、器官、合法放置、重复卡与危机，再按绿 30/红 45/黄 25 的剩余类别权重抽取，类别内等权。红卡最多两次且不连续，同卡每局最多出现一次。
- 同时至多一个事件，结束后至少间隔 60 秒。绿色 2 秒预提示、红黄 8 秒预警。耐久低于 25%、感染大于 80 或完整度低于 25% 时不启动红黄；生效前再次检查。
- 进化、迁移警报和母巢唤醒演出期间不启动，清警报后完整缓冲 15 秒。预警事件遇警报取消该槽；生效红黄遇警报结束。生效绿色允许继续。
- 固定模拟步长驱动倒计时、翻牌、伤害与恢复；暂停无推进，无现实时间补发。侧栏没有按钮、没有键盘焦点，`pointer-events:none`。
- 临时修饰由事件来源登记，读取时计算，范围使用布尔命中避免重复相乘。军团进出减速圈或事件结束时恢复待发攻击的剩余冷却比例，删除倍率登记；冲流切换同样保留比例。
- 切器官、胜败、回菜单、重开清理实体、区域与来源；幂等重复结束。跨器官结束恢复原器官的冲流冷却。已发生的伤害、恢复、感染进度与源清除保留。
- 事件目标死亡不进入病毒击杀事件；药区击杀保留正常世界死亡处理（源停产、裂殖等），但通过 `suppressRewards` 抑制 XP/样本，跳过击杀连锁和命中协议。药区与事件目标命中不记为玩家的病毒适应行为。目标不占敌群人口配额或清波义务。

## 自检修复 · 2026-10-31

本次修复自检确认的三项问题，当前验收应优先读取本节；后面的首版报告保留历史归属。

- 药区新增 `pending / spawned / skipped` 生命周期。每轮预告开始至生成前逐帧校验既定锚点，失效只跳过该轮，记录 `HOST_EVENT_ZONE_SKIPPED` 与原因；不换位置、不补发、不额外消耗随机数。首轮失效不再取消整张卡，已生成药区完成原六秒结算。侧栏显示跳过数量和“血流路径失效”，跳过轮不绘制范围或标签。
- 扫描仍可显示污染源，但事件目标统一排除出 `SCAN_COMPLETED`、`BATTLE_DIAGNOSED` 的病毒计数与发现奖励证据。有实际上下文时只认当前合法生物目标，不能用旧的正数计数兜底领取奖励。只有污染源时 XP/样本为零，混合场景仅统计病毒；正常首次诊断仍为 6 XP/1 样本，每局一次。
- 宿主浏览器测试使用独立 worker 级 HTTP fixture，只监听 `127.0.0.1` 的系统分配端口；向用例注入入口，不再依赖固定 4173 或人工启动服务。只提供已构建的 `index.html / game.js / game.css`，缺少构建明确提示先执行 `npm run build`；测试结束或失败自动关闭服务及连接。其他 `file://` 测试和全局 Playwright 配置保持原运行方式。
