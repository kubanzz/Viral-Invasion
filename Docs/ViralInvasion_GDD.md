## 游戏品牌与正式命名

- **正式英文名**：**Viral Invasion**；中文名：**病毒入侵**。
- **类型/玩法描述**：病毒进化对抗、器官环境策略 Roguelite；“病毒进化对抗”不是游戏正式副标题。
- 主菜单、游戏介绍、结算及任何玩家可见品牌名称统一采用 **Viral Invasion**。
- 此次只变更品牌命名，不改变玩家与病毒双向进化、器官争夺、抗体研究和手绘 3/4 斜俯视设计。

## 0. 项目定位与必须尊重的边界

### 0.1 本项目为全新独立开发

- **在新建空目录 / 新 Git 仓库内从零实现**《Viral Invasion（病毒入侵）》。不基于原“心脏巡游”仓库开发，不要求复制任何旧代码、旧图片、旧配置或旧存档。
- 之前“心脏巡游”版本和 Codex 审查仅是设计思路参考：其核心观察是“治疗与防守存在时间取舍，但诊断和重复游玩深度不足”。旧版本的测试数量、入口路径、操作实现和运行结果**不属于本项目证据**。
- 不设“经典模式”，不需要模式切换、LegacyAdapter、旧工程回归或已有代码接口适配。首个可玩版本直接进入本作的感染对抗模式。
- **不默认用户持有旧资源或有访问旧仓库的权限**。若以后要移植旧素材，单独经用户同意并核对资源许可，不纳入当前 MVP。

### 0.2 产品决策（必须实现）

1. 核心体验是 **玩家与病毒双向进化**；不是“固定关卡 + 随机敌人血量”。
2. 病毒变化具有前兆、弱点、代价；玩家研究抗体取得反制手段；器官特性改变实际战术。
3. 单局追求 10–15 分钟完整胜败循环，结束后能立即开始下一局；后续可有无尽模式，但 MVP 不制作。
4. 最初只做 **心脏一个主战场 + 一个低成本肺部战场**。大脑/肝脏是后续扩展，不作为 MVP 门槛。
5. 先形成有趣的“3 分钟核心小循环”，再做 12 分钟完整局，再考虑局外内容。不得用评级/任务/图鉴替代核心乐趣验证。
6. 桌面浏览器优先，使用新建的模块化 TypeScript + Canvas 2D 工程；开发期可使用本地构建工具，**发行包必须支持离线使用**，不得依赖外部服务。
7. 游戏生理规则为架空奇幻设定，不声称现实医疗准确性；不实现真实病原培育、基因工程或临床治疗建议。
8. **视觉规范已确定**：3/4 斜俯视、二维地面自由移动、手绘生物幻想腔体、童话病毒造型与克制的霓虹生物朋克高光。严禁误做成横版跳台、纯正俯视、菱形等距网格或真 3D。详见 `ViralInvasion_ArtDirection_VisualAcceptance_v1.3.md`。

### 0.3 从零开发的首个可玩切片

在实现真正的病毒进化前，先做一个能启动、移动、射击/净化、扫描、修复组织、暂停与重试的**单屏心脏训练场**。训练场目标为“净化靶标→修复组织→E 复测”，提供最小胜利反馈。该切片仅用于验证操作手感和新工程基础；它不是旧心脏巡游的复刻，也不能视为正式 G1 玩法通过。**G0 同时要确立正确的 3/4 斜俯视视觉/碰撞原型**：场景有远景、地形与前景层次；角色/靶标按接地锚点 Y 排序；但 G0 不要求产出宣传级手绘贴图。

### 0.4 视角与美术选型为已确认决策（非待选方案）

- **观察方向**：玩家从斜上方俯瞰器官腔体，能看见角色头顶和正面/侧面；这是手绘伪 2.5D 的视觉语言，不是真正的三维摄影机。
- **移动与瞄准**：WASD 在同一二维世界平面上自由移动，鼠标支持 360° 瞄准；不加入跳跃、重力和上下平台切换。角色高度感由 3/4 精灵、阴影、背景透视、前后景遮挡模拟。
- **美术主线**：手绘器官幻想（有机纹理和强烈空间氛围）+ 童话化病毒（可爱但危险）+ 克制的霓虹生物朋克光效。优先级：战斗可读性与视觉风格同时满足；被大量粒子遮挡的精致画面属于失败设计。
- **不同器官**：心脏暖红/绯红/金色、搏动与血流；肺部青蓝/淡粉/珠光、肺泡与气流。不同的是环境造型和实际机制，不只是颜色滤镜。
- **权威详细规范**：请阅读 `ViralInvasion_ArtDirection_VisualAcceptance_v1.3.md`（镜头、Y 排序、遮挡、资产、HUD、12 项 VIS 验收）。聊天中提供的游戏截图仅作风格研究，不得直接作为项目资产。

## 1. 产品定位与设计支柱

### 1.1 一句话卖点

**在巨人的活体器官中作战；病毒会根据局势变异和跨器官逃逸，玩家通过扫描、战斗、抗体研究与操控器官节律反制，形成每局不同的连锁净化。**

### 1.2 三根设计支柱（所有新增功能都要服务其中至少一根）

| 支柱 | 必须提供的玩家体验 | 禁止的替代实现 |
|---|---|---|
| 双向进化对抗 | 玩家看见病毒发生策略变化，并有充分信息提出反制 | 仅提高敌人血量/攻击力；针对玩家构筑不可反制的硬克制 |
| 器官即武器 | 心跳、血流、肺部气流可被玩家主动利用，且影响病毒 | 只换背景图、颜色或地图贴图 |
| 连锁策略成长 | 2 个以上机制产生可感知的新效果，玩家能刻意复现 | 技能只有 +10% 伤害、+20% 治疗速度 |

### 1.3 目标用户与时长

- 核心体验：动作操作占 50% 左右，策略观察/构筑占 30%，探索与诊断占 20%；为暂定设计取向，不做僵硬的逐秒配比。
- 入门一局目标 10–15 分钟；熟练后可更快，不为凑时长强制播放不可跳过动画。
- 手感：能直接看懂攻击、危险、治疗和器官反应；有技术成长空间，但操作负担不能因系统增多而骤升。
- 桌面网页优先，离线可玩；移动端非第一阶段验收目标。

## 2. 游戏循环：要形成四层相互支撑的循环

### 2.1 5–15 秒微循环（动作手感）

`发现感染体/受损组织 → 移动与瞄准 → 扫描或直接处理 → 命中/净化/组织反馈 → 获得安全窗口或新危险`

**合格标准**：每轮有清楚的动作反馈与战场状态变化；只靠站桩持续开火不能稳胜。

### 2.2 60–120 秒战术循环（差异化核心）

`发现病毒特性与器官相位 → 选择抢修/清怪/根治/借环境 → 引发连锁效果 → 病毒扩散/适应 → 收集研究证据 → 调整打法`

**合格标准**：同一局中，至少两次因状态变化而改变行动优先级，而非始终沿着同一目标表执行。

### 2.3 10–15 分钟单局循环（完整体验）

`进入感染器官 → 建立早期优势 → 首次研究抉择 → 病毒进化预警 → 跨器官迁移抉择 → 研究第二套反制 → 进化体决战 → 稳定器官 → 胜败结算`

**合格标准**：存在开局、中局转折、高潮、结局；不依靠无限刷怪构成进程。

### 2.4 跨局循环（留存辅助，不能喧宾夺主）

`单局结算 → 保存发现/成就/永久新选项 → 解锁新抗体或病毒情报 → 选择初始携带方案/新种子 → 下一局`

局外成长主要拓展策略空间，不永久堆叠大量基础伤害。即使局外无解锁，单局本身仍应有趣。

## 3. 世界规则与玩家目标

### 3.1 本局叙事设定

玩家是“微型医疗战士”。一种 **虚构的异变感染体** 在巨人内部建立感染核心，能够复制、迁徙并改变性状。玩家既要压制威胁，也要保护器官。病毒“进化”仅指游戏规则驱动的分支变化，不要求现实生物学准确。

### 3.2 胜利 / 失败 / 可恢复性

- **胜利**：发现并击败本局“母巢核心”；心脏与肺部（仅本局激活的器官）健康度均 ≥50；全身感染负荷 <35；完成一次主动复测交互后结算。
- **失败 A**：玩家耐久变为 0，且无可用救援；MVP 不设复活道具，清晰提示原因。
- **失败 B**：全身感染负荷达到 100，持续 15 秒未降回 100 以下，触发系统性失控；过程需要倒计时与危机提示。
- **失败 C**：全身生命稳定度耗尽；身体状态来自器官崩溃造成的持续损失，不能无预警瞬间死亡。
- 任意初始随机种子都必须存在至少一条理论可通关路径；不能出现不具备反制工具的必杀性病毒组合。
- 失败后提供“同一种子重试”和“新病例”两个选项；失败应保存玩家的发现记录，但**不保留本局内的临时属性成长**。

### 3.3 核心状态（初值仅供调试，平衡前不是承诺）

| 状态 | 取值 | 作用 | 主要表现 |
|---|---|---|---|
| 玩家耐久 `playerHp` | 0–100 | 战斗生存 | 明确的 HUD、被击红闪、受击来源 |
| 器官健康 `organIntegrity` | 每器官 0–100 | 决定器官功能与长期存活 | 器官地图、组织受损动态表现 |
| 全身稳定 `bodyVitality` | 0–100 | 各器官危机对整体的影响 | 全局生命条与风险提示 |
| 感染负荷 `infectionLoad` | 0–100 | 战况总体压力，达到上限持续触发失败 | 颜色/警戒级别/声效 |
| 病毒进化势能 `evolutionPressure` | 阶段内 0–100 | 累积触发变异预警 | 阶段进度，不隐藏致命变化 |
| 单局经验 `combatXp` | 非负 | 玩家局内升级 | 进度条和升级草案 |
| 研究样本 `researchPoints` | 非负 | 局内针对性抗体研究 | 样本图标与选择界面 |
| 病毒特性 `mutations[]` | 0–2 主特性（MVP） | 改变行为并暴露代价 | 变异标识、预警卡片 |
| 抗体协议 `antibodies[]` | 0–3 装备位（MVP） | 改变规则和连锁方式 | 技能 HUD、联动提示 |

**机制约束**：感染负荷与器官健康要同时重要，但不可变成多个难以区分的血条。HUD 默认只突出玩家耐久、感染负荷、当前器官健康，其余用折叠面板/预警提示。

### 3.4 状态演算范例（统一使用模拟时间）

- `infectionLoad += untreatedSources * sourcePressurePerSecond * dt`；净化感染源、隔离路径时下降；区间夹取到 [0,100]。
- 当前器官完整度因局部攻击、持续感染而下降，抢修时回升；非当前器官仅用低频、可预测的后台压力，不进行超细粒度战斗模拟。
- `bodyVitality` 在任一器官长期严重受损时缓慢下降，恢复器官后可以逐步恢复；全新项目只有本节定义的模型，不存在旧变量映射；健康度和全身稳定必须使用不同、可测试的计算规则。
- 所有进化、伤害、经验变化由一个确定性的 `update(dt)` 顺序处理；暂停不推进，失焦不追赶大量积压时间。

## 4. 病毒系统：进化要“改变打法”，不是属性膨胀

### 4.1 MVP 敌人家族

- **普通感染体**：移动、攻击、死亡；是压力和研究样本的载体。
- **感染源节点**：周期生产感染体、污染相连血管，必须处理以停止增援。
- **进化体精英**：携带变异特性的加强敌人，负责演示新规则与反制窗口。
- **母巢核心**：末段目标，整合本局的两种已出现特性，承担决战而非只增加血量。

### 4.2 四个候选变异分支（MVP 必须实现前三个，迁移能力由迁移导演负责）

| 变异 ID | 可视特征与预警 | 新行为 | 明确代价/弱点 | 玩家反制 |
|---|---|---|---|---|
| `CARAPACE` 晶壳 | 外壳结晶、破甲提示 | 正面常规射击效果下降 | 移动慢；心跳冲击使晶壳短暂破裂 | 选择时机、脉冲共振、绕后 |
| `FISSION` 裂殖 | 体型膨大、裂纹、倒数 | 被击败时分裂成有限小体 | 小体脆弱；聚集时易连锁净化 | 范围治疗、净化链、地形聚集 |
| `MIMIC` 潜伏 | 颜色趋近组织、扫描波纹 | 躲入组织并造成隐性伤害 | 潜伏时行动慢；每隔固定周期有可见波动 | Q 扫描、显影、精准治疗 |
| `MIGRATORY` 迁徙（阶段机制） | 跨器官迁移箭头、倒计时 | 沿开放通路逃往肺部/心脏 | 迁移途中无攻击、易拦截 | 追击、封锁路线、提前布置 |

**安全条款**：每种变异都必须有**开局基础能力可执行的非最优反制**；研究抗体是更有趣或更有效的选择，不能成为强制随机抽中才能通关的钥匙。

### 4.3 病毒进化导演（不是纯随机，也不是强制针对玩家）

输入：本局种子、器官环境、当前已出现特性、病毒生存压力、玩家近 90 秒行为统计（精确伤害比例、AOE 比例、扫描/隔离频率、组织状态）。

建议算法：

1. 生成所有符合当前阶段与器官条件的可选特性集合，过滤互斥组合和缺乏反制的组合。
2. 为每种特性计算 `weight = base + environmentBias + responseBias + varietyBias`；同一分支连续出现扣分。
3. 将任何单种特性的抽取概率限制在约 55% 以内（初始配置，可调整），余量按权重分配。
4. 固定随机种子抽取候选，先给出**明显的预警和弱点提示**，至少 8 秒后才让特性正式生效。
5. 进化后显示“获得能力 + 付出代价”的卡片；使玩家能理解如何反制。

行为反馈是**软偏置**，不是敌人“读心”：例如玩家长期只使用单点高伤时，晶壳权重略升，但绝不绝对触发；如果出现晶壳，不应无条件抵消玩家所有构筑。

伪代码：

```text
eligible = traits.filter(stageOK && organOK && !incompatible && counterExists)
weights = eligible.map(t => base(t) + organBias(t) + playerPatternBias(t) + diversityBias(t))
choice = seededWeightedChoice(capSelectionProbability(weights, 0.55))
showTelegraph(choice, warningSeconds=8, revealCounter=true)
onWarningExpired: applyMutation(choice), logEvolution()
```

### 4.4 传播模型

- 用**节点-连接图**模拟感染传播，节点包括感染源、血管分岔、组织节点、器官出口；**不模拟真实血液流体方程**。
- 连接有 `open/closed`、`flowDirection`、`travelCost`，传播按固定间隔而非每帧复制。
- 每条路径有传播冷却；每区域同时存活的感染体有硬上限（MVP 例如 24）。
- 病毒扩散会增加可观察的地图压力，玩家截断通路后传播立即停止；这要在屏幕上可见。
- 禁止无限生成造成性能下滑或不可逆雪崩。若玩家长期落后，通过威胁强度上限、短暂缓冲窗口保护可玩性，而不是暗中替玩家赢。

## 5. 玩家能力与抗体研究系统

### 5.1 从零定义的基础行动与按键

新项目统一实现一套玩家操控接口，不借用旧“心脏巡游”的武器逻辑。键位是首版建议，应集中配置并可在帮助页面查看：

| 输入 | 行为 | 规则边界 |
|---|---|---|
| `W/A/S/D` | 二维世界平面自由移动 | 可同时斜向移动；不穿透墙与组织；无横版跳跃/重力/垂直爬台 |
| 鼠标 | 360° 瞄准，左键执行当前工具 | 鼠标屏幕坐标可逆映射到世界坐标；命中与 Canvas 缩放、镜头、遮挡表现一致 |
| `Space` | 冲刺/闪避 | 有冷却，不能无限无敌；与心脏/肺部环境碰撞一致 |
| `Q` | 扫描 | 查看病毒特性、受损原因和弱点，不是常开才能正常命中的隐藏门槛 |
| `1` | 精确净化 | 面向单个感染体、感染源或可治疗病灶 |
| `2` | 范围裂解 | 适合群体控制与裂殖小体；存在射程、冷却或消耗取舍 |
| `3` | 组织修复注射 | 修复受损组织；不能直接取代对病毒的净化；有冷却/充能限制 |
| `E` | 交互 | 使用器官装置、转移接口、研究节点和复测设施 |
| `Esc` | 暂停/返回 | 游戏模拟停止；恢复后不继承持续射击 |

MVP 只要求这一套低负担操作；不要为每个抗体增加一个独立快捷键。所有新功能优先通过既有工具触发、自动规则和 E 交互实现。弹药/装填**不继承旧设计**：MVP 使用明确的工具冷却与充能，若测试后需要装填再作为新设计决策加入。

### 5.2 双通道成长

**局内经验升级（即时）**：击败精英、处理感染源、保护组织、完成有效治疗获得 XP，升级时 3 选 1 选择协议（可暂停战斗）；不能靠无限刷同类小怪成为最优策略。  
**抗体研究（策略）**：扫描发现病毒特性/净化关键样本获得研究点，在研究节点选择针对变异的协议或改造。两类进度分别显示，但最终汇入同一装备位，避免叠加两个重复的升级 UI。

### 5.3 抗体协议候选池（MVP 选择至少 4 个；其他作为扩展）

| ID | 协议 | 触发 | 主要结果 | 风险/取舍 | 联动标签 |
|---|---|---|---|---|---|
| `PULSE_BREAK` | 共振裂解 | 在心跳节奏窗口命中 | 破晶壳并扩大破绽窗口 | 需要时机与接近危险区域 | `PULSE`,`BREAK` |
| `PURIFY_CHAIN` | 连锁净化 | 净化感染体或感染节点 | 净化效果在附近有限次数跳跃 | 单体效率较低；跳跃次数上限 | `CHAIN`,`PURIFY` |
| `IMMUNE_BEACON` | 免疫灯塔 | 使用 Q 扫描标记目标区域，满足冷却后自动召集 | 召集临时免疫单位清理小体 | 灯塔区域周围组织承担少量压力 | `SUMMON`,`ZONE` |
| `EXPOSE_TRACE` | 异常显影 | Q 扫描 | 让潜伏体留下可追踪痕迹 | 占用协议槽位，无直接伤害 | `SCAN`,`REVEAL` |
| `FLOW_REDIRECT` | 血流引导（扩展） | 操作血管节点 | 改变冲流/传播方向 | 操作需要安全窗口 | `FLOW`,`ROUTE` |
| `TISSUE_BUFFER` | 组织缓冲（扩展） | 抢修组织 | 短时护盾保护组织 | 牺牲部分即时治疗量 | `GUARD`,`HEAL` |

MVP 建议 `PULSE_BREAK`、`PURIFY_CHAIN`、`IMMUNE_BEACON`、`EXPOSE_TRACE`；提供至少两条由协议互相影响的**明确联动规则**：

1. `PULSE_BREAK + PURIFY_CHAIN`：对晶壳破绽命中后的首次净化，可触发额外一次邻近净化跳跃（总跳跃不超过配置上限）。
2. `EXPOSE_TRACE + IMMUNE_BEACON`：灯塔优先攻击显影感染体，但仍受射程与冷却约束。

反复触发需有频率限制；不允许无限循环连锁导致浏览器卡死；所有加成在结算/日志中可追溯。

### 5.4 研究注射与配装

- 在安全研究窗口弹出 `三选一` 的协议草案，说明**触发条件、变化效果、代价、联动标签**，允许查看当前构筑。
- 首次研究至少保证一个可用的泛用候选；每局 3 个协议槽位，槽满可替换并提示失去什么。
- 单局奖励以“发现一种新打法”为重点；永久解锁只增加后续抽取候选，不让基础数值无限增长。
- 不允许依赖某一种**随机**协议才能击败某一种病毒；测试必须覆盖最差可选草案场景。

## 6. 器官作为战斗规则，而非换皮地图

**空间共同约束**：所有器官在 2D 逻辑地面上运行，3/4 绘制仅决定视觉纵深；心跳/气流改变的是二维世界坐标与事件判定，不能只改变屏幕特效。玩家、病毒、设施复用同一接地锚点、摄像机转换、前景遮挡、Y 排序和碰撞契约。

### 6.1 心脏（MVP 主战场，从零构建）

- **节律**：有清晰心跳相位：蓄力→冲流→舒缓；仅在确实安全的事件上标“安全”，其他相位不误导玩家。
- **环境主动使用**：玩家可在新建的阀门/血管节点按 E 激活一次“定向冲流”，把指定扇区内轻型感染体推开，并使晶壳露出短暂破绽；冷却后可再次使用。
- **代价**：过度冲流暂时增大局部组织压力（明确提示）；使用时机与位置成为策略。
- **视觉**：3/4 斜俯视手绘腔体、深红组织纹理、瓣膜高光、血流层次；地面流动箭头、节奏提示、冲流范围预览、被波及的感染体位移反馈。
- **无需复杂流体仿真**，只需要触发器、方向向量与范围求交。

### 6.2 肺部（MVP 极简第二战场）

- 一间独立、风格有别的 Canvas 战斗区；复用**本新项目内部已开发的**角色、工具、绘制组件与碰撞框架，不做完整器官地图。
- **呼吸相位**：吸气/呼气交替，方向可见的气流影响小型感染体与地面污染团位置。
- **主动使用**：在肺门按 E 封闭或开放一段气道，以阻断迁移；代价是短时间肺部完整度压力上升。
- **联动**：玩家可把裂殖小体聚拢后用连锁净化；也可能错误地把它们吹向脆弱组织。
- **明确区别**：心脏主打“节奏和定向冲击”，肺部主打“气流聚散和通道封锁”。肺部还应在 3/4 场景中明确画出分岔气道、肺泡、透明薄膜以及空气流向；两器官使用同一玩家精灵比例和摄像机规则。

### 6.3 后续扩展：非 MVP

- 大脑：神经路径传播、隔离与连接，侧重连锁线路决策。
- 肝脏：净化容量与负荷，侧重资源转换与过载风险。
- 只有当心脏 + 肺部的规则组合已产生可信的重复游玩，才排入版本计划。

## 7. 跨器官迁移：关键战略抉择

### 7.1 触发

中局当病毒进化至迁移阶段（例如第二阶段，并非固定第 6 分钟）且仍有有效出口时，弹出 **转移警告**：显示去向、倒数（例 12 秒）、当前心脏残留风险、肺部当前健康；玩家可以继续操作。

### 7.2 玩家选择（MVP 最少两项）

- **追击**：赶往器官入口按 E，直接到肺部与迁移群交战；优势是快速截击，代价是心脏剩余感染源维持低频压力。
- **封锁**：在心脏阀门处按 E 并消耗一定时间/研究资源，阻断主要迁移通道；优势是暂缓肺部危机，代价是病毒滞留心脏、增加本地压力。
- **不处理**：警报倒数结束，迁移群在肺部建立新感染源；属可恢复但代价较高的选项，不应自动判负。

迁移不允许仅通过播放动画就强制玩家离开。进入新器官必须有清晰目的/路线/返回方式；可以随时通过器官图查看两个区域状态，但跨器官移动可有短冷却或固定移动成本。

### 7.3 必须有真实后果

- 不同选择导致病毒分布、器官健康、战术环境和后续精英战位置变化。
- 后台器官危机更新应可预测且可展示，避免玩家离开 30 秒就无预警失去整局。
- 若病毒无法迁移（路径已封），转而在原器官触发一条不同强化线路，不得直接结束事件或无事发生。

## 8. 一局流程与节奏（12 分钟目标，非强制时钟）

| 阶段 | 建议时间窗 | 玩家必须体验的设计事件 | 阶段推进条件 |
|---|---|---|---|
| Ⅰ 初始感染 | 0–2.5 分钟 | 一种明确病灶，基础扫描、动作反馈、第一次环境利用 | 处理感染源或积累阶段进度 |
| Ⅱ 进化前兆 | 2.5–5 分钟 | 看见病毒“预警→变异→弱点”，首次研究/构筑 | 第一特性已被识别，完成关键小目标 |
| Ⅲ 器官危机 | 5–8.5 分钟 | 第二种压力出现，病毒转移警报与追击/封锁抉择 | 处理/放任迁移均进入后续阶段 |
| Ⅳ 联动反击 | 8.5–11 分钟 | 玩家获得第二/第三协议，用两种机制创造一次连锁效果 | 清除两处主要感染节点或积累足够研究证据 |
| Ⅴ 核心决战 | 11–15 分钟 | 母巢携带本局主要特性，玩家利用反制窗口决战并主动复测 | 败北，或满足母巢清除和健康阈值后胜利 |

上述时间是初始节奏目标，不要求硬锁阶段；若高手提前完成目标，应允许加快局势推进；若新手较慢，通过软上限而非无限涨强度保持可挽回。

### 8.1 三次游玩的真实差异示例（设计验证用）

1. **脉冲流**：第一进化为晶壳；玩家选择共振裂解，在心脏利用冲流破壳，短时完成高效清除；转移时选封锁，最终仍在心脏击败母巢。
2. **连锁流**：第一进化为裂殖；玩家选择连锁净化，将敌人引到肺部呼气区域聚集清除；追击迁移群，但需要回头修复心脏残余伤害。
3. **扫描流**：第一进化为潜伏；玩家选择异常显影，把隐藏源找出，再用免疫灯塔守住重要组织；因为追击时机不好，选择封锁减少器官损失。

**验收核心不是“三局特效不同”，而是三局的优先级/位置/治疗时机有不同，并且玩家能解释为什么。**

## 9. 可玩性约束、数值与反刷

- 初期精英和感染源的产生节奏不能比玩家的成长更快：保留“挽回机会”；连续恶化要出现可识别原因和至少一个反制窗口。
- 不得刷普通小怪无限拿经验：普通敌人 XP 在同一来源/同一阶段达到上限后递减；主要奖励来自有效清除感染源、正确诊断、精英与阶段目标。
- 系统不禁止高手速通；速通应通过合理操作成立，而不是可直接无视病毒/器官健康达成结算。
- 感染扩散和能力联动都有限额：每个周期最大新增单位数、传播冷却、连锁最大跳数、事件队列最大长度。
- 玩家首次失利应能定位原因；不使用无法解释的暗改敌人伤害、暗改命中率。
- **初始参数目标**：一局 10–15 分钟；变异预警 ≥8 秒；首次主动治疗/战斗目标在进局后 30 秒内；单地图同时活动感染体建议 ≤24。所有参数可配置并要在试玩后迭代。

## 10. UI/UX 规范

### 10.1 常驻 HUD

只常驻“当前目标 + 玩家耐久 + 当前器官健康 + 感染负荷 + 当前工具 + 抗体槽位 + 进化预兆”。非当前器官状态出现在警报与器官图中。

### 10.2 四类高优先信息

1. **当前最大危机**：某器官持续损伤/感染接近失控，显示造成原因和定位方向。
2. **病毒进化预警**：倒数、即将发生的行为、反制线索，不依赖颜色单通道表达。
3. **抗体选择**：暂停战斗、清楚展示效果与代价、说明取代哪个旧协议。
4. **迁移抉择**：去向、倒数、追击与封锁的利弊；不让 UI 覆盖战场太久。

### 10.3 结算页

- 展示胜败原因、病例种子、使用协议、病毒进化路线、器官最终状况、关键决策及连锁次数。
- 评价“治疗质量”和“系统掌控”两条维度；评分只负责解释与激励，不能成为玩法本身。
- 给出一个“下次可以尝试”的事实性建议，例如“本局未利用肺部气流处理裂殖群”；不要声称玩家必然该选另一策略。
- 两个醒目后续操作：“同种子重试”“开启新局”。

### 10.4 新手引导

使用真实局势完成教学，不用大段文字：第一次病毒变异以固定低压机制引导玩家看预警、选择反制；首次迁移显示一次 3–5 秒暂停说明，后续可以跳过。所有提示可在帮助面板回看。

### 10.5 已确认的 3/4 斜俯视与手绘美术要求

- **定稿视角**：3/4 斜俯视伪 2.5D、二维平面自由战斗；美术层有远景、地形、角色接地阴影、Y 排序、前景有机遮挡和 HUD；绝不转成横版平台射击。
- **视觉主次**：手绘微观生物世界及可爱危险的感染体为主体，霓虹光效只提示抗体、心跳、感染和危险，必要时降低粒子密度与 Bloom。
- **图层与交互**：前景遮挡不得藏住玩家和关键弱点；射线与鼠标命中使用逻辑世界坐标；画面必须有切实的 3/4 深度，不能退化成纯圆形点位。
- **验收**：开发阶段执行独立视觉条目 `VIS-01` 至 `VIS-12`，追踪在验收矩阵中；详细标准以美术规范文档为准。

## 11. 长期成长、内容扩展与留存

### 11.1 MVP 局外保存

- 已发现的变异与弱点（图鉴）。
- 已解锁协议候选、成就、最佳成绩和最近 10 局简要记录。
- 单局内 XP、临时协议等级、感染状态**不跨局继承**。
- 数据完全本地存储；明确“本地浏览器清理数据可能丢失记录”，后续可加入导出/导入 JSON。

### 11.2 不推荐现在制作

抽卡、体力系统、付费系统、复杂排行、好友联机、多人同步、海量器官、100 个仅数值不同的病毒。

### 11.3 可扩展内容生产公式

每一个新增内容必须明确写出：**新增可观察状态 → 新的决策 → 可利用的环境交互 → 反制或弱点 → 与至少一个已有协议的联动**。若只有美术变化或数值变化，不视为新玩法。

## 12. 成功指标与用户测试

### 12.1 第一轮验证（至少 5 位未接触项目的玩家；定性为主）

| 指标 | 初始验收目标（探索性，不是成熟产品 KPI） |
|---|---|
| 认知理解 | ≥4/5 能解释本局至少一次病毒变异及对应的反制思路 |
| 自主完成 | ≥4/5 在不由开发者口头指路的情况下完成教学核心循环 |
| 差异可感知 | 同一玩家连续两局，能指出至少一个导致自己改变策略的状态变化 |
| 自发重玩 | 至少 3/5 在不被要求时愿意主动再开一局；记录原因而非仅记录按钮点击 |
| 心流与公平 | 访谈中没有普遍反馈“病毒随意克制我”“操作很多但没作用” |

以上样本太小，不能推断长期留存率。第一阶段只验证核心可能性；真正的长期复玩需后续更大样本、跨天回访与更多协议/病毒策略。

### 12.2 必须否决的设计情况

- 玩家升级后只有数字变大，不产生新的可观察战术选择。
- 所有种子用同一种路径/同一装备最稳，器官环境几乎无作用。
- 病毒进化不可预测、不可识别、不可反制。
- 疾病传播靠纯随机判定，玩家无法通过理解提升表现。
- 新项目无法在干净环境构建/启动、关键机制缺失，或发行包必须联网才能运行。

## 13. MVP 范围冻结（版本定义）

**MVP 必须**：全新独立工程与基础操作；**3/4 斜俯视 2D 自由移动、手绘生物幻想视觉基线（可由占位素材逐步提升）、Y 排序/前景遮挡与多端坐标一致性**；单局状态机；心脏主战场；肺部极简战场；基本病毒、感染源、精英、核心；3 种病毒变异 + 跨器官迁移；4 种抗体协议与 2 种联动；经验/研究；一次清晰迁移抉择；完整胜败结算；同种子复现；本地保存；自动化回归与真人试玩。

**MVP 不做**：真实病原 AI、真实流体模拟、复杂器官生态、无尽模式、大脑/肝脏、多人、服务器账号、付费、移动端特化。若进度紧张，**不要削掉变异前兆、可反制性、器官环境交互、玩家连锁反馈**；优先缩小敌人数量、缩短场景和减少装饰内容。

## 14. 内容创建前的最终审查问题

1. 玩家能否在 10 秒内看出病毒“进化前→进化后”的行为区别？
2. 玩家能否选择至少两种不同但可行的反制路线？
3. 心脏节律/肺部气流是否至少一次帮助或伤害了玩家？
4. 使用两个协议后，玩家是否主动触发过联动并得到反馈？
5. 病毒迁移后，玩家此前的选择是否影响另一个器官？
6. 一局失败后，玩家是否能清楚说出失败原因和下次的改进思路？
7. 即使不看评级和图鉴，这局游戏是否仍然值得再玩？

如果 1–5 不能成立，先改基础规则；不要通过追加长期奖励掩盖问题。
