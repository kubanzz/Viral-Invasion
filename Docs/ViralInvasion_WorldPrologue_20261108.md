# 世界序章 · 体内防线

2026-11-08。为现有游戏加入33秒实时开场，解释人体遭到入侵、免疫军抵抗与失守，以及玩家前往缓流膜湾驻防的原因。末段准备真实营地并逐渐交还画面，玩家继续亲手建立前哨和出征清剿。

## 体验

从主菜单点击“带队抵达”（`endless-start`）首次自动播放。可用右上角按钮跳过、暂停和切换声音；键盘 `Escape` 跳过，`P` 暂停，`Tab / Shift+Tab` 移动焦点，`Enter / Space` 激活按钮。看完或跳过后进入现有营地流程。主菜单“重看序章”播放后返回菜单，不创建营地、不改变已有营地建设、货币或任务进度。

| 时间 | 演出 |
| --- | --- |
| 0—6秒 | 半透明人体与心肺血管，病毒从喉部沿分支向器官推进 |
| 6—11秒 | 肺泡峡谷中免疫军抵抗病毒进攻 |
| 11—16秒 | 心肌前线被突破，感染膜与敌群推进 |
| 16—21秒 | 先遣队接令，明确驻防、建营与清剿目标 |
| 21—29秒 | 血管通道中的行军、血流与组织尺度变化 |
| 29—33秒 | 小队抵达缓流膜湾，逐渐露出真实营地，交还操作 |

序章采用字幕叙事、合成配乐、心跳、战斗与通讯提示音。所有声音由本地 Web Audio 生成，不依赖在线服务。静音与原游戏声音设置同步。首次播放只使用独立的 `vi-world-prologue-v1` 标记，保留现有 `campIntroSeen` 和营地存档；存储不可用时仍可完成观看和进入游戏。

暂停时冻结镜头、角色动作、感染扩散、进度和声音。窗口失焦、页面隐藏或手机转为竖屏也会暂停；手动暂停不会被窗口恢复或横屏变化取消。过场期间原游戏模拟、输入与音效停止，抵达转场提前准备营地时不推进营地时钟。跳过后清空按键状态，避免角色继续执行观看时按下的移动或攻击。

## 制作与资源

- `src/ui/worldPrologue.ts`：独立 Phaser 演出、真实角色动作、画面与输入生命周期。
- `src/render/worldPrologueTimeline.ts`：六幕时间轴、字幕与时长。
- `src/audio/worldPrologueAudio.ts`：本地配乐与效果音，离开序章即销毁独立音频上下文。
- `src/render/prologueAssets.ts`：正式背景静态导入。
- `asserts/ViralInvasion_Prologue_v1/`：四张独立生成的原画、运行 JPG、完整提示词、制作来源和 SHA-256。

原画由内置 `image_gen.imagegen` 制作，分别为人体、肺部、心肌与血管通道。每张原图1672×941；运行图1600×900，四张共791702字节。角色、感染、镜头、粒子与字幕由运行时代码控制。`manifest.json` 保存完整提示词、生成方式和文件哈希；正常缩放/JPEG派生由目录内 `build-production.mjs` 完成。

离线构建使用 `.jpg: dataurl`，图像内嵌于经典脚本；四张图及清单进入 `build-meta.json` 的来源哈希，并提供 `prologue` 资源条目。单 HTML 手机包沿用既有自包含打包流程。无需新增运行依赖。
