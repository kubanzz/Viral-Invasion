# v0.8.8：压力、进化与收割循环

本版按用户的新要求优化连续挑战：反复经历相对困难、升级进化、清场优势与新的挑战。正式战役保留原规则；本轮不生产美术。设计依据为GDD v1.3 §1–2、§4–6及§9的双向进化、连锁成长、可反制与反刷约束。

## 可玩变化

- **每五波一轮。** 第1/3波压力推进，第2/4波进化收割，第5波精英检验。收割波单体更脆、到场更密；新轮次敌体继续成长。曲线只读取波次，不按玩家装备、输出或清场速度临时追平。
- **精英突破。** 每次清波仍三选一；每五波赢下精英后，所选成长最多连升两阶，受路线上限限制。卡片显示真实前后收益，接受后立即作用于攻击。满阶项目退出选池；重复提交、伪造波次和膨胀阶数被拒绝。
- **可操作的免疫协战。** 连续挑战的Q可指定650范围目标，现有小队从原位短时加速集结，随后以更高追击速度接敌。重指挥不补寿命、不重置咬击冷却；伤害仍须真实绕障、接触和视线成立。自动选敌保留显影优先，减少追近后无效换目标。HUD显示已记录的真实咬击次数。

普通体与支援耐久按每轮1.35倍、精英按1.45倍成长；同轮普通体耐久系数为1／0.58／1.16／0.68／0.82。总出生预算最多48，活体及裂殖预约总量仍不超过24。完整前摇、恢复与基础反制保留，没有锁血、强制精英存活或隐藏伤害。

九个正常策略两版都清至35波，仅证明这组策略可达。候选释放波玩家／敌对组织损伤均0，压力波累计60／28，精英波19／0；范围三局仍无玩家或敌对组织损伤。因此不能宣称所有构筑都一样难，或单一策略已不可能通吃。两条不反制负例分别在19.72／19.12秒自然耐久耗尽，保留实际伤害与结算原因。预定候选免疫重放原始JSON逐字节一致。
