# 微观前哨与血流接引 · v0.18.0

## 当前玩家流程

新档点击“带队抵达”，带领六名抗体拟生体走向缓流膜湾的锚定点。靠近后按 E 或点“建立前哨”；小队完成六秒建设后送达第一份侦查报告。建设演出可跳过，领取进度只记一次。旧版已解锁营地的档案直接回营。

前哨提供仓库、锻造、补给、试枪、情报与血流接引。膜隙初染、纤维回廊、缓流边界依次解锁，已完成任务可重复。前两任务有独立净化/感染源/精英条件；第三任务沿用双线、双源、母巢和最终净化。任务成功后显示实际带回的物品，再回营整备。

游戏场景是一片膜表面或组织液微区。心脏、肺部仅表示大区域归属；稳态锚为小队搭建的生物膜构筑。玩家和友军采用抗体拟生体幻想设定，既有柔和色彩与武器手感保留。

## 成长与经济

- 正式任务取消每波、每五波、经验与研究产生的随机三选一；清波自动推进。
- 两种武器、三个模组槽；四模组承接共振裂解、连锁净化、免疫灯塔、异常显影。蓝/紫/金对应Ⅰ/Ⅱ/Ⅲ阶，金色称神级。
- 出发时冻结武器、强化与模组。基础驻军、武器战技和必要建筑能力可直接使用。
- 敌群使用有限任务预算与固定耐久，替代依赖局内持续升级的无限曲线。击杀产生可追溯的真实掉落，自动收集进本次暂存收获。
- 成功基础奖励200金币；首任务另给足蓝色共振模组的碎片及生质。缓流边界每次成功给一枚锻造核心，神级制作不依赖抽取。
- 蓝色制作消耗5型号碎片/10生质；紫色10/20；神级20/40/1核心。武器强化上限+3，费用沿用8/12/16生质。重复装备可分解，最后一件可用武器受保护。
- 失败、撤离或刷新中断任务：普通金币、生质与碎片各保留50%，向下取整；本次装备、核心及完成奖不带回。永久配装与历史成果保留。

## 血流接引

新存档初始5000金币；有效旧存档一次补足到至少5000金币，补发与领取标记一同保存，消费后刷新不再补满。单次100金币，十次1000金币。基础品质概率白60%、蓝25%、紫10%、金5%；连续49次未金，第50次必金，任何金色重置计数，单次和十次逐抽共用计数。

白色转化为生质；蓝/紫产出同品质武器、模组或型号碎片；金色灵幻体一次性凝成神级武器40%、神级模组40%或锻造核心20%。成品与锻造共享模板池。单抽与十连共用脉流汇聚、品质显现、整批揭晓的演出：本批实际最高品质决定预告光效，实际奖励数量决定卡槽；单抽展示一件大图，十连同时展开十张卡片，一次收下全部奖励。卡片与最终收据保持原始抽取顺序，演出时长不随数量倍增。抽取先完成扣币、生成、保底和入库，再展示真实收据；跳过展示不影响奖励，重复请求不重复扣发。低特效或减少动态效果模式直接显示结果。

## 存档与接入

营地键仍为 `viral-invasion:1:camp-profile`，当前内容为schema 3。包含序章、任务进度/战绩、钱包、库存、碎片、核心、配装、保底、任务暂存收获和独立交易收据。新抽取收据记录50抽保底版本，旧10抽保底收据保持原规则校验与去重。旧Boss账本与胜利数保持原约束，任务/抽取收据独立。旧武器品质、强化、材料、蓝图与旧战绩保留；新任务不写入旧规则排行榜。

存储失败时保留本页结果并提示重试。刷新只能恢复最后成功落盘的原子快照，不承诺恢复从未保存的数据。浏览器检查使用只读 `window.__viral` 诊断，正式动作经由真实DOM输入。

新增图片统一交由用户指定的“美术资源生成会话”（`01a1ac5b-6b21-76e2-80c0-f2f0ae20f724`）制作；生成方只写新素材目录，主会话负责选材、碰撞、管线与实际画面验收。原图、处理方法与生成记录保留，概念图不算运行资源。
