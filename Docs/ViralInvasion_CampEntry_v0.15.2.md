# 营地入口与救援结算修正（统一交付v0.15.3）

用户回忆看到“这次救援结束，再试一种路线”。旧界面在本局没有救援成功快照时使用该标题，既可能是玩家／心核归零，也可能是未完成撤离，容易被误解为通关。不能仅据这句回忆确认其具体死亡原因。

本轮修正：

- 玩家归零明确显示“救援失败：玩家耐久归零”；心核归零明确显示“救援失败：心核被摧毁”，突出真实原因和剩余耐久。
- 仍存活的主动撤离显示“已撤离，本次救援尚未完成”，与失败、通关分别呈现。
- 未成功时显示两线接防、双源、Boss、最后净化的实际完成情况，说明清一波或暂时净化地图不等于通关。
- 已有真实救援成功快照时，继续守卫后结束或死亡仍保留救援成果；结果页补充营地按钮。
- 本局失败但此前已有营地，可返回原营地，不冒称本局通关，也不发本局未带回奖励。
- 主菜单保留独立的“开始挑战”和“心脏营地”两个入口；未解锁时直接说明首次救援成功后开放。

营地解锁、武器／蓝图／材料掉落和永久奖励账本规则保持不变。本轮不根据失败界面补发物品，也不绕过Boss或最后净化。
