# v0.21 田园生活区

三块营养田从设施菜单中落到营地场景：可直接看到土垄、幼苗、成长植株和成熟营养荚。走到田边，点击田地/作物或按E播种、采摘；上方显示最近田地的操作，收获有口粮反馈。远处点击只提示靠近，成熟不自动收取，种收不会暂停世界或打开管理面板。成熟提示属于各块田，不再出现旧“点击建筑”的农场菜单提示。

三地仍对应schema5原来的三个种植记录，不重置既有作物和口粮。免费种子、两次有效出征成熟、每地2粮及缺粮出征规则沿用v0.20。

免疫居所使用三栋独立排序的叶膜宿舍围出生活庭院，编队成员分布在左右门前。每栋有独立实体碰撞，院内可行走，仍只有两个出征编队位，不增加粮耗。

北侧改为较窄的奶油色弧形步道，连接田间、宿舍和中央种植花岛。原五处基础设施保留。完成初始五设施后，外围显示育种园、研究区和疗愈林的轮廓、入口、门栏及“筹建中 · 尚未开放”；门栏实际阻挡通行，尚无解锁任务或收益。它们用于预告后续空间。

默认近景跟随角色，靠近地块时保留可操作视野；“营地全景”显示完整营地与外围筹建区，可随时切回跟随。新手建营沿用原相机和五设施流程。

资源复用已验收的作物、宿舍与角色PNG，所有作物与房屋独立按地面Y排序，原始资源和20MiB运行资源上限保留。验证使用真实键盘/鼠标/CDP触屏输入和只读诊断，覆盖1366×768、844×390、667×320；初始存档样本提供空地、生长与成熟阶段，不能视为自然出征所得。实体手机仍需试玩。
