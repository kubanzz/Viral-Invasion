# v0.23 猎袭母巢与蜜露田园

本轮集中改善三个可感知的体验：母巢真实移动、营地行走镜头稳定和开放通路，以及看得见过程的农场。

## 母巢

远征母巢采用新生成的骨白脊冠、镰钳与暗紫膜肉完整主体。晶膜、裂殖、噬心是三张独立绘制的阶段形态，替换旧完整底图加阶段贴片的组合。三阶段共享地面锚点；呼吸和行进姿态使用模拟时间，暂停冻结。

权威战斗系统加入追击与侧移，阶段速度分别125/145/165。攻击前摇、破韧和蜕变时停步；现有阶段攻击序列之后追加锁向短冲，前摇0.95/0.85/0.75秒，距离310/350/390，伤害20/24/28。预警画出真实扫掠半径，冲刺沿预警方向，不在释放后追踪玩家；单次冲刺只命中一次。世界边界、障碍、减速和刀4冻结都作用于真实移动。三条5400血、破条溢出抑制与最终一次奖励沿用。

旧战役母巢在恢复间隙以70速度巡弋，限制在出生点120范围内；原攻击、膜层、迁移和阶段规则保留。

## 营地

行走不再按最近建筑或田地自动重选中心和缩放。使用固定步行尺度、死区和平滑跟随，主动“营地全景”仍可查看筹建区域。建筑院落改用短角边界，开放四面出入；主路、南北生活轴与田园横路直接连接，真实建筑主体保留碰撞。

## 蜜露田园

- 靠近空田点击或按E启动1.5秒播种，环形进度完成后才写入作物。离开田边、切入设施或离场取消；暂停冻结。
- 每块蜜露营养荚在营地内累计150秒成熟，显示圆形倒计时。每次有效出征仍推进75秒，两次即可成熟。
- 每轮浇水一次加速25秒；长到60秒后可除虫一次，再加速25秒。照料免费且可选，不照料也会自然成熟。
- 成熟作物不腐坏，靠近采摘得到2粮；种子免费，零粮应急出征规则保留。
- 幼苗、成长、成熟使用新的翠绿叶片与奶白金蜜果荚，保留自然大小差异与同一根部锚点。

成长只消费游戏模拟增量。存档每秒批量保存，不按每帧写入，不按离线墙钟长大。schema6兼容schema5：旧growth0/1/2映射0/75/150秒，成熟不回退，金币、收藏和任务回执保留。
