# v0.20 圣裁军团与四曜穿心

2026-11-07。沿用离线微观前哨与四武器玩法，新增永久军团收藏、独立军团接引、农场补给与两支出征编队，重做刀的2/3/4技能及远征母巢。

## 军团与接引

血流接引点有装备、军团两个页签。军团池100金币/抽，白色生质5份60%、蓝色吞噬卫队25%、紫色游猎军团10%、金色曜卫·圣裁5%。连续49抽未金，第50抽必得曜卫；单抽和十连共享军团保底，装备池保底不受影响。重复蓝/紫/金军团转10/20/50生质。抽取在演出前结算，跳过动画、刷新、保存失败重试不重复扣款或发奖。

基础吞噬卫队免费拥有；游猎军团速度230，伤害提高25%，生命降低10%。曜卫固定一领队、三翼卫，Ⅰ阶生命120/72/72/72，总伤害为同阶普通军团150%，活动半径增加30。Q明确围猎后，领队真实近战追加30/45/60伤害，军团共享6秒冷却。只有曜卫可按Q明确围猎已开放的母巢核心，对核心伤害50%；默认清理护卫。R的残像共享追击冷却，不产生新收藏或额外粮耗。

全场最多两支军团，曜卫最多编入一支；基础与游猎可占两个位。阵亡只删除当局实体，永久收藏保留。

## 营地种植与生存

基础五设施教学不变，就绪后北侧开放免费2秒施工的营养农场与免疫居所。居所有两个编队位；农场有三块地，唯一作物营养荚、免费种子，两次有效出征成熟，每块采摘2粮。成熟不腐坏、不自动收割，支持一键补种和采摘。

新旧档一次赠6粮。出发冻结军团与供粮状态，依位序每位预留1粮，结束时才实际扣除。成功总有效；失败或撤离需有效战斗至少60秒、击杀至少5体才推进作物并消耗已供粮口粮。立即撤离不推进也不扣粮，每个runId只结算一次。Q再部署和R裂变不增加消耗；暂停、驻营、离线不扣粮。

缺粮回屋显示虚弱待补给，仍可应急出征，生命与伤害75%；补粮后下次出发恢复。无粮时仍能靠玩家和虚弱基础军团完成有效出征、种粮恢复。首版无永久伤残和饿死，也无离线生长。

## 刀的战技

- **1破阵疾斩**：沿用现有真实碰撞突进。
- **2逆鳞返刃**：8秒CD、0.45秒正面架势，前0.18秒完美弹反抵消首击并6倍反击、40削韧；晚挡减伤75%，3.5倍反击、20削韧；空放收势2倍刀气，距离320。无攻击来源的感染不能弹反。飞弹真正被销毁，每次架势只反击一次。
- **3赤曜剑域**：14秒CD，220半径，0/0.6/1.2秒各1.2倍环斩，1.8秒2.4倍终结，总6倍。减伤20%，可移动普攻。
- **4四曜穿心**：100能量、650范围，优选四只分散病毒，不足在现有目标上补点。3秒绘线，普通移动病毒减速80%，已连接目标固定亮点，玩家减伤70%。鼠标/触屏连续拖线，22屏幕像素吸附，松手可续画；完整手绘立即执行，超时保留手绘部分并自动连齐。无目标不耗能量。

角色沿实际预览的可达曲线高速移动，障碍处绕行。普通标记处决；精英每点10倍、母巢每点6倍及25削韧；未标记沿线每体一次4倍，标记不叠加沿线伤害。完整手绘伤害/削韧乘1.2、沿线宽度乘1.25；执行无敌，结束收刀0.18秒。大招及其衍生击杀不为自身充能，暂停冻结倒计时，离场统一清理。技能期间暂收起可点击的蓝图发现通知，结束后恢复未读提示；B及建设入口无法抢占绘线。
