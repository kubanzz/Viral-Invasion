# 裁决铳：持续电刑与万雷归一

2026-11-08。在当前 v0.24 工作区重做霆链·裁决铳，保留 `thunder` 装备标识、品质、强化、获取与存档。

## 战斗与操作

D 为品质、强化与力量各结算一次后的基础伤害。范围采用世界单位。

| 操作 | 机制 |
|---|---|
| 霆链电刑 | 长按普攻自动连接周身240范围最多8体；瞄准近目标可指定主弧，否则最近目标。主弧每秒 D/当前普攻间隔，支弧35%。每0.1秒结算，松手停止；目标死亡、出界或遮挡时重选。 |
| 1 断罪连爆 | 周身300及当前通电磁极覆盖区，感电4D、未感电1D，每体一次并消耗感电；5秒冷却。 |
| 2 引雷磁极 | 450距离点投，200范围1.5D落地爆发与0.4秒牵引，磁极保留4秒。玩家按住普攻且在450内通视才供电；与玩家共享目标预算并去重；9秒冷却。 |
| 3 雷遁穿场 | 0.18秒内穿行280，期间无敌、沿途每体2.5D一次，真实地形截停。宽80雷痕持续2.5秒，每0.25秒0.25D并感电；10秒冷却。 |
| 4 天穹裁决·万雷归一 | 100能量展开随身360范围雷暴，6秒内每0.5秒对最多12体各0.5D。0.35秒后可再按4，进入0.25秒收束；6秒到时自动收束。终结在玩家当前中心结算4D，感电另加最多4D（雷暴积蓄时间/6），并消耗感电。 |

普攻电流及3的有效伤害立即附加或刷新3秒感电；普通电击不造成持续硬直。大招落雷不单独附加感电。连爆、终结和余震不递归生成感电爆炸。

桌面左键／手机普攻盘长按可配合移动和1234。1与4点按自施放，2点投，3方向释放；大招可重施时显示“立即裁决”。安全试枪支持按住0或普攻按钮，松手、失焦和退出立即断电。

手机横屏雷枪试枪采用左侧画面、右侧两列操作；667×320下画布453×168，按钮均至少44像素。视野聚焦玩家与靶群，雷暴圆按实际范围裁切，雷遁后仍保留玩家与靶群。

典型连招：2聚怪供电→长按→1连爆；3穿场留痕→1反杀；4展开→长按与3带场走位→再次4收束。

## 成长、伤害与表现

- 多重每阶增加2个电击目标；贯穿每阶额外跳电一体，35%主弧伤害、不递归，每脉冲每体只命中一次。护膜零伤目标不能充当跳板。
- 急速提升持续电流伤害率；范围和余震强化2的落地爆发，余震没有二次牵引。电流与磁极逐段检查地形。
- 每个普攻脉冲有独立伤害事务：同一脉冲不跨母巢血条，下一脉冲可继续伤害。Boss正常感电和引爆，位移限制沿用现有规则。
- 大招落雷、终结及派生伤害不回充大招。死亡或离场直接取消雷暴，不补末爆；暂停冻结计时与音效。
- 连续弧、感电纹、磁极、雷痕、雷冠、回卷电弧与主雷柱共享实际状态；伤害数字合并为四分之一秒窗口，持续电流使用单一循环声部。终结才触发短促镜头震动，低特效／减少动态关闭震动。
