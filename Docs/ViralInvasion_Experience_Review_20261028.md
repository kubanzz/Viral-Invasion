# 流畅度与素材接入验证记录

本记录对应 2026-10-28 的工作区 v0.9.0，保留已有未提交工作。素材源为本项目 `asserts/`，新素材仍需审阅并显式登记；开发启动和构建会重新同步。batch10 的四帧待机按 4 FPS 接入，walk、hurt、dash 尚未批准，继续使用单张回退。

## 实施与验证

- 在表现层插值角色、敌人及免疫细胞的位置，并平滑镜头；暂停、切换器官、长帧及大位移重置。贴近障碍时，各活动实体非法的插值位置回退到真实位置。60、120、144 Hz 的模拟时间序列及同种子、同输入战斗状态对照通过。
- 依据真实工具事件播放区分工具的反馈音，增加后坐、枪口闪光和冲刺轨迹；主武器光束只在真实出生事件可证实时采用工具枪口，命中和遮挡仍由模拟状态决定。
- 窄窗口缩减面板和工具栏占用，保留工具说明及危机提示；360×640 至 1280×720 五种视口在 Chrome / Edge 验证。360 像素宽下文字较小、战场视野有限。移除两次每帧全屏 Canvas CPU 复制，保留必要的图层与 GPU 更新。
- 四帧待机的隔离实机预览记录了四轮循环，以及暂停、左右翻转和起停回退：`artifacts/experience-optimization-20261028/idle-preview-evidence-v3/report.json`。正式离线包的动画、窗口和图层检查在 Chrome / Edge 共 10 项通过。
- 包含实体插值校验与窄屏修改的固定构建在本机无头 Chrome 1366×768，使用真实输入和密集战斗完成 600 秒：标准平均 59.95 FPS、p95 16.8 ms、最长帧 66.6 ms，低特效平均 59.96 FPS、p95 16.8 ms、最长帧 33.4 ms；采样包含 24 个敌人与 3 个免疫细胞。证据：`artifacts/experience-optimization-20261028/collision-hud-performance/report.json`。这些数字只覆盖该构建、设备、浏览器和场景，不等于所有设备或真人试玩；自然内存采样也不能单独证明不存在泄漏。
- 压力构建的所有已记录输入与当前工作区一致；Chrome / Edge 对该离线包的五种窗口、图层和待机动画共 14 项回归通过。以密集快照进行的渲染状态不变性检查也通过。

## 已知限制

- walk 八帧仍为待修复候选，dash 尚无批准的完整组。hurt 两帧已交付并完成隔离时序验证，但持枪连接横穿胸部且工具与手部脱离，暂不批准；详见 `artifacts/chatgpt-art-generation-20261028/quality-art-feedback.md`。当前待机切换单张行走姿势仍会跳变，其他方向与开火动作也尚待素材。
- 同一真实战役自动路线曾一次完整通过，另一次到达肺部后角色耐久耗尽；标准免疫路线也曾失败，复测通过。不能将这些结果称为稳定的人类通关验证。
- 上一轮单测的无尽伤害、催化文案和研究方向断言已根据当前真实规则和诊断状态修正；三个非针对性协议战役路线的输入驱动改为实际的工具 2 按下/释放操作，保留原通关断言后三例通过。20 分钟战斗模拟单独重跑通过。1000 种子测试的旧驱动有同类问题；修正后仅保存了 100/1000 的检查点（100 胜、无不变量失败），进程中断，不能称作完整通过。
- 未在真实显示器刷新率、实际听觉体验或目标用户设备上完成真人试玩。后续素材需在实际游戏内重新审查，不应仅凭文件存在启用。

- 补充诊断在同一离线构建的 DPR 2 稀疏战场交错进行 4 次截图和 4 段无截图对照：4 次截图均出现 466.6–516.8 ms 长帧，控制段最大约 16.8 ms。此前压力测试的两次长帧也接近各自的密集截图，强烈提示截图干扰；旧记录缺少足够时间戳，不能断言当时两帧的确由截图造成，也不能排除其他战斗场景的卡顿。完整报告为 `artifacts/experience-optimization-20261028/dpr2-longframe-diagnostic/report.json`。
- 暂停时角色、敌人和免疫细胞保留上一帧合法显示位置，恢复后继续插值；血量、事件和阶段始终来自最新模拟状态。Chrome / Edge 暂停精灵位置及按真实帧间隔采样的恢复镜头检查各重复 5 次通过；早期固定 5 像素断言的失败记录保留。包含该修改的 DPR 2 密集 600 秒报告位于 `artifacts/experience-optimization-20261028/pause-final-performance/report.json`：标准平均 59.88 FPS、低特效 59.89 FPS，p95 均为 16.8 ms；最长帧分别为 500.0 和 533.2 ms，不能仅凭截图对照确定其原因。
- 工具准星按实际模拟角色位置及当前工具射程反馈：工具 2 使用 420，工具 1 和 3 使用 530；工具 2 和 3 还提示目标点受障碍遮挡。工具 1 是沿射线判定的武器，障碍前仍可能命中目标，因此不将障碍后方的准星直接标为整次射击被阻挡。准星只提供几何提示，冷却、目标有效性及命中仍由游戏判定。真实浏览器移动与冲刺开火检查确认首发对应点击前可见镜头下的世界位置；镜头随后的移动会改变屏幕上的显示位置。
