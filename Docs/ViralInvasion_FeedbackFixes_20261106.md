# 战斗反馈与营地交互修复

本轮在 v0.18.0 基础上改善战斗反馈与营地服务流程，保留既有顶部 HUD 精简成果。

- 失败结算显示“清剿失败”和简洁原因；主动撤回显示“已撤回前哨”，半数普通资源结算规则沿用。
- 稳态锚本体常显血条和当前/上限，≤30%变红。真实打锚前摇或最近两秒敌袭损血触发小地图红圈、感叹号、返回防守目标与限频短音。单纯靠近、攻击军团、修复和环境侵蚀不误报；暂停冻结，静音不补播，低动态效果保留静态标记。
- 点位感染从各自中心向外扩散，区域多边形裁剪避免互相覆盖。感染中和感染完成使用同一世界坐标地面，捕获方向不再依赖攻击者排序，进度不重建地面缓存。
- 建筑服务删除全局页签和无关新手提示；关闭和底部“返回营地”恢复原位置。仓库、锻造的试枪返回原服务。
- 血流接引改为营地主路东侧相对坐标 `(132,90)` 的悬浮光核，光环、光柱与粒子由运行时绘制；节点不阻挡行走。仅世界节点及附近交互打开接引，抽取时再次校验激活状态和距离。

## 状态和资源接口

`anchorDangerView()` 为小地图、HUD、屏外方向提示及音效提供统一只读状态；`TerritoryState.coreLastHitAt` 为可选临时展示时间。不会增加持久化失败原因或存档版本。

营地设施支持可选院落归属和 `blocksMovement`。继续使用原 `summon` 身份、已激活状态及交易/保底数据；旧存档直接在新位置呈现光核，不重新收费或要求重建。

新素材由用户指定的“美术资源生成会话”交付，来源、透明边缘、锚点和 SHA256 见 `asserts/ViralInvasion_CampFeedback_v1/delivery.json`。主会话只更新 `microfront.camp.summon` 的选材，冻结旧素材与本轮源图。接入记录见 `artifacts/feedback-fixes-20261106/art-intake.json`。

## 验证边界

规则、受控视觉、真实输入与离线包验证分别登记在 `artifacts/feedback-fixes-20261106/verification-summary.json`。静态视觉 fixture 和供应的初始存档不代表自然赚取、真人难度或实体手机测试；失败的驾驶记录保留。
