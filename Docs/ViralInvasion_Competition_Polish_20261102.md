# 《病毒入侵》参赛版精修 · 2026-11-02

## 主题诠释：万物生

在巨人体内，玩家通过净化与成长，让受感染的心脏逐步恢复生机。抗体壮大、血流复苏，生命在战斗中重新生长。

## 可玩内容

首页选择“开始挑战”，亲自瞄准净化病毒，每清一波获得一次战斗强化。首份强化提供扇形抗体Ⅰ、裂解新星Ⅱ、冲刺斩Ⅰ，分别改变射击覆盖、聚群爆破和冲刺进攻；军团负责辅助围猎。

首阶段五波总预算为 **40／100／80／160／120**，收割波以成群的脆弱感染体展示进化收益。第三波加入点射支援，第五波包含晶壳冲锋精英、点射支援和可拦截弹囊；危险仍有真实前摇与基础反制。挑战活体预算上限48，队列、待分裂小体与弹囊共用人口约束。

完成第五波的战斗强化与协议选择后，展示第一阶段成果。继续挑战保留同一局的成长、分数与耐久进入第六波；选择结束才正式结算。此后沿用无尽的远侧源、组织袭击与后期病毒进化。

每五波额外获得一次协议选择；本模式取消清波XP和预装成长债务。战役原成长系统保留，其入口继续从普通首页隐藏。旧最高纪录与近期记录保留，但旧版与本版的成长和敌群规则不同，旧成绩不作为新版的趣味、平衡或性能验收证据。

## 表现与素材来源

环境复苏由前五波已清波数派生，逐步恢复原场景暖色和血流，增加有界流动微粒与第五波复苏信号。它只影响绘制，不修改碰撞、敌人数量、组织耐久或伤害。实际组织仍受损时继续使用受损贴图及HP提示。

命中标记读取真实正伤害回执，击杀标记匹配真实死亡体；同一片区域的多目标反馈合并，普通设置最多12组命中与6组击杀标记，低特效设置最多4组命中并关闭装饰性击杀粒子和复苏微粒。本轮不新增镜头震动。

本轮复用工作区 `asserts/` 中已经由 `asserts/art-selection.json` 选定的角色、病毒、组织和环境资产，构建通过本地美术同步流程生成图集；新增血流与反馈使用程序绘制，无新增外部下载素材。项目允许AI辅助制作；本说明仅记录本轮实际复用来源，不替既有素材作未核实的版权保证。投稿前应对照原始创作记录核验素材及字体的使用授权，并按赛事要求签署知识产权协议。
