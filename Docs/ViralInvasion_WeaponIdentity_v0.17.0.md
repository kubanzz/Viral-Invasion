# 双武器身份重做 v0.17.0

2026-11-05。目标是让玩家在实际战斗尺寸下，仅凭持握轮廓、普攻弹道和技能节奏就能分辨两把武器。旧 `steady` / `piercing` 收藏ID、品质、强化、营地材料和蓝图继续使用。

## 两种武器

| | 稳流·蜂巢针枪 | 贯脉·回旋刃弓 |
|---|---|---|
| 轮廓 | 短粗多管蜂巢、圆鼓药仓、奶白与薄荷青 | 竖向月牙双刃弓臂、象牙与琥珀橙，无针筒枪管 |
| 普攻 | 快速小针，34基础伤害、基础一体 | 慢速宽月牙，28去程／18.2回程伤害，每程基础两体；间隔约为针枪1.6倍 |
| 1 | 蜂群追针：五根散开的蜂针有限转向追击前方可见目标 | 蓄势穿心：锁方向准备0.45秒，4倍基础伤害，最多六体；每穿一体，后续伤害加12%，最多36% |
| 2 | 排异震环：玩家脚下半径155瞬发，基础68伤害、最多击退70 | 束脉锚：点投后持续牵引1秒再爆，半径150、基础42伤害、总牵引最多80 |
| 3 | 蜂巢超载：4秒加速，每次普攻额外两根35%伤害侧针 | 回缝风暴：三片大月牙出去再收回，每目标每程至多一次伤害，去程2倍／回程1倍 |
| 主要操作 | 追踪点杀；贴身用震环解围；超载抢反攻窗口 | 锚聚敌后侧移排线，再蓄势穿心；发出回刃后横移改变回程 |

蜂群不是无限自动锁敌：存在转速、总转角、前方视野与距离限制。回刃按玩家当前位置调整回收方向，有独立每程命中账本、有限距离及寿命；两程均受真实障碍和护膜约束。技能与普攻仍走统一生产伤害入口。

## 当前战场和成长

- 123独立技能、F净化、Q驻军、Space冲刺保持。震环和超载不要求瞄准，手机点按即放；其他技能可拖动瞄准。
- 净化同线生命泉与前线解除感染源护膜，失守复膜且源耐久保留。武器不跳过区域供能、祭团护膜或Boss核膜，也不自动净化节点。
- 固定目标、建筑、母巢与已进入攻击动作的敌人沿用位移限制。锚和震环的余震不重复位移、不递归。
- 力量、品质、强化计入一次。多重／贯穿／急速继续影响普攻，超载只固定增加两根侧针；新星与余震只影响技能2。
- 在途弹丸、预约连针和余震合计最多192，敌方人口及预约仍最多48。

## 营地与素材

营地换装立即更新世界持握外观。仓库、锻造、战利品和试枪复用当前两件武器的实际透明PNG；破损展示为同一件物品的褪色表现。安全试枪共用战场弹道和技能特效，可用0普攻、123技能或按钮操作；群靶首靶在震环范围内。试枪只使用隔离状态，不消耗材料或写战绩。

新美术由用户指定的“图片生成会话”生成，原图、提示词、生成记录与注册数据保存在 `asserts/ViralInvasion_Weapons_v2/`。运行素材用独立ID `fantasy.weapon.steady.held` 与 `fantasy.weapon.piercing.held`，分别登记512画布、握点与发射点。既有原图和旧选材保留。静态武器配合程序持握、旋转、开火和技能表现，不称独立逐帧动画。
