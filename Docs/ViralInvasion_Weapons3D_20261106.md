# 三维武器与握持优化 · 2026-11-06

当前 v0.18.0 的三维主角已使用独立三维蜂巢针枪和回旋刃弓。原接入的“手骨投影点 + PNG 武器”会产生固定透视、整图翻转、整体前后切层及转身不同步；本轮将武器放进角色的同一个 Three 场景，修正比例和挂接。

## 资产与装配

| 武器 | 三角形 | 大小 | 造型与挂点 |
| --- | ---: | ---: | --- |
| 蜂巢针枪 | 1,984 | 75,052字节 | 紧凑象牙护壳、薄荷能量筒、蜂巢短枪口；右手刚体挂接 |
| 回旋刃弓 | 1,756 | 70,488字节 | 有厚度的双弧刃、琥珀核心；左手刚体挂接，独立动态弓弦 |

资产位于 `asserts/ViralInvasion_Weapons3D_v1/`。使用 Three.js 0.187.0 的标准几何、材质合并和 GLTFExporter 离线制作，并经 GLTFLoader 回读；是本项目新制作的真正三维网格，没有重新生成角色或消耗 Tripo 积分。可复现脚本为 `scripts/build-held-weapons-3d.mjs`，哈希和节点坐标以同目录 `manifest.json` 为准。

两件武器均为刚体，不另加武器蒙皮。握柄位于原点，+Y上、+Z前，提供握柄、枪口及副手参考节点。挂点使用 Three 标准骨骼父子变换，继承手的旋转和位置；武器与人物共用相机、光照和深度缓冲，能被手掌、前臂与身体局部遮挡。成功显示三维武器时，不再叠绘旧 PNG 武器。

挂点校准使用与游戏相同的“下身待机 + 上身武器”混合姿态，避免完整源动作的腰部朝向误烘入武器局部旋转。稳定待机的枪口方向有全象限回归检查；射击后坐力、步态和转身过渡仍保留动作带来的自然变化。

## 持弓与发射

- 从原拉弓动作截取静态持弓准备姿势 `Bow_Ready`，避免闲置时垂手拖弓或自动反复拉弦。它是派生姿态，未伪计为新源动画，角色 GLB 仍是原53关节与17片段。
- 真实蓄力事件只播放准备姿势之后的拉弦区间。弓弦由两段细三维线体连接上下锚点和活动弦心，随蓄力拉开、释放后回弹。
- 使用 Three 官方 `CCDIKSolver` 校正右手与弦心接触。私有骨架视图引用已有臂骨，未修改53关节 GPU 蒙皮、绑定矩阵或原角色资产。
- 准备姿势有0.03单位的轻微预拉，使弦心位于紧凑角色的手臂可达范围内；额外拉距相应缩短，满弦位置不变。释放时回到松弦位置，没有增加虚假蓄力或伤害。
- 实际三维枪口的投影接入现有弹丸及光束的展示出生点，附加短促枪口闪光；伤害、命中、冷却、库存、存档与随机数规则不变。
- 武器边界包含拉开的弦心与闪光，继续交给 Phaser 的场景深度排序及遮挡。没有新增独立帧循环。

## 验证

最终报告、截图及回归证据位于 `artifacts/weapon-3d-optimization-20261106/`。涵盖真实默认建营/首任务、全象限及跨 ±π 转向、移动与射击、暂停/缩放/重开、弓的持握及真实技能蓄力、WebGL1 回退、可信双触点。

最终冻结构建的 Chrome 5/5通过（62.0秒，无跳过、失败、重试或远端请求），相关8个单测文件55/55通过，全项目 TypeScript 检查通过。13个稳定方向的枪管最大偏差约0.201°；持弓准备时手弦间距约0.00915、实际拉弦样本最大约0.00598模型单位。射击后坐力、移动和转身过渡不纳入稳定待机的精确朝向声明。

本轮存在并行的战利品界面修改。为让武器验收可复查，`build/` 保留与最终试玩服务器完全相同且校验输出哈希的固定构建；武器相关源码与该构建一致，其他界面文件的后续变化另列于 `build-attestation.json`，没有回滚或覆盖它们。

弓的浏览器测试使用隔离上下文：通过公开 `CampProfileStore` 奖励 API 生成拥有待修复贯脉的合法初始存档，再真实点击修复、装备、出征和技能。它不代表自然流程通关，也未改用户存档或实时调试状态。

GLB 自包含嵌入离线 `game.js`；构建核对资产清单哈希，`build-meta.json` 记录两件武器。Vite 与 Vitest 同时登记 GLB 为资源文件。WebGL2 或初始化不可用时仍回退原 PNG；菜单素材预览、仓库卡图和独立试枪面板保留已有二维展示。

## 范围

本轮优化武器三维表现、比例及握持。仍使用现成角色动作，不宣称逐根手指完全贴合或完全没有穿插；实体手机性能仍待真机验证。新武器制作不改变 Tripo 免费角色身体的非商用评估限制，原许可记录保留。
