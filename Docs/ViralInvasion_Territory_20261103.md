# 心脏区域争夺与奇幻生态 · v0.10.0

## 实际玩法

首页“开始挑战”显式启动区域规则。隐藏战役和训练保留其规则；底层未显式启用territory的历史回归fixture不作为当前主玩法验收。

胜利路线为：守住生命泉 → 净化失守节点 → 击破双感染源 → 击败母巢 → 保存救援成果。没有固定八波门槛，第五波仅提供突破与协议，不再显示旧版完成出口。玩家或心核耐久归零失败，同帧击败母巢且死亡仍失败。

五节点复用现有2400×1500心脏战场：心核(1200,900)、北泉(1150,330)、南泉(1880,1300)、西源(450,600)、东源(1950,450)。心核和北泉初始健康，其余感染；地图区域采用裁剪Voronoi，显示归属不改变碰撞。

普通病毒经过不染地。带标记的侵染者在生命泉120范围累计10秒完成占领；多人不加速，离开后每秒回退10个百分点。西源向北泉派遣，东源向南泉派遣；关联泉已失守则转攻心核。前两波最多一名、之后最多两名，替换已有普通出生槽。源被真实击破后不再派新侵染者，已有敌人保留。

工具3瞄准150范围内失守生命泉启动3秒净化。期间可移动射击；离开范围或侵染者干扰会暂停而不清空进度。健康生命泉150范围每秒恢复3耐久，争夺中仍有效，完全失守停止。重叠治疗不叠加。驻留1秒清除玩家感染；新感染重新累计这1秒。

病毒或母巢实际攻击造成正伤害后，使玩家感染8秒，每秒损失1耐久。重复感染只延长持续时间，不叠层或推迟下一次掉血。训练、自损和感染自身不会递归感染。暂停、选择、详情和失焦均冻结模拟。

清波不再固定补玩家18和心核12；生命扩容只补增加的耐久上限。工具3仍可抢修心核，但不顺带治疗玩家。Q需玩家主动部署或指挥；开局免疫灯塔已经装备，基础驻防无需免疫成长Ⅲ阶。健康节点均可驻防，军团具有生命、真实移动和咬击；失地后继续守原点，不代替玩家净化。

第3波按前两波实际弹丸/范围伤害决定晶壳或裂殖，并生成两处238耐久源。双源清除取消尚未出生的本波队列，已入场及预约裂殖仍须处理，领取本波强化后进入680耐久母巢战。母巢继承已见单一特性，使用现有核膜、前摇和反制，不套用隐藏战役的复测流程。

首次净化每区100分、摧毁每源500分、救援成功1000分；源所在区首次净化与毁源两项奖励可以同时获得。重复夺回不刷奖励，裂殖小体不额外产分。持久源和母巢独立于清波义务，所有活体和预约人口共用48上限。

## 救援与守卫记录

救援成功先保存不可变快照，再暂停展示“结束救援 / 继续守卫 / 查看配装”。继续守卫沿用同run的装备、成长、军团与生命，从下一波恢复，不重新发救援奖励。守卫失守不撤销原成功，整局只计一次。

当前战绩键为`viral-invasion:2:territory-profile`，旧`viral-invasion:1:endless-profile`原样保留且不混比。存储失败保留内存快照并提示，可重试。这里只保存成绩，不支持刷新后恢复整张战场。
