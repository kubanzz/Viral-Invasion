# Viral Invasion：独立新项目验收项追踪矩阵（v1.3）

> 本表保留2026-10-26的G0阶段快照；后续G1–G4逐项状态和版本证据由 [主测试矩阵](ViralInvasion_TestMatrix.md) 维护，不能把本表旧“未执行”解读为当前尚无实现。原始规格的17个模块、88项AC、12条RUN和12项VIS保持不变，原件在DesignDoc_v1.3。v0.6.0试玩改造另见 [反馈处理](ViralInvasion_PlaytestFeedback_v0.6.0.md)，其证据不与旧版本混算。

## 填写规范

- 状态限：`未执行`、`通过`、`失败`、`阻塞`、`不适用（须给理由）`。
- 证据写真实 Git 提交、运行命令、测试产物路径、截图/视频及执行者和日期；不要填旧“心脏巡游”的验收证据。
- `M00–M02` 和 `RUN-01` 是 G0 的交付门槛；后续模块依次由 G1–G4 实现。G0 可对尚未引入病毒的后续规则使用训练靶/测试实体证明基础机制。
- 浏览器/自动化结果与真人试玩分开填；只有自动化覆盖不能证明趣味性。
- `VIS-*` 是跨模块视觉与镜头验收，**必须用真实游戏运行画面**记录；不能用参考截图、AI 概念图冒充运行结果。
