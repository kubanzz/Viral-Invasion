## 节奏M13-01的处理

1. 保留当前快速确定性路线作为回归基线；先量实际新玩家首局的墙钟、游戏计时、暂停与每段目标耗时，区分迷路、读面板、有效决策和重复劳动。
2. 若实际行动量过少，优先增加可理解的目标变化、器官取舍与环境互动；每项扩展都须让玩家能看到行动后果。不得以强制等待、单纯堆HP或重复杂务填满10–15分钟。
3. 若首玩过长来自不明目标或重复操作，先改善目标/反馈并裁掉无意义步骤；以新玩家真实记录复验。
4. 修改战斗、目标、成长或旅行参数后重跑完整模拟和对应浏览器路线。未取得时长证据或未达原标准前，继续明确标注M13-01未通过。
