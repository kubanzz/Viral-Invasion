# 武器战技 v0.16.0

2026-11-05。心脏挑战采用独立普攻与每把武器的三个固定战技；修复即全开，营地单武器换装。未增加双武器、蓝量或技能研发。

## 操作

左键或手机射击盘持续普攻；123直接施放武器技能；F/左侧独立净化按钮处理组织与心核；Q脚下驻军；Space只冲刺；B建设；R抗体（手机在战术菜单）；E仅在已建弹射荚附近合法交互。旧战役、旧训练保留原工具规则。

稳流为集中连针（6秒）、震荡抗体（10秒）、稳流超载（18秒）；贯脉为贯脉重针（7秒）、束脉爆囊（10秒）、裂脉扇刃（16秒）。普攻34/28和基础单体/双体贯穿保留。连针逐针追瞄，重针准备0.35秒后自动沿初始方向从实际位置发射；爆囊分别击退/持续牵引；扇刃同一施放对每体最多一次伤害。

移动、普攻和技能瞄准拥有独立输入。普通施法结束后仍按住的射击自动恢复；暂停、详情、失焦与旋转冻结模拟并清除输入，需要重新按下。成功受理才消耗冷却，动作中不排队，冲刺/弹射取消未发射部分但不退款。

## 兼容与成长

武器、技能、伤害类别与按键槽分离。普通针弹保留晶壳正面减伤，重针/爆囊/扇刃沿用重攻击反制；仍经过源膜、祭团护膜和Boss核膜。F有独立修复冷却。技能不会自动净化组织，不增强军团或建筑。

力量作用武器伤害一次；永久装备仍封顶18%。多重/贯穿/急速仅普攻，新星与余震仅武器2，余震不重复位移也不递归。超载在满急速仍有效。所有在途射弹、连针及余震预约合计不超过192，不计入敌方48人口。

七区、v0.15.4源膜供能、Boss、最后净化及胜负规则保持。战绩v7独立存储，v6及更早记录只读展示；营地装备、材料、蓝图及领取去重保留，旧成功只迁移营地和基础蓝图，不补随机奖励。不恢复刷新前战场。
