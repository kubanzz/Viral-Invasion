## 当前挑战的胜负与区域争夺

净化同线生命泉与前线 → 切断供能，解除源膜 → 拆除双源 → 母巢决战 → 清理残敌和剩余感染，完成心脏救援。玩家或心核归零即失败，没有固定五波或八波通关要求。

心核与两处生命泉初始健康，两处前线与源区初始感染。侵染者沿路线占前线，普通病毒实际接触泉实体也会污染，每只每秒2.5个百分点、最多计3只，与专职10取大值。有预警的四人进攻队保持，前线失守后抢泉者会主动争夺生命泉。健康泉150内每秒治疗3耐久，连续1秒无新的传染接触或攻击才清感染；前线不治疗。身体触碰及病毒攻击均造成8秒感染，每秒扣1，刷新不叠层、不延迟下一跳。黏液法师的圈可躲，筑巢者和有六只库存的小巢可提前拆；耗尽小巢仍需清理，地图以巢标记提示。

免疫灯塔开局可用且不可替换。站到健康节点150内点驻防，新军团在脚下出现；满两团调最近一团真实行军，不恢复伤势。小队拦截侵染者但不能代替净化。源基础1200耐久，同线生命泉与前线健康即可解膜。军团等级、是否驻防及是否命中敌人不影响源膜；节点失守才复膜，保留已造成伤害。源毁取消该侧未出生进攻和孵化，已有敌人仍需处理。

母巢死亡不会自动清场或洗白区域，必要时继续最后净化。七区全健康、侵染进度为零时记录全域健康累计与最长连续时长，重新受侵染会暂停累计。救援胜利立即保存并暂停，可结束或继续守卫。继续守卫保留本局成长、耐久和军团，后续失守不会撤销救援成功。新版区域战绩与旧版无尽战绩分开；这里只保存成绩，不支持刷新后恢复战场。

## 病毒进化与战斗

“开始挑战”的前两波记录你的实际攻击：以弹丸为主会出现晶壳，以炮弹或斩击为主会出现裂殖；混合打法或有效观测不足时，本局确定一种变异。第3/4/5波分别混入6/8/8只普通特化体，第5波精英继承同一特性。其余普通体仍按原节奏供你清群，不会全部额外加血。

晶壳正面挡普通针弹，使用武器2爆囊、贯脉重针/扇刃或侧绕突破；裂殖小体使用爆囊或扇刃收尾。第3波顶部显示进化与反制；救援期间保留已见特性，母巢继承其中一种。公告不暂停、不遮挡操控区；详情可查看前两波实际伤害比例。

双源击破会取消当前波尚未出生的队列；活体与预约裂殖仍计入清波义务。所有敌方活体和预约人口共用48上限，感染源与母巢不阻挡普通清波。每波选择强化，每五波仍有突破与额外协议。

该命令先校验并构建当前源码，再生成 `releases/Viral-Invasion-Mobile.html` 与 `releases/Viral-Invasion-Mobile.zip`。ZIP 只包含同一份 HTML 和本说明。校验记录位于 `artifacts/mobile-release/package-report.json`；构建来源清单保留在本机，不放入手机包。

已完成当前构建时，可单独运行 `node scripts/package-mobile.mjs`。源码、打包脚本、本文档或构建输出在构建后发生变化，会拒绝打包，需先重新构建。`dist/index.html` 继续保留桌面网页入口。

运行手机浏览器回归：`npm run test:e2e:mobile`。首次运行 WebKit 项目时，先使用 `npx playwright install webkit` 将对应浏览器安装到 `.tools/playwright-browsers`（设置 `PLAYWRIGHT_BROWSERS_PATH` 后执行）；测试配置默认读取这个项目内缓存。当前轮盘结果位于 `artifacts/mobile-moba-20261101/`，旧布局与首次适配证据分别保留在 `artifacts/mobile-redesign-20261101/`、`artifacts/mobile-20261031/`。Chromium 的多指检查通过 CDP 注入真实触点；桌面 WebKit 的单指轮盘以鼠标路径验证，多指硬件行为留给真机验收。旧版III导流的隔离浏览器机制用例不等同于自然晋级过程或最终手机包的真机记录。
