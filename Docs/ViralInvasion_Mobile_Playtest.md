# 病毒入侵 · iPhone 本地文件试玩

**触屏 v3 待验证候选**：已重新设计轮盘交互，仍需在真实 iPhone 的 Sitecase 中复测。

本次交付是网页游戏文件，不是 iOS 安装包。触屏横屏版在 Windows 上构建，不需要 Mac、苹果开发者账号、同一个 Wi-Fi 或公网服务器。

## 收到文件后这样打开

1. 在 iPhone 安装 **HTML 查看器 - Sitecase**，要求 **iOS 17.6 或更新版本**。中国区链接：<https://apps.apple.com/cn/app/html-viewer-sitecase/id6762896369>。
2. 接收 `Viral-Invasion-Mobile.html`，保存到“文件”App。若收到 ZIP，先在“文件”中解压，再找到其中这个 HTML。
3. 在“文件”中长按 HTML，使用共享菜单导入 Sitecase；也可打开 Sitecase，选择“打开 HTML 文件”，再选中它。无需导入整个网站文件夹。
4. 将手机转为横屏。可在 Sitecase 的显示设置中选择“专注模式”，隐藏查看器工具栏；退出专注模式的方法以 App 当前提示为准。
5. 点击游戏开始按钮后游玩。游戏代码、界面和素材全部位于 HTML 内，接收文件并安装运行工具后，可关闭网络进行试玩。

手机依然需要一个能执行 JavaScript 的网页运行工具。系统“文件”或聊天 App 的快速预览不能等同完整运行环境；仅在它们的预览中看到页面，不代表游戏已经正常启动。

Sitecase 官方声明支持本地文件、CSS、JavaScript 和离线游戏。单个 HTML 可使用免费功能；整个项目文件夹的导入属于 Pro，本发行物不要求该功能。功能或可用地区以实际商店页面为准。官方介绍：<https://sitecase.io/>。

## 手机操作与布局

普通网页入口与单文件 HTML 均按浏览器可用尺寸实时切换：宽度不超过 1024px，或高度不超过 600px 时使用移动布局；在鼠标电脑上放大窗口后恢复桌面布局。真实粗指针触屏设备保留触控布局，也可用 `?mobile=1` 强制预览触控界面。布局切换会暂停战斗、清空已按住的输入，保留同一局进度；点击继续后重新按下控制键。竖向窄窗口仍遵循横屏战斗提示。

- 当前使用 MOBA 轮盘布局：左下移动；右下 88px 主攻击盘，裂解、修复、免疫三个 56px 技能沿弧形分布；冲刺、交互和抗体为较小的辅助圆键。手机不再使用“切工具后点施放”的控制条。
- 主攻击盘按住即持续净化，拖动调整方向；点战场后再轻点主攻击盘，也能沿选定落点攻击。
- 技能按下只预览方向、范围和落点，拖动瞄准，松手才释放。拖到 × 区域并松手可取消；取消预览不消耗技能或资源。点战场保留精确落点后轻点技能，可精准修复组织、使用治疗点或指挥军团。
- 在大器官中预览远处技能时，镜头会平滑移动并适度拉远，让角色和落点避开操作区；结束预览后恢复跟随。
- 解锁裂解导流后：先用裂解轮盘选点，再拖入 ✓ 导流确认圈，技能才正式施放；保持同一触点拖动引导，松手引爆。确认导流后的冷却与位移限制沿用原规则，结束导流不会退还已施放的技能。
- 左上小地图实时显示战场，点击可打开完整战况。生命与器官状态使用短条，技能以冷却环和数字反馈；新操作反馈最多显示 4 秒，详细目标与反制说明放在战况。验收包含标题栏压缩后的 280/320px 内容高度与刘海安全区。
- 工具射程、组织遮挡、治疗点距离和冷却继续遵循原规则；靠近装置使用交互键。
- 暂停、查看详情、选择升级时会停止战斗输入。切到其他 App 或旋转方向后，按游戏提示继续，重新触摸摇杆。
- 战斗完整布局按横屏设计；竖屏可浏览菜单，进行战斗前需横屏。

## 离线与存档边界

游戏沿用本机存档，不能自动与电脑、Safari、另一个查看器或另一份导入文件同步。运行工具不允许持久化存储时，游戏会降级为会话暂存并提示。重命名、重新导入文件、删除查看器数据或卸载 App，都可能影响存档；更新前保留原文件和原条目，不承诺跨导入版本自动迁移，也不将长期存档作为本轮真机已验证结论。

## 验证范围

发行脚本检查构建来源与输出哈希，把游戏脚本安全内联到单个 HTML，并用独立 ZIP 解码器逐文件比对。桌面浏览器与 WebKit 的自动化检查，只覆盖各自实际报告的项目。

**真实 iPhone + Sitecase 仍需验收**：Phaser/WebGL 初始化、约 9 MB 级单文件加载、多点触控、音频、刘海安全区、后台恢复、存档重启与实际帧率。Sitecase 官方没有为此游戏给出 WebGL 或性能保证；构建完成、文件通过校验、桌面触屏仿真通过，均不能替代手机实测。

建议手机依次试：断网打开 → 开始战役 → 同时移动和按住主攻击 → 拖动修复后松手 → 拖动裂解到 × 取消 → 指挥军团 → 进入升级选择并继续 → 暂停/恢复 → 切后台返回 → 重开游戏查看档案。记录手机型号、iOS 与 Sitecase 版本、操作方式和任何问题。

## 从工作区重新打包

```sh
npm run package:mobile
```

该命令先校验并构建当前源码，再生成 `releases/Viral-Invasion-Mobile.html` 与 `releases/Viral-Invasion-Mobile.zip`。ZIP 只包含同一份 HTML 和本说明。校验记录位于 `artifacts/mobile-release/package-report.json`；构建来源清单保留在本机，不放入手机包。

已完成当前构建时，可单独运行 `node scripts/package-mobile.mjs`。源码、打包脚本、本文档或构建输出在构建后发生变化，会拒绝打包，需先重新构建。`dist/index.html` 继续保留桌面网页入口。

运行手机浏览器回归：`npm run test:e2e:mobile`。首次运行 WebKit 项目时，先使用 `npx playwright install webkit` 将对应浏览器安装到 `.tools/playwright-browsers`（设置 `PLAYWRIGHT_BROWSERS_PATH` 后执行）；测试配置默认读取这个项目内缓存。当前轮盘结果位于 `artifacts/mobile-moba-20261101/`，旧布局与首次适配证据分别保留在 `artifacts/mobile-redesign-20261101/`、`artifacts/mobile-20261031/`。Chromium 的多指检查通过 CDP 注入真实触点；桌面 WebKit 的单指轮盘以鼠标路径验证，多指硬件行为留给真机验收。III 导流的隔离浏览器机制用例不等同于自然晋级过程或最终手机包的真机记录。
