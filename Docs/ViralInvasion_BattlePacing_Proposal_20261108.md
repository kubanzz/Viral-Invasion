# 关卡进度与清源后攻防 · 2026-11-08

本文保留最初讨论与首轮修复的历史状态。后续自主验收发现的问题已进入[微区攻防v0.25.0](ViralInvasion_BattlePacing_v0.25.0.md)修复：有限携疫队、15秒保护、阶段路径和投放加速以该文档为准。

## 本轮范围

用户反馈：Boss 战无法持续积累大招；不清楚什么时候能通关；清除感染源后，站在稳态锚旁射击成为主要玩法。

本轮直接修复 Boss 充能与现有进度提示。本文的携疫者、净化保护和 Boss 感染事件是讨论提案，尚未加入玩法。数值均为原型起点，需要实玩校准。

## 当前机制与问题

- 三个正式任务分别有 3、4、5 波，基础敌群预算为 240、400、600。第三关完成五波、摧毁双源并恢复节点后进入母巢战，击败母巢、清理残敌与感染后成功。
- 源毁后，有限基础敌群仍继续出生，但该线未来的专职侵染小队会取消。已经出生的侵染者仍会争点。
- 普通病毒贴近营养凝露仍可污染；部分普通体会袭泉，但主动袭泉要求同线前线已经失守。清源前须先恢复前线，清源后又缺少新的占线角色，这条威胁链经常中断。
- 因而问题不是病毒完全丧失感染能力，而是后续敌群很少再主动争夺外圈，玩家缺少离开稳态锚的理由。
- 旧界面仅显示当前波数，并可能沿用“等待第3波感染源苏醒”。正式任务第1波已经激活源，且清源不等于完成全部敌群，这会直接误导玩家对结束时间的判断。

## 1. Boss 战：有效伤害推动大招循环

建议本轮规则：母巢实际损失最大总血量的 1%，增加 2 点能量，满条仍为 100。

- 计算三条血合计的最大血量，避免每条血重复计算。空能量入场、持续造成普通战斗伤害时，约在半血可得到一次大招。
- 使用最终实际扣除的 HP；护膜、转阶段、阶段血量下限挡住的部分不充能。
- 大招伤害及带有大招来源的后续伤害不回充；母巢死亡不再额外叠加结构击杀奖励。其他敌人的击杀充能保留。
- 沿用当前玩家与军团共享战斗成果的归属；不额外增加受伤充能和站场自动充能。
- 每损失 1% 仅加 1 点会让空条入场者直到母巢死亡才满条，难以改善本次 Boss 战，因此不采用该起点。

## 2. 通关预期：阶段与真实余量优先

不建议给现有清剿任务直接加超时失败倒计时。清剿的结束由敌群、源与母巢等目标决定，固定时间不能准确表示还差多少。

推荐在后续界面原型中加入简洁的任务路径：

`清剿与清源 → 母巢决战 → 最后净化 → 通关`

前两关省略母巢阶段。清剿和清源可以并行完成，不能用阶段文字误导为必须按顺序操作，也不将波数机械换算成总完成百分比。

常驻信息保留当前阶段、一个行动目标和真实波次。例如：

- `清剿与清源 · 第3/5波`；行动目标 `截杀北线携疫者`。
- 双源提前清除时明确 `感染源已清 · 完成剩余波次后迎战母巢`。
- 母巢战沿用三条真实血条；在阶段说明中提前告知击败后还需清理残敌与感染。
- “本波剩余”应明确包含已在场、待出生及待分裂单位，避免玩家以为这些就是全关最后敌人。
- 短倒计时用于真实事件：侵染者接近、污染完成、净化动作、Boss 攻击；关卡用时可在结算记录。

若以后增加“坚持90秒等待撤离”的独立生存关，才使用全局倒计时，并明确归零后的停止增援与撤离条件。

## 3. 清源后：有限携疫者制造可处理的争点

保留毁源的永久成果：源不复活，该源的生产与专属增援停止。剩余病毒携带的感染能力继续存在，来自地图外的有限敌群仍可争点。

### 最小原型

1. 从清源后的既定波次预算中替换一小队：1名携疫者、2名普通护卫。不额外增加敌群总量或人口上限。
2. 第一轮试调每个后续波次最多1队，同一时刻最多1个外圈主争点，北南轮替。携疫者死亡后不额外补生。
3. 携疫者有独立识别标记，实际移动到节点，持续播种后才失守。玩家可途中拦截，漏掉后再净化；不允许节点随机凭空变脏。
4. 初始沿用约10秒占点与3秒净化，试验4—6秒来袭方向预警。必须测量移动路线：从合理战斗位置出发，预警、敌人行军和占点的总窗口应覆盖回防时间并留操作余量，不能仅靠固定秒数判断公平。
5. 净化完成后试验15秒保护期，并保留离开范围时已经获得的净化进度，减少刚净化、刚离开就被同点重染的重复劳动。
6. 优先沿用健康凝露的治疗收益与Q驻军。确保驻军能争取玩家离场时间，再根据实测决定是否额外添加净化补给奖励，首轮不叠加新的成长系统。

### 玩家应有的选择

- 提前离开锚点截杀携疫者，用移动换取低成本防守。
- 留军团牵制锚点附近敌群，自己去净化外圈。
- 外圈感染尚可控时，先清核心附近危险，再处理失地；失守后病毒仍须真实推进、攻击核心，不通过离屏规则直接扣核心血。

持续争点仍需有高低节奏。一轮回防结束后，不能立即安排另一端同等级危机，让玩家有时间回血、输出和调整驻军。

### Boss 与收尾

Boss 是战斗高潮，不宜持续要求玩家横穿全图。后续可单独原型化每次换血条的一次近场感染事件，整场最多两次，与大范围攻击错开。目标必须处于决战可回防范围；若现有节点不满足距离条件，先不加入这项机制。

Boss 死亡后停止创建新的感染任务，已经出生的携疫者仍是有限残敌；清理后不会再产生新感染。最后净化只处理实际失地，满足条件即结束，不追加固定等待。前两关则在有限波次出生预算耗尽后进入同样的收束。

## 验收重点

- 玩家能否说清“现在做什么、做完后还差什么”，而不把当前波余敌当作全关余敌。
- 清源后是否会主动离开稳态锚，以及离开是为了拦截、净化还是单纯寻找残敌。
- 回防成功率、节点刚恢复就再失守的次数、没有战斗的往返时间、军团独立拖延效果。
- 按初始武器和传说武器分别观察尾段时长，防止高伤害配装依然长时间等待既定波次刷完。
- 同步记录 Boss 攻击压力与感染事件，避免核心危急、远端失守、Boss大招同时强迫玩家处理。
- 充分说明哪些数值经真人试玩验证；脚本通关与自动战斗时长仅用于机制和边界检查。

参考：Valve 的 [GDC2009《Replayable Cooperative Game Design: Left 4 Dead》](https://cdn.akamai.steamstatic.com/apps/valve/2009/GDC2009_ReplayableCooperativeGameDesign_Left4Dead.pdf) 第35—38页讨论战斗强度的峰谷：持续相同压力会疲劳，长期无事会无聊；高压后应让已有战斗自然结束，再留出喘息。这里借鉴节奏原则，具体携疫者方案为本项目设计假设。
