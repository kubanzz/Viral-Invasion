# 心脏远征 v0.15.0

本轮已完成守线解锁蓝图、真实军团建设、祭团追踪弹、心脏二相Boss、战利品带回和安全营地成长。2026-11-04 冻结的 candidate-3 已完成桌面与触控浏览器真实输入闭环，发布版本为 v0.15.0，战绩规则为第6版。

## 战场

开局没有弹射建筑。首次完整击退一线进攻保底永久解锁基础弹射荚。B／手机战术菜单选择蓝图，点击健康地面锁定位置，再确认施工。选址在玩家180内，底座40，与关键节点100距离；至少两名存活军团成员抵达70内，累计施工6秒。Q改派暂停工地，不覆盖玩家新命令。每局2份工程补给，双源各首次摧毁加1、上限4。替换建筑共享装填，不额外补血补兵。

基础弹射荚射程1100、范围240、伤害260、装填24秒；速装荚800／200／220／16秒。110范围内且已完工、健康、装填完成才能按E预览；远处E无效，越界取消，按住再靠近不会激活。0.75秒把玩家送到合法落点。

第3波有限祭团由408耐久母体与三名204耐久祭司组成，4秒预警、四体原子预约。三名祭司全部击杀才能解除母体护膜。追踪弹35伤、68耐久、速度260、100度/秒转向、6秒寿命，含充能全场上限2；可用射击、能量炮、剑气、冲刺斩和弹射冲击拦截，不给击杀或分数。法师死亡停止后续生产，已经发出的炮弹保留；清波清除孤儿弹。

黏液法师136耐久，筑巢者204，小巢238。小巢建成预警1秒后首孵，再每4秒两只、总共六只；前线失守时幼体分工追击与抢泉。主Boss1800耐久，半血在当前动作结束后排一次1.2秒预警、有安全缺口的28伤扩张脉冲。旧战役不采用此升级。

## 带回与营地

Boss死亡形成稳定战利品包，拾取仅暂存。两线历史接防、七区健康、残敌和预约清空后胜利，才原子带回并解锁营地。此前死亡、退出或刷新失去未带回奖励，永久收藏不丢失。

首通固定破损贯脉针枪、速装蓝图、40生质；品质紫90%／金10%。复刷蓝60%／紫30%／金10%，已有蓝图转5生质。按枪型收藏最高已修复与最高待修复品质，重复蓝／紫／金转8／12／20生质，强化绑定枪型保留。

基础稳流针枪34伤；贯脉28伤、基础总命中两体。品质白／蓝／紫／金增加0／3／6／9%，强化最多三级、每级3%，永久增幅封顶18%，然后叠局内强化。不会放大军团、建筑或协议伤害。

安全营地复用健康心脏，含仓库、锻造、补给与出击。修复10生质，三级强化8／12／16；额外抗体每支5，下次出击最多额外2支，合计最多4。出击冻结配装，备货一次转入新run；旧战绩和营地奖励分别保存。规则6战绩不混比规则5，旧成功只迁移营地与基础蓝图。

## 本轮修正

军团交接保留至少两名真实细胞抵达前线的要求，完成验证依据同团真实命中侵染者、清除进攻与预约、节点健康及驻军存活。修正军团在防区边界真实拦截成功却被额外距离门槛否决的问题，不补血、不复活，也不跳过到位要求。

祭团预警的四个实际阵位现在会为普通出生、进攻队和其他智能病毒保留空间，避免同一时刻的普通出生挤入阵位而令祭团取消。玩家实际净化阵位仍会正常取消遭遇，人口上限、派兵节奏和有限配额保持原规则。

补齐军团工人拥挤时的合法抵达路径、手机移动和开火时第三指打开施工面板、稳定的选址确认，以及营地暂停／失焦／旋转后明确打开概览的处理。进入营地会清理旧战斗反馈计时。
