# v0.7.7：连续进化挑战技术候选

本轮依据用户对地图、进化感和攻击单调的反馈，以及最新“重复可玩、持续升级打病毒、优先爽快感，不关注美术资产”的目标实施。遵循 `DesignDoc_v1.3/ViralInvasion_GDD_v1.3.md` §1–2 的双向进化与短循环、§4 的可识别/可反制变异、§5 的抗体联动、§9 的敌群预算。文档原 MVP 不做无尽的范围，按用户最新持续成长目标扩展为独立模式。

## 可试玩变化

- 主菜单新增“连续进化挑战”。使用 2400×1500 心脏战场、跟随镜头及独立导航图，中央组织与阀门分开布置。敌群从玩家周围多个方向分批接敌；不把全部设施和敌人挤在开局区域。
- 每次真实清场获得一次三选一战斗进化。候选来自 9 类：扇射、贯穿、裂解新星、冲刺斩、扫描爆发、免疫军团、急速净化、生命扩容、净化突破。首次保证扇射与免疫强化可选。有限能力满级后退出候选，保留持续有效强化。
- 每项升级接入真实伤害与碰撞：多束射线/逐体穿透、实际范围与冷却、沿实际冲刺段命中、Q 周围爆发、细胞实伤/存续/独立召集冷却。卡片与 HUD 显示具体前后变化。
- 初始预装免疫灯塔，Q 部署 3 只临时免疫细胞。细胞移动、绕障、接触咬击；可与显影追踪、连锁净化等原协议协同。协议经验作为补充成长，波次成长不受原 5 个经验阈值限制。
- 每 5 波精英来袭，8 秒预警。晶壳、裂殖、潜伏按编队轮换，后段混编；普通体维持 68 耐久，主要通过数量、速度、攻击节奏与职责增加压力。精英有 1.1 秒固定落点爆破，范围控场可打断，普通承诺攻击最多同时 3 个。
- 下一波必须等待当前敌群、未出生预算及已承诺裂殖子代处理完毕。清波选择期间暂停，确认后补给并继续。暂停页可主动撤离；死亡或撤离均独立记录最高完全清除波次、得分与连击。同种子重新构筑，局内属性归零。
- 混战中附带条件玩家轮廓与真实脚底定位；保持正常 Y 排序，不修改战斗状态。未接入或修改用户提供的美术资产。
