# Viral Invasion v0.7.5：战场信息排布与危机可读性

这是三点试玩反馈改造后的可玩技术候选。地图、进化与协同玩法继承 v0.7.4；本轮修复实际画面中的标签叠合、HUD占区和危机信号被覆盖问题。`DesignDoc_v1.3/` 原文未修改。

## 玩家可见的变化

- 组织、敌人血量、破绽、研究台、阀门、气道、复测终端和免疫小队使用同一套屏幕文字排布，按实测字体尺寸避让其他标签和可见HUD。保留真实锚点；移位标注用短引线指向所属对象。
- 灯塔身份、当前小队数量和剩余时间合成一条说明；只计当前灯塔、当前器官内尚未过期的真实细胞。细胞身体、吞噬姿态、寿命条和已发生咬击的标记保留，并为文字预留保护区域。
- 左右HUD缩小，空协议槽同行显示。当前器官低完整度提示“需抢修”，离场器官提示“需回救”，仍显示残留感染源和实际离场损伤。玩家经过时，配装面板和小地图的可选图像短暂淡化；耐久、组织、感染、全身稳定、器官风险和母巢反制继续显示。
- 短窗口只压缩常规说明，感染失控倒计时始终保留。危机源到组织的方向连线、箭头、轮廓和真实倒数在前景及效果之后绘制，两档均保留。
- 远处标签会省略；有限视口无解时，必要标签会保留并记录冲突。当前实现不承诺任何极端组合下都零叠合。

## 玩法体验入口

正式心脏和肺部均为2400×1500，设施分区，跟随镜头和小地图支持路线选择。四种协议、三个槽位、每次三选一；已有协议可升至Ⅰ/Ⅱ/Ⅲ阶，卡片展示收益、代价和使用方式。Q诊断后可在研究台定向研究。

未装备灯塔时Q召一只短时侦巡；装备后为三只会移动、绕障和接触咬击的免疫细胞。显影可引导优先围猎，共振配合连锁可增加真实跳数，进阶连锁有折射。真实接受的伤害与命中记录沿用 v0.7.4 修复，没有用计划伤害冒充收益。

## 继续保留的验收边界

五位首玩者标准盲测仍为0/5；用户先前反馈单独归档，不能换算为五人通过。首次三分钟理解、目标玩家10–15分钟正常整局节奏、成长体感、主动复玩及孵化价值需真实观察。

真实浏览器缩放、原生OS失焦/最小化、完整内存稳定及部分决定性混战视觉子项仍开放。本轮浏览器resize/DPR与合成失焦测试分别保留其技术范围。v0.7.4 的M16-04整体仍为partial；旧closedSubclauses误含内存子句标题，本轮只认定原设备帧预算/无致命错误子句已过，内存子句继续开放。
