# v0.25.0 全部战斗特效改造

2026-11-08。范围为四武器普攻、1234、军团、敌人与母巢、受击击杀、治疗净化与战斗状态；安全试枪共用新版特效。营地环境、抽卡及开场演出沿用已有表现。伤害、冷却、判定、永久存档与操作未作玩法改动。

## 运行与时序

- 采用 Phaser 4.2.1 原生 ParticleEmitter、Sprite、Rope、纹理和混合模式；特效配方只读取真实模拟回执。装饰运行层不参与伤害，也没有独立浏览器循环。
- 总线回执与补充日志读取去重，等待回执对应的显示时间才播放；使用插值 `visualTime`。原生粒子移出自动 UpdateList 后由宿主推进，序列帧由视觉年龄选帧，避免依赖墙钟的Tween在暂停后补跑。
- 支持安全试枪合法的小数tick回执。试枪用独立透明Phaser宿主、同一配方和烘焙资源，关闭时释放；原有靶场与操作保持独立于正式存档。
- 地面雷痕/范围与角色层分离，接触点按实体深度显示；竖直雷柱保持独立高度。规则危险几何、准星、HUD保留可读层。
- 命中、特化命中回执归并为唯一接触反馈；持续电流及治疗按目标短时合并。原生对象有数量预算和有界回收池，低特效减少粒子及残影，减少动态偏好关闭强动态。

## 表现变化

- 三连斩保留即时接触，增加肩脊与有限臀胯随动、过冲和收势；刀光沿挥击方向扫出。原生Rope逐节点读取实际障碍裁剪，负责主刀光，避免整张弧形贴图穿墙。
- 雷电采用短时保持、突变和有限分叉，区分主弧与支弧；感电纹移至角色轮廓附近，数字做有限避让。万雷归一分批收束，终结主雷柱与接地余波分层。
- 针枪短促刺入、刃弓出射与回收、军团武器轨迹均共用新的轻击/重击/击杀反馈。曜卫残像只采样真实残像实体，最多8条、每条4点，不创建假单位。
- 敌人蓄势、落地、冲锋、母巢阶段变化，以及实际治疗、净化、感染开始与清除接入统一事件配方。危险边界仍由规则几何负责。
- 挥刀与接触音分开调节，关键清除与终结重音独立限流，避免连续普通命中吞掉重音。

## Effekseer素材的实际制作方式

官方Effekseer 1.80.8便携版已下载并核对官方SHA256。7个原创节点配方经实际编辑器工具加载迁移并保存为现代 `.efkefc`，原始纹理为原创绘制的透明笔触与蒙版，没有将静态图片声称为逐帧动画。

生产序列由官方EffekseerForWebGL 1.80.8 WASM加载同一真实工程，固定随机种子、60Hz模拟，每2帧采样为30FPS透明PNG。该运行库只用于制作端，未加入游戏发行包。另在桌面编辑器中实际打开 `hit-heavy.efkefc`，使用Recorder导出18帧透明图集作为独立制作验证；来源记录明确区分这两条路径。

最终7组共92帧，组别为 `hit-light`、`hit-heavy`、`kill`、`cleanse`、`slash`、`thunder-pillar`、`ground-ring`。源工程、纹理、录制设置、各帧分析、图集注册、工具与原稿哈希保存在 `asserts/ViralInvasion_CombatVfx_v1/`。终结雷柱12帧、0.4秒，独立竖高168×360。

各序列使用统一的仿射注册、画布和接触锚点，裁去首尾全透明帧；裁帧来源偏移保留在交付记录，真实接触反馈直接从首个可见帧开始。新播放器不受旧角色版本开关影响。

`slash`烘焙组作为原始素材保留；当前正式主刀光使用有真实裁剪与方向演化的Rope，不再叠一张完整弧形Sprite。其他序列由原生Sprite按视觉时钟播放。

## 资源与离线

用户选择的嵌入美术JSON上限为32MiB，即33,554,432字节；该数值不代表GPU纹理或整份手机HTML大小。当前验证入口同步预算，旧验收报告保持其原始版本含义。

新组单独紧凑装箱，单序列不跨页。源工程、录制配置及交付清单纳入发行输入哈希；运行时所有资源仍内嵌经典IIFE和data URI，无额外网络素材、WASM加载或本地服务器要求。

最终美术JSON为22,044,797字节，新增7页PNG共1,037,846字节；新增图集解码RGBA为17,555,824字节。32MiB限制针对嵌入美术JSON，不能当作GPU占用或整个手机HTML的上限。最终交付版本为v0.25.1，包含同工作区同期完成的现有开场影片；本任务没有重做开场。
