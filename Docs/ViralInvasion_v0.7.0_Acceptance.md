## 实际新增

- 正式战役使用版本化 `campaign-1`，G1/G2 快速夹具明确为 `fixture-1`。浏览器和完整会话模拟使用同一正式配置。
- 首次未确认的病例固定晶壳，完整预警至少8秒。开局2名普通体，首精英解决前最多4名普通体、guided累计增援预算2；精英仍为238HP，放在阀门附近。基础1绕后，或真实E冲流后基础1命中，才记录反制掌握；协议伤害、普通正面射击和单纯击杀不会冒充掌握。
- 五阶段通过真实目标推进：首次清源 → 首次精英清除 → 实际迁移抉择／拦截结果 → 新组织危机源清除 → 双特性母巢与主动复测。后两阶段仍检查原主要感染、两名精英、所有激活器官≥50%、感染<35%等条件。
- 新阶段Ⅳ传播支点有独立实体、源到组织连线与倒数。68HP；每8活跃秒冲击6完整度，最多三次、一次至多两名有限守卫，没有普通增殖或传播通路。心脏E对准支点打断，肺部关闭气道暂停；基础工具也可直接清源。离场保留余量，满24单位时等真正出生后才开始充能。
- 清源可通过连锁打击附近守卫；异常显影＋灯塔可由真实移动的三只细胞接触围猎。沿用四协议、三槽、Ⅰ–Ⅲ阶、击退打断与实际触发反馈。
- 引导可从战场或手册跳过。版本化保存“跳过”和“实际完成”，独立于迁移指引；跳过无奖励、不清怪、不推进时钟。相同病例重试保留变体；新病例读取已确认状态，最近记录和最佳记录保留配置及显式trait覆盖。

本轮新增遭遇是首反制和有限支点；迁移与母巢继续复用原机制，不将五个阶段名称当作五个新关卡。未增加最低胜利时钟、HP填充或纯等待目标。
