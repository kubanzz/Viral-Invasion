# Viral Invasion：阶段遭遇与首次反制引导计划

日期：2026-10-27 · 状态：v0.7.0 已实施首次反制与五阶段目标，技术候选已验证；首玩体验仍待真人验收。

UI／音频生命周期补丁已由v0.6.3交付；立体遮挡修复见[v0.6.4验收](ViralInvasion_v0.6.4_Acceptance.md)。本文件保留实施约束，实际范围与证据以[v0.7.0验收](ViralInvasion_v0.7.0_Acceptance.md)为准。原始 `DesignDoc_v1.3/` 保持不变。依据为 GDD §1.3、§2、§8、§10.4、§11.3，以及 AC-M09-05、AC-M13-01、AC-M14-02。

## 1. 目标与边界

- 入门完整局以 10–15 分钟为调参目标；GDD §1.3／§8 同时允许高手通过完成目标加速，不能设置最低通关时钟。
- 形成开局、变异应对、器官危机、联动反击、母巢决战五个具有不同决策的阶段；60–120 秒战术循环至少提供两次改变行动优先级的局势。
- 每项新增内容按 GDD 第355行填写：**新增可观察状态 → 新的决策 → 可利用的环境交互 → 反制或弱点 → 与至少一个已有协议的联动**。缺一项则退回设计，不以更多目标数量代替。
- 不靠提高感染源／母巢 HP、拉长步行距离、纯等待、不可跳过说明或无限刷怪补局长；不增加新器官、工具快捷键或独立模式入口。
- 随机协议提供不同解法与效率，不能成为通关钥匙；四协议、三槽、两主特性、活动单位与事件预算继续受现有配置约束。

## 2. 配置与运行契约

- 建立正式战役的 `EncounterConfig`／阶段目标状态，与 G0 训练及 G1／G2 机制 fixture 的快速节奏明确分离；统一 GameSession、伤害、碰撞、事件与成长路径。
- 正式入口、正式战役浏览器用例和完整会话模拟使用同一正式配置；fixture 报告必须标明覆盖机制，不能替代正式局节奏证据。
- 集中配置目标内容、遭遇位置、压力上限、阶段兜底与参考时长；目标时长720秒只是调参参照，不参与胜利判定。
- 阶段由已接受的目标事件推进；时间只产生有预警的压力／可挽回兜底。提前完成目标即可推进，不能完成后等待时间到点。
- 记录 seed、配置版本、引导变体及实际目标分支；同 seed、同配置、同输入必须复现。不得让未记录的本地档案状态暗中改变复现结果。
- 原有胜利条件继续要求母巢清除、所有激活器官健康达标、感染负荷达标和主动复测；普通击杀或教学完成均不能直接获胜。

## 3. 首次固定低压反制教学

- 在真实正式局中完成，首次采用固定、可读的晶壳遭遇作为候选实现：一名预警清楚的低压威胁，附近可利用的冲流装置和明确绕后路线；不以静态文字或假靶替代。
- 先提供一次真实移动、净化／扫描目标，进局30秒内可以操作；随后通过“≥8秒预警 → 壳层出现 → 玩家反制 → 实际破绽／净化反馈”教授因果。
- 同时展示两条基础解法：绕后净化，或利用 E 冲流破壳；不得要求先抽中共振裂解。协议收益在获得后通过同一遭遇规则展示。
- 固定低压来自显式遭遇配置与有限威胁，不通过隐藏修改命中率、生命值或按玩家失败次数读心调难度实现；失误仍有恢复与重试机会。
- 提示按实际事件收束：出现预警时指向威胁、破绽时提示行动、接受的反制命中后确认效果；不覆盖危机提示，不强制阅读大段文字。
- 随时可跳过引导提示，之后能在作战手册回看规则及本局记录；跳过不得凭空清怪、发奖励、推进时钟或完成阶段。
- 引导完成／跳过分别记录并版本化保存，不能复用“首次迁移已确认”。同种子重试保留该次运行的引导变体，后续新局可进入正常软随机演化。
- 首次迁移说明已有实现，复用并核对其生命周期，不重复新增第二套迁移教学。

## 4. 五阶段战术目标

| 阶段 | 主要局势与行动目标 | 决策、环境与协议应用 | 推进与兜底 |
|---|---|---|---|
| Ⅰ 初始感染 | 从可辨病灶建立安全窗口，处理早期传播支点并观察组织变化 | 清源还是先抢修；近场布局提供扫描与侦巡接敌机会 | 接受的关键目标事件推进；不靠刷普通体升级 |
| Ⅱ 变异应对 | 看见首次变异，并对具有弱点的护源／精英遭遇形成反制 | 绕后或冲流破壳；裂殖聚敌或范围处理；潜伏扫描或组织修复；协议提供另一种效率与控制方式 | 目标完成即可推进；未选研究或不针对协议仍可解 |
| Ⅲ 器官危机 | 第二种压力改变优先级，并触发真实迁移抉择 | 追击、封锁或放任影响分布与健康；肺部气流／气道和心脏残留风险形成取舍 | 复用有界迁移后果与返回通路；超时产生可救援新局势，不直接判负 |
| Ⅳ 联动反击 | 将已形成的构筑用于新的攻防局势，而非只清剩余计数 | 在保护受压组织与处理传播支点间选择；晶壳窗口接净化链，或显影后免疫围猎；基础工具可用替代路线完成 | 完成关键感染节点／研究证据目标；不要求抽中特定组合或强制购买协议 |
| Ⅴ 核心决战 | 母巢带入本局两特性，利用弱点取胜，再稳定器官并主动复测 | 保留核膜与两特性可见使用；决战中仍有走位、反制与治疗取舍 | 所有胜利条件同时成立才结算一次；失败可解释、可干净重试 |

- 每阶段至少一个独立目标状态与完成事件，HUD显示当前状态、下一行动及实际原因；不能仅更换阶段名称。
- 遭遇位置围绕现有功能区与安全通路配置，避免把所有活动重新堆回同一屏；路线长度由决策需要决定。
- 每个遭遇在实施前补齐第1节内容公式和两条基础能力解法；协议联动是可利用的机会，不作为随机装备门槛。
- 多阶段压力受单位上限、离场预算与恢复窗口约束；较慢玩家仍有明确挽回路径，不能用无限增殖迫使结束。

## 5. 观察指标与验收

- 从模拟事件记录每阶段进入／完成时间、具体目标分支、危机与恢复、实际反制命中、环境使用、草案选择、成长后首次触发、迁移后果与最终结果；不由 UI 推测战斗因果。
- 分开记录有效模拟、暂停／阅读及总墙钟时间；统计各阶段无目标空档，不能用总测试耗时充当单局长度。
- 单元／集成验证目标推进幂等、跳过无奖励、暂停冻结、同配置复现、无协议／非针对草案可解、提前完成可推进、超时恢复与压力有界。
- 浏览器以正式配置真实键鼠覆盖三迁移路线、首引导完成／跳过／回看、至少两种不同构筑及干净重试；保存实际画面与事件证据，fixture 另列。
- 若正式内容超过现有单局驱动300秒上限，应据目标上界另设有界操作／runner预算并记录原因；不能为适配旧预算缩短正式内容、跳过目标或改测快速fixture。
- 小样本首次玩家记录阶段耗时、迷失点、升级后行动变化、两次优先级改变、变异与反制解释；连续两局记录策略变化和自发复玩原因。
- 自动化只验证行为与合法快速路线；M13-01入门节奏、M14-02首次3分钟理解、标准五人盲测及趣味／孵化潜力仍须真人原始观察。未取得记录前不宣称通过。
- 有意义的实现变化完成后执行相应回归；性能与发行证据绑定新构建，不能迁用旧包结果或把长时间压力存活当作标准胜局。

- v0.6.2游戏源码 `f83514d`：`artifacts/feedback-v062/full-system-seeds.json` 为1000个完整熟练驱动会话，平均73.2045模拟秒、范围65.55–85.5秒；不是首次玩家局长，也不是1000场浏览器或真人测试。
- 同版 Chrome seed41原始 `artifacts/feedback-v062/browser/g4-G4-complete-browser-see-a29a1-tence-and-clean-seed-replay-chrome/win.json`：两源1.70／6.37秒清除、两变异22／40秒、母巢54.40–62.77秒，总68.53秒。这提示阶段行动量需审查，但不证明所有新玩家同样快。
- 主矩阵 M13-01早期51.00–65.35秒、均56.0145秒属于旧G4记录；应保留版本归属，不冒充v0.6.2结果。当前M13-01仍未关闭。
- v0.6.2已有大地图、三阶协议、实体免疫细胞及围攻提示；这些机制继续复用。两张采样截图存在局部重叠，不证明全帧无遮挡。
- 标准五人盲测仍0/5，已有一份用户实际反馈另列；本计划不增加真人人数。现有帧预算、内存观察和原生窗口限制继续按各版本验收文档分别报告。

## 7. 实施顺序

1. 前置稳定性补丁由v0.6.3交付；v0.6.4完成立体上部遮挡修复，保持Y排序／碰撞和接地轮廓。同快照前后图与本包不利帧分别存证，不把灯塔十字计作细胞；完整内存稳定继续开放。
2. v0.7.0 已落地正式 campaign-1／fixture-1 配置分离、阶段状态与真实事件，固定首场晶壳教学以及引导完成／跳过／重试元数据。
3. v0.7.0 新增阶段Ⅳ传播支点；阶段Ⅲ复用原有三路线迁移，阶段Ⅴ复用双特性母巢。只有首反制与有限支点是本轮新增遭遇，不将原有阶段重命名计作五个新关卡。
4. 以最终构建完成行为回归与技术候选，收集真人原始记录后迭代入门10–15分钟目标；不提前关闭体验验收。
