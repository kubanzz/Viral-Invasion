# 玩到27波后的真实反馈与处理范围

用户于2026-10-28回复此前v0.8.8难度问卷。实际试玩包哈希未提供，本记录不假定它与当前工作树相同；它是同一位用户的真实反馈，不填入五人新玩家盲测。

1. 冲刺斩太普通，希望有挥刀范围斩杀的爽感。
2. 病毒升级强度跟不上玩家，缺少挑战。
3. 玩到27波，爽感有提升；玩家进化开始没有变化，前后期病毒进化都没有感受到威胁。希望突出“威胁→玩家强化→爽感”。
4. 武器1比较好用，其余价值不明显，尤其工具2应重设计以应对不同挑战场景。
5. 病毒攻击组织和玩家的强度不够。

## 本轮实际方向

- 大范围冲刺挥斩，Ⅲ阶回旋与Ⅵ阶延迟回斩，真实扇面、位置与墙体判定同步；表现由模拟的实际范围驱动。
- 工具2牵引裂解：短射程、聚拢、延迟爆破，给贯穿／连锁／细胞创造目标；新星Ⅲ允许按住导流。工具1保留远距即时持续火力；催化明确转换普通爆发，不重复发放免费伤害。
- 有限离体弹囊：施法或宿主死亡消费同一库存，独立预警与飞行；第5波可见，第15波后母囊分叉。基础工具、挥斩和真实细胞可拦截，墙体／侧移仍有效。收割波不新增携带者。
- 延续v0.8.11的组织袭击与免疫驻防，但不将它们单独称为“威胁已成立”。

## 不能回避的证据

v0.8.11固定22局中，原候选9局的162名组织袭击者全部被清除，组织起手和实际组织伤害仍为0；同策略细胞总伤害并未普遍提高。新驻防政策三局证明真实守备和咬击，但远离玩家仍击中袭击者的覆盖不普遍。这支持继续修复威胁与工具分工，不能以新增两个功能宣布目标满足。

新版本需要分别验证真实拦截／飞行／分叉／命中、工具2产生的聚群收益、挥斩不同阶段的实际覆盖、压力与收割差异，以及用户是否愿意换打法。自动策略秒拦截和无伤仍应保留，不能为制造难度而给敌人锁血、隐藏追平或保底伤害。

这些改动尚不等于后期全局构筑分支、长期复玩或孵化价值通过；目标保持未完成。美术会话在独立快照继续生产素材，本轮只接入实际战斗范围所需的代码表现。
