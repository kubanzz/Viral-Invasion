# 初始方案与结算事实补齐

日期：2026-10-27；设计来源：原始v1.3 GDD §2.4、§5.4、§10.3、§11.1。原始DesignDoc_v1.3不修改。

v0.7.1已经交付可玩候选，用户同意先完成技术候选、真人随后补。本轮只落实仍缺失的跨局实际选择与结算因果，不新增器官、协议、快捷键、账号数值或付费内容，不以这些界面代替核心趣味验证。

## 初始方案

- 默认“现场应答”：空装出发，20XP首份三选一、后续成长及四种局内协议池保持可用。
- 一份已结束病例实际携带过的协议，会成为未来初始方案候选；胜败均可，未结束退出不记。现有携带记录兼容。不会把“已携带”称为已触发联动或掌握反制。
- 可预装其中一种协议：固定Ⅰ阶、均衡、占1/3槽，开局立即真实生效。使用预装等于提前使用第一份XP成长；20XP只结清该名额，不生成草案，55XP及以后照常。总XP不扣、阈值不涨、不获得额外永久等级。
- 债务独立于当前装备。研究升级、换掉协议、旅行或暂停不会免除偿还；一次奖励跨多个等级只偿还一次，其余正常排队。
- 本实现扩的是“未来初始方案候选”，不声称四种局内协议池新增内容。相同XP下的总成长获取预算不增加，代价是放弃观察首轮局势后再三选一的灵活性。
- 菜单和结果提供可选入口，不强制弹窗。明确立即效果、协议本身代价、预支代价和下一草案阈值。预装与偿还分别反馈，不把20XP偿还包装成一次新升级。
- 新局用当前偏好；同病例重试、最近及最佳病例回放保持记录的版本化初始方案。旧记录明确空装，不借用当前菜单偏好。只保存方案ID／规则版本，不保存上局XP、阶数、校准、损伤或细胞。

## 结算事实

- 在宿主接受事件时累计，与近期512条事件日志分离；本局结束冻结，新局清空。
- 修复量采用实际完整度增加，不把对满血组织的空操作计为治疗。组织总损失和装置／协议主动代价分开，受击量只统计真实扣除。
- 协议日志可能是计划意图。连锁／折射／共振／小队命中须与同tick、相同root、目标及协议的实际正伤害匹配；核膜拒绝、已死目标或无实际扣血不计。基础侦巡不冒充灯塔，折射不混入净化链。
- 一条净化链至少一次真实邻体命中计一次发动，跳数按实际命中计；共振连锁按根，显影小队按实际标记咬击计。定义与两维事实显示在结算和病例复盘中。
- 环境、诊断、迁移与母巢只描述已发生事实，不推算“避免了多少伤害”或把迁移决定当作感染源已实际出生。
- 匹配缓存只保留当前tick、上限256，摘要只有固定计数与有限枚举。溢出显式提示统计不完整；旧记录没有指标时显示未记录，不补造零。
- “治疗质量”和“系统掌控”采用事实解释，不加入刷分奖励、评级或排行榜。已有器官终态、胜败原因、策略建议和两个重开操作继续保留。

## 验证边界

机制／档案测试覆盖预算、研究先行、重复／旧事件、终局与旧档。完整模拟保留500空装基础路线；另外500协议路线覆盖现场应答和四种预装各100，并保留两引导变体和三迁移路线。真实浏览器从空档实际获取协议、结束病例、解锁方案、预装、偿还、继续成长、结算及重试／刷新回放；不写入生命、时间、装备或存档制造证明。长压力在功能进程结束后独占执行，统计器的有界性与两画质预算一起观察。

五位新玩家标准盲测仍0/5。首次理解、首玩10–15分钟、两局真实策略改变、自发复玩、趣味及孵化价值仍需原始真人记录；原生OS操作与完整内存稳定也不由本轮窄证据自动关闭。
