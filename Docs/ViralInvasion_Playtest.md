## 执行准备

- 招募5位从未看过本项目设计文档、操作演示或试玩的新玩家，逐位独立进行。仅使用匿名P01–P05，不收集姓名、联系方式等身份信息。
- 使用最终待验收的双器官离线发行包；现场填写真实版本、Git提交及发行文件哈希，不沿用旧G2版本号。每人首次启动使用独立空存档/浏览器配置，并记录初始状态。
- 记录设备、浏览器版本、窗口尺寸、DPR、声音、普通/低特效档。以正常入口开局，不预装协议、不注入生命值/时间/关卡状态。
- 只提供发行入口，允许玩家阅读游戏内信息。观察者不口头提示按键、目标位置、工具答案、协议或迁移路线，不代操作。
- 如因故提供帮助，逐字记录原话与时间；后续完成标为“经提示完成”，不能计入自主完成。技术故障与玩家误解分开记。
- 如需录像/截图，先征得知情同意；未同意则只做匿名文字记录。保留原话，不由AI补写、润色或推断玩家没有说出的动机。

统一开场白：

> 请自行尝试这款小游戏，按你理解的方式玩。你可以查看游戏内的信息，也可以随时停止。过程中我不会讲解玩法；结束后再聊你的体验。

## 单人流程（总计10–20分钟）

| 环节 | 执行方式 | 必记事实 |
|---|---|---|
| 启动，约1分钟 | 念统一开场白后保持安静 | 首次认出玩家/目标的时点、第一项实际操作、是否主动看帮助 |
| 第一局，自主进行 | 不指定路线或强求胜利；允许暂停、退出，达到总观察时间则如实截断 | 从开局到成功/失败/退出的墙钟时间、游戏内计时、暂停/草案/帮助耗时、阶段和卡点 |
| 结局后60–90秒安静窗口 | 不问“还玩吗”、不指重试按钮、不宣布应玩第二局 | 自发说想再玩、实际点击同种子/新局、误点或直接停止；窗口内观察者有无说话 |
| 第二局，仅在自愿时 | 继续无指路观察 | 与第一局相比的真实行动变化、触发它的状态/反馈、玩家解释原话 |
| 结束访谈，约2–4分钟 | 在安静窗口之后提中性问题 | 原话、实际遭遇范围、无聊/不公平/难辨认的具体时刻 |

若为补覆盖而邀请第二局，必须记录邀请原话，并标为“受邀重玩”，不得计入自发复玩。未玩第二局则策略变化记“未覆盖”；未遇到第二类变异、肺部或母巢也记“未遇到”，不能当作识别失败或通过。

## 观察清单

| 观察项 | 可计入的证据 | 避免的误判 |
|---|---|---|
| 玩家与空间 | 首次找到玩家、脚底/遮挡时定位、实际绕障/受击行为 | 观察者指认后不能算自主识别 |
| 至少两类变异 | 各自遇到的时点、形态/能力/代价/反制的描述与原话 | 不要求背英文名；只读名称不能证明懂机制 |
| 当前危险 | 预警开始、实际反应、命中/躲过及本人解释 | 随机移动恰好躲过不能直接算理解 |
| 反制 | 尝试哪种工具/位置/时机、实际效果、错误尝试及自行纠正 | 选卡或看提示不等于成功执行反制 |
| 当前目标与失败风险 | 玩家能否解释当前要做什么，区分自身耐久、器官完整度、感染负荷和全身稳定 | 不在进行中给出这些指标的正确答案 |
| 双器官与迁移 | 实际进入哪些器官、如何选追击/封锁/放任、观察到何种后果 | 未进入肺部不能算理解其环境机制 |
| 构筑与策略变化 | 相同玩家两局的目标优先级/站位/修复时机/工具与协议使用前后对照，附状态与时间 | 选了不同卡片但行动没变，不算真实策略变化 |
| 自发重玩 | 安静窗口中的原话或主动开局，注明同seed/新seed及理由 | 被邀请、误点和观察者引导分别列出 |
| 时长与瓶颈 | 首局墙钟/游戏计时/暂停分开，教学、清源、精英、迁移、母巢、复测逐段记录 | 不用自动策略56秒、总观察时间或估计值代替实际单局时间 |
| 视觉可读性 | 具体对象、器官、特效档、遮挡关系、误认原话和媒体索引 | 普通/低特效技术截图不能替代真人辨识 |

访谈只问已发生的体验，保留完整回答：

1. 你刚才想做什么？你觉得这一局为什么结束？
2. 你看到了哪些不同的感染体？它们有什么不同？
3. 哪一刻你觉得危险？你做了什么，结果怎样？
4. 有什么让你改变了做法？如果玩了两局，两局做法有什么不同，为什么？
5. 结局后你为什么继续或停止？
6. 哪些地方不明白、无聊、太难或不公平？能指出具体时刻吗？

不要在问题中透露“扫描能破拟态”等正确反制，也不要要求玩家认同某项机制有趣。

## 汇总规则与阶段目标

依据GDD v1.3 §12.1：至少4/5能解释一次变异及反制，至少4/5无需口头指路完成教学核心循环；同一人连续两局能指出实际状态改变导致的策略改变；至少3/5自发愿意再开局并记录理由，且不应普遍出现无法解释的“随机硬克制/操作没作用”挫败。额外逐项记录两类变异、玩家/危险识别、双器官理解和完整母巢通关，不能用教学完成率替代它们。
