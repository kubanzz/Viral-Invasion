## G0 首次操作观察流程

对象：未接触本项目的玩家。仅提供发行入口与游戏内帮助，观察者不口头指路。使用匿名编号，不记录真实姓名或联系方式。

1. 从离线发行入口进入训练场，记录能否认出玩家、训练靶、受损组织和复测设施。
2. 请参与者自行完成场内目标，记录移动/瞄准、扫描、精确净化、范围裂解、组织修复和E复测中的停顿与误解。
3. 观察是否理解当前工具、错误工具反馈、冲刺冷却，以及前景遮挡下自己的位置。
4. 暂停、继续并重开一次，记录是否出现持续开火或旧状态残留。
5. 结束后询问其对目标和操作的理解；观察是否主动重开，区分自发行为与被要求操作。

## G1–G4 玩法验证补充（待对应阶段实现后执行）

| 观察项 | 记录方式 | 设计初始目标 |
|---|---|---|
| 变异认知 | 不给答案，让玩家描述至少一次变异能力、代价及反制；保留误认原话 | 至少4/5能够解释 |
| 自主完成 | 观察是否无需开发者口头引导完成教学小循环 | 至少4/5自主完成 |
| 战术变化 | 同一玩家两局，记录位置、目标优先级、治疗时机或构筑改变及其原因 | 能指出至少一处真实策略差异 |
| 自发重玩 | 不提示重开，记录是否主动要求/开始下一局及原因 | 至少3/5自发愿意重玩 |
| 器官差异 | 隐去器官名称后，观察是否由心跳/瓣膜/血流与气流/肺泡/气道认出环境及影响 | 分别记录成功和失败，不伪造比例 |
| 视觉可读性 | 记录玩家、至少两类病毒与当前危险的误认；比较普通/低特效 | 对应VIS-12逐条留事实 |
| 公平与因果 | 让玩家解释败因，记录“随机克制”“操作没作用”等反馈 | 不应出现普遍且无法解释的挫败 |

五人属于早期定性样本，不能推断长期留存。当前所有G1–G4条目均为未执行；尚不能宣称本游戏已证明有趣、吸引人或具备市场价值。
