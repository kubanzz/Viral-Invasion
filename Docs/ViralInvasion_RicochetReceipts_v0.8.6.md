# v0.8.6：让成长战绩记录每次真实折射

本版修复扇射与连锁进阶组合的实际反馈缺陷，不新增卡片或美术资产。标准五位新玩家盲测仍 **0/5**，趣味与复玩验证保持开放。

## 问题与修复

扇形抗体Ⅱ一次发射五束射线，连锁净化Ⅲ每两次存活命中可折射一次。同帧同源的两次折射原来共用回执标识：目标实际受伤两次，战绩与成长历史却将它们去重为一次，玩家查看成长效果时会低估实际收益。

定向集成场景使用真实后段精英可有的204HP、半径30，明确预设成长和位置，再执行一次公开输入step。前后两版主目标均204→34，邻体均204→64，实际折射70+70；修复前战绩只计1次、历史只写70，修复后计2次、历史70+70。两版伤害事件除回执标识外相同，充能余数1、预算使用6、拒绝0、协议激活2均相同。这是明确的预设状态复现，不是自然抽卡或真人证据。

每次预算受理的独立折射现在拥有独立事务标识；同帧、同源、同邻体以及共同上游来源都不会碰撞。上游来源只作溯源。预算拒绝、无可用邻体不提交序号；序号仅保留当前tick，换器官不重置同tick身份，新局使用新命名空间。统计与历史的严格回执匹配、重复消息去重继续保留。

本版没有提高伤害、改蓄能周期、改变候选或降低敌人耐久。原致死连锁、催化不递归、分裂人口约束保持。

Chrome1366×768与Edge1100×560均在离线生产构建中，以真实DOM/鼠标/键盘自然取得连锁Ⅱ并观察至少3次真实折射，联接唯一正伤回执、战绩、历史、HUD与配装详情；暂停350ms后计时与结果保持。两份配装详情截图已查看，计数可读，紧凑窗口的长说明沿用滚动区。两浏览器未自然出现同tick同邻体的两次折射，不能把本轮浏览器通过替代前述碰撞回归。

定向回归还检查真实HP裁剪、共同上游、重复回执、预算拒绝、无邻体、跨器官/新tick身份、重开确定性与原致死连锁。首次预期失败及实际140/旧反馈70的原始收据保留。主树首次检查的输出路径与定向检查同名，写入保护中止；改用独立输出路径后重新执行，旧记录未覆盖，没有改变游戏或放宽断言。

没有把自动胜局、精确统计或新包可运行等同于更爽、更有趣、自发复玩或商业孵化价值。后段精英变招仅列为[后续候选](../artifacts/ricochet-v086/planning/late-elite-next-step.md)，尚未实现；敌人伤害仍随波数增长，不能把部分HP/人口预算封顶写成全部威胁封顶。
