# Viral Invasion v0.7.1：诊断驱动的定向研究

日期：2026-10-27 · 状态：技术候选已交付；机制、最终浏览器、双档长测和离线发行验证完成。

本轮补齐 GDD §5.2 的“针对性抗体研究”：此前研究台只是消耗样本再抽一次与经验相同的随机草案，没有让已收集的诊断证据变成主动方向。原始 `DesignDoc_v1.3/` 不作修改；地图、四协议、三槽、三阶、首次反制和有限支点继续沿用。

## 实际行为

- 正式战役在研究台 E 打开方向页，先不扣样本、不生成草案；玩家可免费取消或 Esc 返回。方向页、手册和配装详情共用原来的暂停所有权。
- 通用研究始终可选。晶壳、裂殖、潜伏方向只由本局实际 Q 诊断记录开放；变异预警、击杀和旧档发现不会冒充这次诊断。
- 确认方向时唯一扣除3样本，生成三种不同且合法的协议候选。晶壳保证共振＋连锁，裂殖保证连锁＋共振，潜伏保证显影＋灯塔；第三种按种子和既有构筑产生。玩家可以选任意一项或放弃，不强制使用相关反制。
- 已有协议仍按实际阶数提供进阶或Ⅲ阶合法校准；不继承局外等级。经验草案的原随机、开局泛用和后续进阶保障保留。G1/G2快速夹具的即时研究路径单独保留，不用于证明正式流程。
- 确认前取消不改变草案随机序列；确认后放弃不退样本，不能通过取消免费重抽。请求、确认、扣费和草案日志含 requestId、方向和实际余额。重复／旧局请求被拒绝，重开清除待确认研究、样本和临时配装。
- 阶段Ⅳ支点出现、装置中断和真实清除现在进入有界的战术记录；原512条事件／128条近期消息淘汰后，仍可回看原因。只记录已发生事实，不推断未造成的伤害或已经完成抢修。

按 GDD §11.3 的内容公式：**已诊断特性与可用样本 → 选通用或针对方向、选择一项候选 → 前往真实研究台 E → 基础反制始终可解 → 研究保证提供现有共振＋连锁或显影＋灯塔的联动机会**。本轮增加的是研究决策，不新增快捷键、器官、协议数量或永久伤害。
