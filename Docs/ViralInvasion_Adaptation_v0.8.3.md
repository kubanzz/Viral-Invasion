# v0.8.3：连续挑战接入行为进化

本版延续玩家提出的地图拥挤、成长无感、攻击单调与免疫协战缺失四项反馈。当前为技术候选，标准五位新玩家盲测仍为 **0/5**。

## 当前可玩内容

- 心脏、肺部均为2400×1500，设施与感染目标分区，配合跟随镜头、小地图和导航选择路线。
- 四条协议可升至Ⅰ–Ⅲ阶，连续挑战另有九类逐波成长：净化突破、扇形抗体、贯穿净化、裂解新星、冲刺斩、扫描爆发、生命扩容、急速净化、免疫军团。每次仍三选一，已拥有的能力继续强化；每五波可免费重配协议。
- Q基础召来短时侦巡；装备免疫灯塔后部署三只真实移动、绕障和接触咬击的免疫细胞。小队存活且召集冷却中时，可在Q就绪后重新指挥。搭配异常显影优先围猎标记体。
- 远距点射支援、晶壳锁向冲锋、裂殖双点爆发和潜伏组织侵蚀提供不同应对场景。晶壳可近身绕后，Q可指挥小队赶往远端支援，范围裂解可击退打断。

这些是累计保留的玩法改造，来源见[v0.6.0反馈处理](ViralInvasion_PlaytestFeedback_v0.6.0.md)、[九类成长](ViralInvasion_v0.7.7_Acceptance.md)、[编队与重指挥](ViralInvasion_v0.7.8_Acceptance.md)、[v0.8.2反制](ViralInvasion_Combat_v0.8.2.md)。本轮没有新增美术资产。

## 本轮增量

原连续挑战在记录行为后，仍仅按种子和波数轮换性状。本版将设计v1.3 §4.3的行为软偏置用于连续挑战后段；无尽模式属于后续授权扩展，原GDD将其列在MVP之后。战役进化算法保持原规则。

- 第5/10/15波保留三类精英教学，第16波保留混编引入。从第20波起，每五波依据最近90模拟秒的实际行动、器官环境和近期主性状记录，选择下一代主性状。
- 行为只统计正伤的基础精准/范围攻击、主动爆发、有效诊断和实际手动修复。协议伤害与隔离控制不计入这一有限模型，不能称为完整构筑或总DPS画像。
- 近期重复分支降低权重，新主性状的单次抽签概率最多55%。可能连续抽到同一分支；55%不表示主性状与伴随性状的合计出现率。
- 最多同时两个性状，保留合法旧性状作为伴随变异。预警开始时只抽取一次，完整八模拟秒内维持旧代；随后先提交新代，再出生该波实体，后四波继承同一计划。
- 进化卡分别显示实际能力、代价、基础反制、伴随变异与倒计时；HUD区分当前与待生效性状。暂停同时冻结预警时间。
- 复用已有三类精英招式，不增加敌人HP、攻击数值或有限出生预算。普通体仍为68 HP；支援混编名单沿用v0.8.2规则。
