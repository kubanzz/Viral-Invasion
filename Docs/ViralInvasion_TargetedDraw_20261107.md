# 金色定向接引与追加体验补给

装备池默认定向「霆链·裁决铳」，可在「血流接引 → 武器与模组 → 更换定向目标」选择两把传说武器、四种金色模组或锻造核心。

- 当前目标每次装备抽取累计1次，单抽、十连共享；第100抽直接产出目标金色，提前抽中则重新累计。
- 抽到其他金色不清空定向计数。各目标独立保存计数，切换后可继续此前进度。
- 原有50抽出金保底保留；定向出金同样重置该保底。军团池不推进装备定向。
- 旧装备/军团保底、收藏、金币与回执保留；定向进度从功能启用后开始记录。
- 回执记录当次目标、定向前后计数与100抽上限，重复请求不会再次扣款或推进计数。
