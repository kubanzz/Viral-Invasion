# v0.8.2：让走位、绕后和免疫协战产生实际收益

依据设计 v1.3 §2.1、§4.2、§5、§6，以及用户提出的空间拥挤、成长无感和攻击单调反馈。这是技术候选；五位新玩家盲测仍为 **0/5**。

前续版本已加入 2400×1500 双器官、设施分区、镜头/小地图、四协议三槽位与Ⅰ–Ⅲ阶、九类逐波战斗成长、真实移动咬击的免疫小队。本轮补上这些能力的使用场景，保留玩家成长数值、普通体 68 HP、有限出生和裂殖预算。

## 本轮规则

- 连续挑战从第3波开始，每波现有支援预算中的第一只点射体优先保持560–600距离，射线范围620。其余支援保留各自战术；没有额外增加敌人数或血量。
- 远距支援保持1.5秒出生缓冲，再经过1.05秒锁线预警才攻击。锁定后身体、方向与射线起点不追踪玩家。玩家可以侧移避开，也可接近并用基础射击清除；退让速度80低于玩家235，遇墙止退。
- Q瞄准远端部署或重新指挥免疫小队。细胞必须实际移动、接触并造成正伤；原有显影减速也作用于支援退让。Q仍有召集冷却与协议组织成本。
- 晶壳自由移动时转身上限1.2弧度/秒；近身侧绕可以离开原有正面减伤锥。正面精准伤害仍乘0.3，范围裂解、E冲流破壳与原有协议继续有效。已承诺攻击、冲锋和恢复姿势保持冻结。
- 出生沿用原48个候选；失败时才做有上限的完整方位搜索。远环确实无安全点时，该预算位退回近距点射姿态，仍保留至少340安全距、1.5秒缓冲、合法足迹与真实视线。人口满时保留队列；没有合法点时不伪造出生或跳过预算。

两局定向Q各对28只远距支援造成1904＝28×68真实细胞伤害，分别137/122次正伤命中；这些目标没有受到基础射击伤害。实际协议组织成本84/90，敌人组织伤害0，随后恢复84/90。HP恢复包括现有成长扩容与清波补给；不能把最后满血误写成全程无伤。

这支持移动接近与定向协战都能取得真实清除收益，不以站桩死亡作为唯一验收。主动组远距支援均在起手前被清除，未证明其自然侧闪体验；侧移、基础Q与完整移动晶壳的伤害窗口另有真实Session交易夹具。世界XY输入也不等同鼠标可达或真人理解。
