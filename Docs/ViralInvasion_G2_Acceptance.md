## 实现与规则边界

`src/game/evolution.ts` 在最近5400固定tick（90秒）窗口内统计有效基础伤害、接受的Q/隔离及实际修复量；同tick合并，空枪/拒绝操作/过量伤害/协议自动伤害不伪装成玩家策略。专用seed流选择合法未出现trait，单项概率≤0.55、最多两主特性，选择决定先记录后进入≥8秒预警。没有合法候选或只剩一个候选时明确defer，避免伪造概率上限。

`growth.ts` / `growthTypes.ts` / `protocols.ts` 在现有会话中处理奖励、三槽草案、校准、研究与四协议；命令返回统一伤害/死亡入口，不复制主循环。`growthHud.ts` / `growthVisuals.ts` 提供三选一、第四项替换/放弃、样本及协议反馈。

| 协议 | 实际触发与均衡配置 | 代价与边界 |
|---|---|---|
| PULSE_BREAK | 距节律装置≤240，surge相位基础命中追加18伤害、暴露4秒，每目标每节律一次 | 需接近及配合时机；校准改变距离/伤害取舍。 |
| PURIFY_CHAIN | 基础清除向170范围合法邻体跳2次，每跳38；共振破绽清除可增至3跳 | 检查视线与已访问目标；协议链伤害不另开新链。 |
| IMMUNE_BEACON | 接受Q后鼠标标记点召集1座，6秒寿命、190射程、0.8秒间隔、24伤害 | 12秒独立冷却、当前组织-3；放置射程420且处理可见障碍。 |
| EXPOSE_TRACE | Q标记/显形9秒，前3秒速度×0.7；灯塔优先标记体 | 占槽且无直接伤害；移除即清标记/减速。 |

三个槽位始终有效；第四协议需第二次原子替换确认或放弃。已有协议可在balanced/focused/extended之间校准，不叠无限等级；草案保证三个不同协议的合法选项。研究每份消耗3样本，放弃不退，返回候选不换卡。

奖励独立于512条诊断日志去重：源20XP/2样本、精英30/2、基础诊断6/1、每种trait首次诊断8/2、首次有效保护15/1；普通体同来源4/2/1/0，裂殖子体0。累计20/55/95升级，前两选择由目标事件保证，无计时送经验。
