# v0.13.0 心脏攻防：军团接防与战斗反馈

本轮围绕玩家先守点、军团成长后接管防线的完整流程改造。2400×1500地图、七节点和48敌方活体及裂殖预约上限保持；运行时素材预算仍为20MiB。

## 成长与通关

北南两线分别首次在健康前线或生命泉300范围实际交战、完整击退一支进攻小队，且组织侵染进度回退至0，会将灯塔最低等级提升至Ⅱ/Ⅲ。顺序不限，不依赖随机免疫强化。挑战的灯塔是保留能力，其协议槽不能被替换。

现存军团升级保留生命绝对值、位置和攻击时钟，只提升上限与参数、增加新等级解锁名额；阵亡成员不会因重复Q或相同等级同步而补回。

Ⅲ阶军团至少两名活成员抵达健康前线150范围后，下一支对应正常进攻队开始验证。军团实际伤到侵染者、整队及预约裂殖全部处理、前线健康且侵染归零、该团仍驻防存活，才完成该线接防。玩家可协助，失败可在后续有限波重试，不锁清波。

源护膜需要历史接防完成、泉与前线健康、当前仍有活驻军在前线300范围内。军团改派、全灭或组织失守会复膜；源已受伤保留。摧毁源永久停止该线新进攻，已出生敌人不消失。

双源摧毁后处理残敌、预约裂殖和本波成长，进入母巢战。母巢死亡不会自动清场或洗白组织；必要时进入最后净化。七区健康、侵染归零、实际战斗义务清完，玩家与心核存活时立即保存胜利。同帧死亡优先。接防历史在后续军团伤亡后保留。

## 操作与反馈

- 3/手机净化：靠近150范围一键开始，3秒累计，继续移动射击。离开、侵染者干扰、支援泉失守或直接受击会暂停，保留进度；直接受击暂停0.8秒，感染持续掉血不反复打断。
- Q/手机驻防：最多两团；手机短按优先附近健康节点，长按拖动指定。指令瞄准独立于持续射击。
- 中央重炮：位置(1200,600)，110内按住E或手机炮台按钮瞄准，松开发射，取消保留弹药。单发、24秒自动装填、1100射程、240爆炸半径、260基础伤害，0.6秒后落地。仅伤普通病毒、侵染者、护卫与裂殖小体，经统一伤害和死亡流程结算；不直接净化组织。
- 普通射击增加深色描边、亮芯、短拖尾、枪口与命中反馈。感染增加贴地暗紫影和真实掉血脉冲；30%/15%耐久分级警示，35%/20%退出对应等级，提示真实健康泉方向或先夺回泉。
- 低高度横屏固定布局：104移动、80攻击、52主要技能、48最小点击区、至少8间距，安全区内显示；炮台与抗体按上下文显示，手指占用期间不重排。
- 行走按实际模拟位移累计步相，停止、贴墙、冲刺和传送正确切换。现有16帧使用局部下肢足底接地修正及对应阴影，原图、统一注册点与持枪锚点保留。

## 计时与存档

七区健康且侵染进度全部为0时，累计全域健康时间。再次侵染暂停累计、重置当前连续值；夺回后继续累计，并记录最长连续时长。移动中的侵染者、普通敌人或玩家个人感染不单独阻止计时。

所有计时使用模拟步进，暂停、强化选择、详情、后台和旋转暂停均冻结。胜利快照保留当时的累计与最长连续值，继续守卫更新同一局最终成绩。第4版领地存档与旧版1/2/3记录分开，旧数据不重写；保存失败保留会话快照并提示。未实现刷新恢复战场。
