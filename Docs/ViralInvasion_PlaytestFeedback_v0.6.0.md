## 1. 地图小、设施集中，缺少探索和空间选择

**反馈与根因。** 旧版正式战场沿用了1200×800的训练场尺度，研究、修复、复测等设施彼此接近；固定全图镜头让不同目标集中在同一屏内。设计要求器官环境能改变战术，而紧凑摆放削弱了清源、补给、研究和跨器官行动之间的路线选择。

**本轮改动。** 正式心脏与肺部均扩展为2400×1500世界，实际可行动边界由1070×625变为2230×1270，地面面积约为原来的 **4.23倍**；总世界矩形面积则是3.75倍，二者不混用。训练与早期机制fixture保留原尺度，不能用这些fixture的图当作正式大地图证据。

心脏分为复苏前庭、抗体研究区、节律枢纽、感染前线和深层病灶；肺部将入口、免疫集结、气道与感染肺泡分开。设施与感染源依据各区重新布置，并留出绕障通路。跟随镜头保留局部角色和目标的可读尺度，移动时探索其他区域；小地图显示玩家、设施、当前视野和目标方向。导航同时考虑另一激活器官的残留感染与健康条件，避免母巢清除后仍误导玩家在未达标状态反复复测。

**可复查验证。**

- `tests/unit/campaign-space.test.ts`：检查地图尺寸、设施间距、碰撞净空与12秒迁移预警内的路线可达性；`camera-follow.test.ts`验证镜头及正反坐标一致性。
- `artifacts/feedback-v060/spatial-travel-fix-unit.json`、`navigation-render-profile-unit.json`保留空间、旅行、导航和相关边界测试。
- 最终浏览器的两个空间用例均实际行走、记录镜头原点移动、执行Q召集和真实射击；Chrome为1366×768，Edge为1100×560。证据位于 `artifacts/feedback-v060/browser-rerun2/` 下的 `Feedback-spa-*`目录，包含 `entry-district.png`、`cell-patrol-bite.png` 与 `spatial-cell-evidence.json`。
- 从最终ZIP解压入口另做Chrome 1100×560画面复核，目标、小地图、配装和操作栏可见，无页面错误或远程请求：`artifacts/feedback-v060/compact-1100x560.png`、`compact-layout.json`。这是窗口尺寸检查，不能代替真实浏览器缩放。

## 2. 进化存在于规则中，但选择和提升缺乏体感

**反馈与根因。** v1.3规定每次三选一、最多三个槽位，而不是整局只有三种提升。旧实现虽有四种协议，但优先塞入未装备协议，早期很难看到已有路线继续成长；后续主要在均衡、聚焦、延展之间侧向切换。草案文字和战斗反馈没有把“这次得到什么、现在怎样用、实际触发了几次”连在一起。

**本轮改动。** 四种协议、三槽和每次三选一继续作为构筑约束；每个协议新增 **Ⅰ→Ⅱ→Ⅲ** 的局内进阶。持有协议后的草案，只要还有未满阶路线，就保证至少一个已有协议的进阶候选，并在还有新路线时同时提供新协议。首份草案保证免疫灯塔与连锁净化两种可直接使用的路线，第三项由种子在其余路线中选择。达到Ⅲ阶后才提供明确标注的侧向校准，不将其称为额外升级。

| 路线 | 实际进阶收益（均衡校准示例） | 玩家能做出的新行动 |
|---|---|---|
| 共振裂解 | 追加伤害18→32→46，破绽4→5→6秒；装置有效距离随阶提升 | 接近器官节律装置，在冲流窗口命中并破壳 |
| 连锁净化 | 每跳伤害38→54→70，跳跃距离170→200→230；Ⅱ阶每3次、Ⅲ阶每2次命中存活目标向邻体折射 | 对耐久目标持续攻击也可产生折射；清除后的连锁仍保留，最多三跳且不递归 |
| 免疫灯塔 | 三体每轮总伤害24→36→48，持续6→8→10秒；召集范围随阶提升 | Q标记战区，让小队追击、接触吞噬；独立冷却与组织承压仍有取舍 |
| 异常显影 | 标记9→12→15秒，减速时长3→4.5→6秒，速度倍率0.7→0.6→0.5 | Q控制敌群并给免疫小队提供优先围猎目标 |

不同校准的实际参数由同一配置函数生成效果和文案，表中不是所有校准共用的固定数值。草案新增“本次提升”和“选完这样用”，装备后显示短时进化提示、角色周围的协议与阶数印记，HUD记录真实触发次数。获得灯塔或显影后，Q可立即再使用以体验新能力。结算显示本局最终阶数；等级、细胞、经验和配装不跨局继承，局外档案只保留发现、尝试和病例路线。

**可复查验证。** `tests/unit/growth-evolution.test.ts`覆盖三阶实际效果、连锁折射、基础与协议召集、以及300个seed×1/2/3项持有状态共900份草案的“进阶＋新路线”保证。最终浏览器三条迁移路线都通过合法经验/草案获取了进阶装备；`draft-*.png`展示前后变化，`route.json`保留每次候选、选择与终态。此前成长定向回归的旧失败与修正记录保留在 `artifacts/growth-rework-*.json`，不替换旧G4证据。

## 3. 攻击单调，免疫辅助像一个静态效果

**反馈与根因。** v1.3 §5.3的免疫灯塔写的是“召集临时免疫单位”。旧实现主要以固定灯塔定时发射射线完成伤害，缺少细胞接近、追击、接触攻击和撤离的过程；该协议还需要先抽到，玩家前段可能完全接触不到协同。基础工具2主要承担范围伤害，与精确净化的操作区别也不够突出。

**本轮改动。** 未装备灯塔时，Q也会召来 **1只短时、低伤的免疫侦巡细胞**，不占抗体槽、不收取组织承压。装备灯塔后，Q在鼠标标记点召集 **3只强化细胞**；它们是真实模拟实体，会移动、绕组织障碍、选取目标，并在接触范围内执行吞噬攻击。三只分摊协议每轮总伤害，不把原灯塔伤害无条件乘三。显影联动会优先围猎标记体；普通体与裂殖小体是主要清理对象，母巢仍需玩家执行反制。

细胞到期、换出灯塔、旅行切换器官或结束病例时，会按规则撤离；召集冷却不能通过往返器官重置。协议命中与基础侦巡日志分开，不用基础侦巡冒充协议触发。工具2新增对可移动存活敌人的击退，并打断被击退目标原有的攻击前摇；感染源和母巢不会被推走。配合连锁进阶的折射、显影减速和器官冲流，工具的用途从单纯换伤害数字扩展为聚敌、控制、清理与协同。

**可复查验证。** `immune-cells.test.ts`验证实体移动、接触限制、目标优先级、预算拒绝、同帧伤害边界和清理；`area-control.test.ts`验证范围击退与前摇取消。正式浏览器记录了无协议的实际侦巡命中，以及合法取得协议后的三体协同命中和进阶折射。`protocol_beacon_hit-live.json`、`protocol_ricochet_hit-live.json`保存截图前后状态，不能将这些前后相邻时刻说成严格同tick对照。

## 5. 交付范围与待补体验证据

本轮已经针对三条反馈实现可操作的变化，技术证据覆盖大地图、进阶规则、实体免疫协同、击退和完整胜利。它不能自动证明用户已经觉得更有趣、愿意复玩，或达到商业孵化价值。

- 标准五位新玩家盲测仍为 **0/5**；当前用户的一份真实反馈单独保留，不伪填为五人或盲测通过。继续使用 [试玩执行包](ViralInvasion_Playtest.md) 收集真实原话、首局计时、反制理解、两局策略差异和自发再开行为。
- 首玩约10–15分钟仍待真实数据；本轮没有用强制等待填充局长。
- 物理OS失焦/最小化、真实Ctrl缩放仍未验收；headless暂停、viewport、坐标往返和既有synthetic blur不能替代。
- 现有三只细胞围咬同一目标时可能重叠；“实体追击/接触吞噬已实现”不等于所有密集战况下三体都清楚分开。
- 本轮没有重做v0.5.0的10分钟设备性能测量，不将旧包帧率或内存结论迁移到新地图/新细胞版本。
