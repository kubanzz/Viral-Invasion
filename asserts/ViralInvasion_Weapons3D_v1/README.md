# 三维持握武器 v1

蜂巢针枪与回旋刃弓的独立轻量 GLB。沿用项目已有武器的象牙护壳、薄荷能量筒、多孔枪口及双刃／琥珀核心识别点；尺寸改为适合医疗巡护员的紧凑比例。

使用 Three.js 0.187.0 的标准几何、圆角挤出、曲线管体和 GLTFExporter 离线制作。网格为本项目新创作，没有下载其他武器模型或消耗在线生成积分。Three.js 软件许可为 MIT；本说明不改变项目原美术或角色身体的许可。

运行 `node scripts/build-held-weapons-3d.mjs` 可复现 GLB 和 `manifest.json`。材质使用标准粗糙表面与少量柔和发光，没有外部贴图。按材质合并网格，不需要独立骨骼播放器。

- 坐标：+Y 向上，+Z 为发射方向。尺寸单位与原角色 GLB 相同，角色绑定高度约1。
- `grip`：原点，持枪挂右手、持弓挂左手。运行时需按手骨局部轴校准挂点旋转，不能将任意手骨轴假定为 +Z。
- `muzzle`：发射／枪口表现节点。`offhandGrip` 为可选副手或拉弦参考。
- 弓的 `stringTop`、`stringBottom`、`stringCenter`：弦节点；弦位于握柄后方，拉弦方向为 -Z。GLB 不烘入弓弦，运行时可用标准线／管体连接当前拉弦手。

文件哈希、实际尺寸、三角形数、材质与节点坐标以 `manifest.json` 为准。枪、弓本体均为刚体；双手握持与拉弦姿态由角色动画及必要的现成 IK 适配。
