# 第11批：设施美术

本目录仅建立生产计划，尚无生成图片，manifest.assets 为空。每次生成一个对象或屏幕图层，下载、核对原文件后再记录；未生成的文件不得虚构入库。

统一1024×1024真实透明PNG，源落脚点(512,850)，pivotSource=[0.5,0.830078125]，完整安全留白。沿用奶油白／医疗蓝／薄荷青手绘材质。终端屏幕与基体、出口开关对必须保持同一画布、源尺度和位置，不逐图裁边、定高或重新居中。

| 计划ID | 内容与实际状态 |
| --- | --- |
| facility.research.base | 一台低研究台，三个试管与样本槽；对应graph research，样本是否足够及研究选择仍由实际游戏和UI表达。 |
| facility.terminal.base | 一台共用终端机壳与空白深青屏幕；对应实际terminal entity，不能又给graph retest画第二台。 |
| facility.terminal.screen.waiting | 原屏幕内部蓝色波形与琥珀指示点；对应真实等待条件，其余区域透明。 |
| facility.terminal.screen.ready | 同屏幕位置的薄荷波形与就绪点；不写通过文字，可复用启动诊断／完成复测用途，真实文字由程序区分。 |
| facility.exit.closed | 专用器官旅行拱门关闭态；对应graph exit未激活或迁移锁定，与隔离闸／气道阀不同。 |
| facility.exit.open | 同一拱门门片收入两侧，中间真实透明；通行冷却仍由真实状态绘制，不增加伪造冷却贴图。 |

生成顺序：研究台→终端基体→等待屏幕→就绪屏幕→出口关闭→出口开放。屏幕无文字／数字，单体无背景、地板、接地阴影、范围圈或UI。
