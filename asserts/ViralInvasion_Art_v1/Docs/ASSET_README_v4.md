## 强调：正式美术与占位资源的区别

**正式风格基准**：用户选定的白蓝手绘机器人 `medic_idle_selected.png`，心脏手绘场景优先参考 `archive_stage01-04/stage03/`。

**工程化候选 / 非最终绘本级定稿**：batch05 中的组织节点、感染源、瓣膜配对、肺泡、气道门和肺部底图使用可编辑 SVG 程序生成，长处是精确透明、配准、可动画；笔触和细节仍比手绘原图简洁。建议交 Codex 进行 G0–G1 集成验证后，再确定哪些需要手绘覆盖。

**动作占位**：`player/idle_frames` 与 `player/move_placeholders` 来源于同一张静态角色，只做微缩放/轻微摆动，**不是独立绘制的腿部交替行走或攻击动作**。

**历史病毒变体**：stage04 为从概念拼版提取的低像素原型，不应视为最终高清进化形态。
