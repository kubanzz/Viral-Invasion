# 病毒入侵 · 序章原画 v1

2026-11-08 使用 **OpenAI 内置 image_gen.imagegen** 分别生成四张正式背景原画。未调用外部 API 或 CLI；四张均为独立新图，未将多画面拼成一张素材。

## 素材

- `body`：半透明人体宏观全景，奶白薄荷轮廓、暖珊瑚心肺、血管网络，左侧深绿留白。
- `lung`：肺泡峡谷与支气管拱廊，中央下半部保留角色战斗空间。
- `heart`：暖珊瑚心肌纤维拱廊，中央下半部保留角色战斗空间。
- `vessel`：血管旅行通道，少量红细胞提供微观尺度参照，中央通道可容纳小队。

所有原画均为无文字、无界面、无固定角色、无感染覆盖的背景板。角色动作、病毒推进、感染扩散、镜头与字幕由游戏代码独立演出。

## 文件与来源

- `source/*.png` 保存内置工具返回的原始图片，尺寸 1672×941。
- `production/*.jpg` 为正常缩放与格式转换后的运行素材，尺寸 1600×900，JPEG 质量 85；四张总计 **791,702 字节**。
- `*.prompt.txt` 保存每张生成时使用的完整提示词。
- `manifest.json` 同时记录完整提示词、制作工具、派生方式、尺寸、字节数、SHA-256 和人体感染路径参考锚点。
- `build-production.mjs` 可用 `node asserts/ViralInvasion_Prologue_v1/build-production.mjs` 重建派生图片和清单。脚本只做比例缩放与 JPEG 编码，不重绘内容。
- `src/render/prologueAssets.ts` 静态导入四张正式 JPG；离线构建将其内嵌进包，运行时不依赖网络。

生成前观察了项目当前营地及免疫军截图，随后用文字描述既有奶白薄荷、柔和有机组织、生物幻想插画风格。没有使用截图作为编辑目标，也没有修改已有美术资产。

人体原画中心在画面右侧约 65%，喉、肺、心和腹部的归一化锚点见 `manifest.json`。使用覆盖铺图或镜头缩放时，覆盖动画应与原画应用同一变换。
