# v076 敌群身体分离：实现与针对验证

已修复真实移动逻辑。旧 AI 全部追向同一组织／玩家点，只与固定地形碰撞，到达同一攻击距离便停下，敌人之间没有占位。实际查看 v075 新 600 秒压力原图，并核对其 tick8872 状态：24 个活体中，13 个普通敌人压在两簇约 `(941.61,1203.29)`（8体）／`(941.35,1176.32)`（5体）；2 世界单位内近重合对38、身体圆相交对78，最小表面间距−44。这是真实位置重叠，文字避让不能解决。

设计依据是同一 XY 逻辑／碰撞平面、死亡无幽灵占位、真实尺度形态可分及 AC-M14-07 密集场景可读；没有从文档推导出减少敌人、隐藏实体或加 HP 的方案。具体原文入口见同名 JSON，DesignDoc 与旧证据未改。

本代理仅修改：

- `src/actors/enemyCrowd.ts`：确定性、单活体快照的软分离；完全同点使用 ID 反对称方向，不消耗 RNG。位移受特性／减速后的 tick 预算限制，走原墙碰撞，额外验证边界与最大位移；短切向只有减少重叠能量才采用。
- `src/game/battle.ts` 敌人移动段：同时应用分离；分离已经消耗移动预算的身体不立即追踪回原堆叠点。正常追踪若会挤入活体，采用稳定浅切向或排队。
- `tests/unit/enemy-crowd.test.ts`：重合、边界、顺序独立、固定前摇、伤害身份及归档状态针对验证。

所有已定义 `attackAt` 的身体在分离计划中固定，包括到期但尚未按原逻辑结算的攻击；source、core、迁移体只作为固定占位。死人不参与。未承诺攻击的单位分离后若仍在原 reach 内，可以正常发起前摇；新前摇一旦受理，身体／aim／at 固定，直到真实结算。旧堆叠若含已承诺前摇，会等它结束后在冷却窗继续展开。

原伤害7／4、前摇／冷却、攻击范围／reach、上限24、source／core／设施坐标均未调整。**接敌次序、队列及实际总压力会变化，属于玩法修复**；不能继承 v075 的胜率、1000局或性能／内存结论。
