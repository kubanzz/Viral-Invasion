## 收到文件后这样打开

1. 在 iPhone 安装 **HTML 查看器 - Sitecase**，要求 **iOS 17.6 或更新版本**。中国区链接：<https://apps.apple.com/cn/app/html-viewer-sitecase/id6762896369>。
2. 接收 `Viral-Invasion-Mobile.html`，保存到“文件”App。若收到 ZIP，先在“文件”中解压，再找到其中这个 HTML。
3. 在“文件”中长按 HTML，使用共享菜单导入 Sitecase；也可打开 Sitecase，选择“打开 HTML 文件”，再选中它。无需导入整个网站文件夹。
4. 将手机转为横屏。可在 Sitecase 的显示设置中选择“专注模式”，隐藏查看器工具栏；退出专注模式的方法以 App 当前提示为准。
5. 点击游戏开始按钮后游玩。游戏代码、界面和素材全部位于 HTML 内，接收文件并安装运行工具后，可关闭网络进行试玩。

手机依然需要一个能执行 JavaScript 的网页运行工具。系统“文件”或聊天 App 的快速预览不能等同完整运行环境；仅在它们的预览中看到页面，不代表游戏已经正常启动。

Sitecase 官方声明支持本地文件、CSS、JavaScript 和离线游戏。单个 HTML 可使用免费功能；整个项目文件夹的导入属于 Pro，本发行物不要求该功能。功能或可用地区以实际商店页面为准。官方介绍：<https://sitecase.io/>。

## 手机操作与布局

普通网页入口与单文件 HTML 均按浏览器可用尺寸实时切换：宽度不超过 1024px，或高度不超过 600px 时使用移动布局；在鼠标电脑上放大窗口后恢复桌面布局。真实粗指针触屏设备保留触控布局，也可用 `?mobile=1` 强制预览触控界面。布局切换会暂停战斗、清空已按住的输入，保留同一局进度；点击继续后重新按下控制键。竖向窄窗口仍遵循横屏战斗提示。

正常战斗视野已拉近，让小屏角色、病毒眼口与特化轮廓更容易辨认。远距技能预览时仍会拉远显示角色和真实落点，松手或取消后恢复正常视野；小地图继续提供远处敌群和设施位置。

- 当前使用 MOBA 轮盘布局：左下移动；右下约80px主攻击盘，能量炮、净化、驻防三个52px技能沿弧形分布；冲刺及上下文操作有效点击区至少48px，间距至少8px。手机不再使用“切工具后点施放”的控制条。
- 大攻击盘标为“射击”，按住持续开火，拖动调整方向；“净化组织”用于夺回节点，靠近受损心核时显示“修复心核”。
- 能量炮按下预览，拖动瞄准，松手释放，拖到 × 取消。驻防按下即在脚下部署，150内自动绑定最近健康节点，满两团则改派最近一团，保留现有生命、人数和攻击冷却，不再远程拖动驻防。挑战“净化/修复”是靠近后直接点按，不需要瞄准、不切主武器；旧训练与战役保留原操作。
- 在大器官中预览远处技能时，镜头会平滑移动并适度拉远，让角色和落点避开操作区；结束预览后恢复跟随。
- “开始挑战”的能量炮按下预览、拖动瞄准、松手发射，碰到敌人、弹囊或障碍立即范围爆炸，不需要导流确认。新星增加范围和伤害；净化余震会在主爆炸0.35秒后追加一次小范围爆炸。隐藏训练与战役保留原有牵引规则。
- 冲刺按钮点按立即位移；持续按住超过0.25秒开始蓄能，按下后1.25秒满蓄。拖动调整方向，松开发射3道剑气，满蓄5道；滑至 × 取消。剑气独立6秒冷却，取消不会退回已发生的冲刺。蓄能时移速70%、暂停工具开火。
- 左上小地图实时显示战场，点击可打开完整战况。生命与器官状态使用短条，技能以冷却环和数字反馈；新操作反馈最多显示 4 秒，详细目标与反制说明放在战况。验收包含标题栏压缩后的 280/320px 内容高度与刘海安全区。
- “净化/修复”在150范围内优先对附近可净化组织启动3秒净化，可继续移动射击；离开范围、侵染者干扰或直接受击会暂停并保留进度；直接受击暂停0.8秒，感染持续掉血不反复打断。前线需对应生命泉健康才能净化。没有净化目标时可修复附近受损心核，不会同时给玩家回血。靠近其他装置使用交互键。
- 暂停、查看详情、选择升级时会停止战斗输入。切到其他 App 或旋转方向后，按游戏提示继续，重新触摸摇杆。
- 战斗完整布局按横屏设计；竖屏可浏览菜单，进行战斗前需横屏。

开局没有弹射建筑。首次完整守住一条战线后，提示获得基础弹射荚蓝图；点“打开建造”或战术菜单，选择健康地面确认工地，至少两名军团成员实际到位后施工6秒。建筑110范围内且健康、装填就绪才出现弹射操作：按住拖动选落点，松手起飞，取消不消耗装填。基础荚1100射程、0.75秒飞行、240落地半径、260伤害、24秒装填；速装荚800／200／220／16秒。玩家留在落点继续战斗。空中不能地面操作、不会碰地面病毒，但已有感染继续扣血；不直接净化组织，不伤友方、主源或最终母巢。暂停冻结飞行与装填。

接防反馈依据实际到位和命中，依次显示驻军2/2、下一队反扑、军团拦截和清除护卫；失败会说明重试方法。心脏Boss有远程锁向冲刷和二相大范围脉冲，先看预警再侧移、冲刺或进入安全缺口。胜利奖励页列出实际武器品质、蓝图与生质；“回营修复战利品”可直达锻造。修复后可装备并进入安全试枪场，点按射击比较同线两只靶，试枪不消耗材料、不计分，也不改变战场。

感染时脚下紫暗影、掉血时紫色边缘提示；耐久30%及15%分别加强危险提醒，请前往健康生命泉。普通射击保留清晰枪口、弹体和命中反馈，低特效也可见。

## 离线与存档边界

游戏沿用本机存档，不能自动与电脑、Safari、另一个查看器或另一份导入文件同步。运行工具不允许持久化存储时，游戏会降级为会话暂存并提示。重命名、重新导入文件、删除查看器数据或卸载 App，都可能影响存档；更新前保留原文件和原条目，不承诺跨导入版本自动迁移，也不将长期存档作为本轮真机已验证结论。

## 当前挑战的胜负与区域争夺

守住健康生命泉 → 分别击退两线完整进攻，灯塔升至Ⅱ/Ⅲ阶 → 净化前线并部署军团，实际守住一轮反扑完成接防 → 解膜拆除双源 → 母巢决战 → 清理残敌和剩余感染，完成心脏救援。玩家或心核归零即失败，没有固定五波或八波通关要求。

心核与两处生命泉初始健康，两处前线与源区初始感染。侵染者沿路线占前线，普通病毒实际接触泉实体也会污染，每只每秒2.5个百分点、最多计3只，与专职10取大值。有预警的四人进攻队保持，前线失守后抢泉者会主动争夺生命泉。健康泉150内每秒治疗3耐久，连续1秒无新的传染接触或攻击才清感染；前线不治疗。身体触碰及病毒攻击均造成8秒感染，每秒扣1，刷新不叠层、不延迟下一跳。黏液法师的圈可躲，筑巢者和有六只库存的小巢可提前拆；耗尽小巢仍需清理，地图以巢标记提示。

免疫灯塔开局可用且不可替换。站到健康节点150内点驻防，新军团在脚下出现；满两团调最近一团真实行军，不恢复伤势。小队拦截侵染者但不能代替净化。源基础1200耐久，需要历史接防、泉和前线健康及存活驻军才解膜，失守或撤军复膜但保留已造成伤害。源毁取消该侧未出生进攻和孵化，已有敌人仍需处理。

母巢死亡不会自动清场或洗白区域，必要时继续最后净化。七区全健康、侵染进度为零时记录全域健康累计与最长连续时长，重新受侵染会暂停累计。救援胜利立即保存并暂停，可结束或继续守卫。继续守卫保留本局成长、耐久和军团，后续失守不会撤销救援成功。新版区域战绩与旧版无尽战绩分开；这里只保存成绩，不支持刷新后恢复战场。

## 病毒进化与战斗

“开始挑战”的前两波记录你的实际攻击：以弹丸为主会出现晶壳，以炮弹或斩击为主会出现裂殖；混合打法或有效观测不足时，本局确定一种变异。第3/4/5波分别混入6/8/8只普通特化体，第5波精英继承同一特性。其余普通体仍按原节奏供你清群，不会全部额外加血。

晶壳正面挡弹，用能量炮、剑气或侧绕突破；裂殖死亡后出现2只脆弱小体，用炮弹或剑气收尾。第3波顶部显示进化与反制；救援期间保留已见特性，母巢继承其中一种。公告不暂停、不遮挡操控区；详情可查看前两波实际伤害比例。

双源击破会取消当前波尚未出生的队列；活体与预约裂殖仍计入清波义务。所有敌方活体和预约人口共用48上限，感染源与母巢不阻挡普通清波。每波选择强化，每五波仍有突破与额外协议。

本轮浏览器、离线构建与帧表现记录见 `artifacts/opening-evolution-20261102/`，以实际报告为准；真实手机自然完成和真人手感尚待实测。新玩家试玩请另记录能否说出病毒进化了什么、至少一种反制。

## 从工作区重新打包

```sh
npm run package:mobile
```

该命令先校验并构建当前源码，再生成 `releases/Viral-Invasion-Mobile.html` 与 `releases/Viral-Invasion-Mobile.zip`。ZIP 只包含同一份 HTML 和本说明。校验记录位于 `artifacts/mobile-release/package-report.json`；构建来源清单保留在本机，不放入手机包。

已完成当前构建时，可单独运行 `node scripts/package-mobile.mjs`。源码、打包脚本、本文档或构建输出在构建后发生变化，会拒绝打包，需先重新构建。`dist/index.html` 继续保留桌面网页入口。

运行手机浏览器回归：`npm run test:e2e:mobile`。首次运行 WebKit 项目时，先使用 `npx playwright install webkit` 将对应浏览器安装到 `.tools/playwright-browsers`（设置 `PLAYWRIGHT_BROWSERS_PATH` 后执行）；测试配置默认读取这个项目内缓存。当前轮盘结果位于 `artifacts/mobile-moba-20261101/`，旧布局与首次适配证据分别保留在 `artifacts/mobile-redesign-20261101/`、`artifacts/mobile-20261031/`。Chromium 的多指检查通过 CDP 注入真实触点；桌面 WebKit 的单指轮盘以鼠标路径验证，多指硬件行为留给真机验收。旧版III导流的隔离浏览器机制用例不等同于自然晋级过程或最终手机包的真机记录。
