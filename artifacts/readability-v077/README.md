# v0.7.7 continuous evolution candidate

This candidate follows v0.7.6 at `8364bf1`. The latest goal prioritizes repeatable combat, continuous hero/virus growth and satisfying attacks. Original designs, older evidence, and supplied `asserts/` assets remain unchanged.

The main addition is an independently replayable continuous challenge using the existing large heart world, fixed simulation, collision and accepted-damage path. Each real wave clear offers one of three upgrades from nine families; waves rotate enemy cohorts and periodic elites. The finite heart/lung campaign remains available.

Tests distinguish unit fixtures from natural public-input simulation and real offline browser keyboard/mouse play. Requested effects are not counted as successful hits; immune evidence joins accepted positive target HP loss. Prior full-system seed and long browser performance results apply only to the old candidate.

The conditional player contour is a small accompanying readability aid. Normal bodies remain Y sorted; conservative geometry indicates potential overlap and does not measure pixel readability. No art assets are introduced.

Human blind playtesting remains deferred by user instruction. Automated completion demonstrates mechanics and stability, not fun, retention or incubation value.
