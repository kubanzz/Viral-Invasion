普通病毒经过不染地；带标记的侵染者需要10秒占领生命泉。3号技能在150范围启动3秒净化，期间可移动射击，离开范围或侵染者干扰会暂停进度。

开局免疫灯塔立即可用；Q瞄准健康节点驻防、指敌或空地指挥，最多两支有生命的小队。军团必须实际绕障和接触咬击，不能替玩家净化；改令保留生命与攻击冷却。
双源各238基础耐久，击破后永久净化该区并停止该侧新侵染编组，已有敌人保留。两源都毁后取消本波未出生队列；清完剩余义务并领取强化，进入680基础耐久母巢战。
前两波实际攻击决定第3波晶壳或裂殖，母巢继承已见的一种特性。晶壳可用炮弹、剑气或绕后突破；裂殖死亡后用范围攻击清理小体。敌方活体及预约人口合计不超过48。
每波三选一强化，每五波突破并补充协议。清波不自动回血或修复心核，生命扩容只补新增上限；3号抢修心核不顺带治疗玩家。
救援胜利立即保存并暂停。可结束救援或保留成长、耐久和军团继续守卫，后续失守或返回菜单均保留救援成功、更新同条记录，整局只计一次。
