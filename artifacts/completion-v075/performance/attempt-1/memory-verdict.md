# v075 十分钟内存观察结论

建议根代理采用有限结论：**冻结 v075 在记录的 Windows/i7-10700K、Chrome 155 headless、1366×768、驻心脏双生产源场景中完成 600.05 active 秒；未观察到持续失控的 V8／DOM 保留。实际正增量必须并列保留，不能写成零增长。**

本次只做离线派生和独立复核，没有启动浏览器、执行 GC／模拟／测试或改生产源码。`report.json` SHA256 为 `a0e1650f4071f0653b56ae37c89c33d0a813cda50a766be05131b610ddca5437`，bundle 为 `971313934fc806144ceb3c2dc89eda76ce142ea1aac2bdee54ff0a52003ce342`；执行 exit0、浏览器关闭成功、游戏与 host 未变。完整分位数见同目录 `memory-review.json`，本结论指纹见同名 JSON。

600.05 秒不含 149.442 秒准备／warmup，118 个 natural 样本全都没有显式 GC。标准／低档各约 300 秒、平均约 59.998 FPS、帧时间 p95 均 16.8ms，无致命错误、远程请求或帧观察丢弃。正式测量真实接受灯塔咬击为 **884**；926 是观测到的请求日志数，不是实际伤害计数。

## 为什么支持有限观察

首末 60 秒 used 中位 **15,959,564→19,198,040 B（+20.29%）**，这项增长真实存在。十个完整分钟的 used 中位约为 15.96、14.87、20.65、17.03、14.93、22.80、18.80、14.40、20.02、19.55 MB，低位约为 8.40、8.02、7.42、7.03、6.37、9.76、8.92、7.59、7.30、8.89 MB；均非持续向上，期间有 **59 次 used 采样下降**。这是采样回落，未冒充某个已仪器确认的 GC 事件。

V8 capacity 首末 67,440,640→74,326,016 B，首末一分钟容量中位只增加 3.77%；容量与活对象占用分别解释。正式采样结束后，真实暂停并三次 GC，used 从当时自然占用 29,823,768 B 降至 **6,068,800 B**，capacity 降至 8,003,584 B。这个较晚检查证明大量占用能够释放，并不等于有同一 tick 的开始／结束强制 GC 基线。

自然 DOM 始终只有一个 document；节点范围 326–1,026，首末 774→536；监听器首末均 38。事件始终 512，效果采样 3–13，含短时尸体的 target 数组采样 23–26，runMetrics 临时帧最多观测 2／256、摘要没有 limited。新 SceneLabels 的 256／128 缓存硬界来自源码复核，**该压力 driver 没有采样这些诊断，不将其写成已观测的逐帧计数**。

## 菜单重开的保留正增量

这部分在正式帧／natural 测量完成后，使用真实暂停／菜单／start／Q 操作、1.1 秒等待和各三次显式 GC；不能混为自然 GC 吞吐。

| 匹配菜单检查 | collected used B | capacity B | 节点 | 监听器 |
|---|---:|---:|---:|---:|
| 返回菜单 | 5,371,248 | 6,168,576 | 451 | 37 |
| 重开 5 次后 | 5,385,896 | 6,430,720 | 422 | 37 |
| 重开 10 次后 | 5,554,956 | 6,430,720 | 451 | 37 |

0→5 增 **14,648 B（0.27%）**，5→10 增 **169,060 B（3.14%）**，总增 **183,708 B（3.42%）**。collected used 两段都上升，不能称完全平坦。节点回到 451、监听器保持 37，embedder 在后半段下降，backing 后半段不变；结合预检中有界缓存、单例监听与容器 WeakMap，没有找到逐轮积累旧 HUD 树／监听器或整局副本的证据。

**剩余精确疑点是这 183,708 B 尚未获得 heap dominator／保留路径归因。** 不能擅自叫它 JIT、某个缓存或泄漏。它限制“重开零保留／无限稳定”的说法，不需要据此否定已经完成的有限 active 十分钟观察，也不必再扩大为无限期压力门槛。

## 可以直接引用的范围

> 当前版本已完成记录设备上的 600.05 active 秒驻心脏自然压力及独立终后 GC／菜单重开检查。未观察持续失控 V8／DOM 保留；首末一分钟 used 中位增加 20.29%，十次菜单重开 collected used 增加 183,708 B（3.42%），节点回到 451、监听器保持 37。该结论限定此场景，不声称零增长。

`AC-M16-04` 的原文是有限十分钟目标，本证据可支持上述技术范围；完整行中的原生／实际目标设备呈现、其他路径或总进程内存应按各自证据标记，不能因无法证明无限稳定而抹掉有限运行结果。

本次肺始终未激活、旅行 0、后台损伤 0；后台／旅行幂等账本增长没有被本场景覆盖，根代理的迁移采集应单独引用。压力结束仍 playing，后续十次是**未完成局的菜单重开，不是真实结算**；永久 profile ID 每次真实结算增加一项的契约另行说明。V8／DOM 读数也不是总进程 RSS、原生 Canvas 或 GPU，更不替代真人趣味性验收。
