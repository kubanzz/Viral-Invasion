# Viral Invasion · 病毒入侵

在巨人体内作战的生物幻想动作小游戏。当前 **v0.8.1 / G4 技术候选**，在既有战役与连续进化玩法上加入手绘资产、Phaser 表现和持续美术同步，并修复图标、遮挡及重复武器表现。

## 立即游玩

下载并完整解压 [v0.8.1离线包](releases/Viral-Invasion-G4-v0.8.1.zip)，双击 `Open-Game.cmd`。工作区双击 `Start-Game.cmd` 会先同步素材、校验构建并按需重建；也可用 Chrome / Edge 打开 `dist/index.html`。无需网络、账号或服务器。

本版使用明亮的珊瑚色心脏、薄荷色肺部与白蓝医疗机器人。开发启动与构建前从本工作区的 `asserts/` 生成图集，不读取旧机器路径或以环境变量覆盖工作区素材；已绑定文件更新会进入构建，新编号或新类别列入候选等待选材。运行中的开发服务更新素材后须手动执行 `npm run art:sync` 再刷新，或重启开发服务。选材、完整逐帧动画和游戏内验收是独立步骤；关键姿态不视为连续动画。当前流程和素材缺口见 [素材更新说明](Docs/ViralInvasion_Asset_Workflow.md)，历史接入和验证见 [v0.8.1 美术说明](Docs/ViralInvasion_v0.8.1_Art.md)。

- **更大的战场**：2400×1500心脏与肺部，实际可行动地面约旧版4.23倍。设施分区、跟随镜头、小地图和器官往返支持路线选择。
- **可以继续进阶的构筑**：四种协议、三槽、每次三候选；协议升至Ⅰ/Ⅱ/Ⅲ阶，卡片显示前后数值与新用法，后续还有定向研究与下局Ⅰ阶预装。每次选择期间暂停。
- **可见的免疫协同**：Q空装召一只侦巡；装备免疫灯塔后召三只细胞，移动、绕障、接触咬击。搭配异常显影优先围猎标记体；共振裂解搭配连锁净化增加一跳。Ⅱ/Ⅲ阶连锁还会在持续命中时折射。

本版增加敌群身体间距和侧向让路，减少同点堆叠；已开始攻击前摇的身体与落点保持不动。裂殖爆发与孵化倒数优先放在真实危险圈外，拥挤时先找附近空位。组织、设施、小队与破绽沿用统一文字避让，进化记录只呈现实际命中和真实HP损失。详细设计及证据见 [v0.7.6验收](Docs/ViralInvasion_v0.7.6_Acceptance.md)、[最初三点反馈改造](Docs/ViralInvasion_PlaytestFeedback_v0.6.0.md)。

## 建议这样体验

1. Q诊断后，用1清除感染源，停止增援；用3对医疗十字抢修。
2. 首次草案选择**免疫灯塔**，鼠标指向活敌再按Q。停火片刻，能更容易看清小队移动和咬击。进一步选择异常显影观察优先围猎。
3. 已有协议继续升级可达Ⅲ阶。也可尝试共振裂解＋连锁净化，靠近装置利用冲流、破绽和连锁清群。不要把三个槽位理解为整局只有三种提升。
4. 看清变异预警：晶壳绕后或E冲流破壳，裂殖小体用2清群，潜伏体Q显形。2还能击退可移动敌人、打断前摇。
5. 第二次变异后选择追击或封锁。肺部气道E可截流；处理组织危机支点、清源及两次精英，再到复测终端唤醒双特性母巢。
6. 母巢净化、所有激活器官完整度≥50%、感染<35%后，主动E复测获胜。结算可查看治疗质量、系统掌控、双方进化和真实行动；档案保留发现与最近10局，临时经验/阶数重新开始。

| 按键 | 操作 |
|---|---|
| WASD | 八向移动 |
| 鼠标 / 左键 | 瞄准 / 当前工具，可按住 |
| Space | 冲刺，1.5秒冷却 |
| 1 / 2 / 3 | 精确净化 / 范围裂解 / 组织修复 |
| Q | 扫描与免疫召集 |
| E | 附近装置、研究、器官出口及复测 |
| Esc | 暂停 / 继续 |

细胞需要实际接近敌人，不穿组织障碍，不能直接攻击核膜保护的母巢。心脏冲流消耗4完整度、冷却8秒；肺部关闭气道消耗3，开启消耗1。感染100后有15秒恢复机会；低完整度会影响全身稳定，恢复至50%才缓慢回升。操作手册和战术记录可在游戏内回看，支持关闭声音和低特效。

**2026-10-28 实施更新：已接入 Phaser 4.2.1 WebGL、真实 PNG 图集和原生精灵。** 现有玩法模拟、碰撞规则和 DOM HUD 保留；危险几何、部分状态特效与缺图单位通过 Canvas 兼容层呈现，尚未全部改写为原生精灵。2026-10-27 规划与历史验收按原版本保留，本轮结果以 v0.8.1 美术说明和构建清单为准。

制作与交付要求见[美术规范 §7](Docs/ViralInvasion_ArtDirection_VisualAcceptance_v1.3.md#7-资产制作与-phaser--krita-管线)，迁移步骤与验收门槛见[实施计划](Docs/ViralInvasion_ImplementationPlan.md)。原始设计与现行设计中的相关技术要求同步修订，既有证据保留原版本归属。

## 从源码运行

需要 Node.js 22.12+ 或24+与npm。浏览器发行没有运行时依赖。

```sh
npm ci
npm run dev
npm test
npm run build
npm run test:e2e
```

`src/`为TypeScript/Phaser与Canvas兼容层实现，`tests/`包含规则和真实浏览器回归，`scripts/`为构建/采集工具，`Docs/`记录实施与验收。`DesignDoc_v1.3/`与`Docs/`已同步纳入2026-10-27美术管线修订，历史实现和验收记录按原版本保留。`dist/`和`releases/`不进入Git；干净检出须构建。构建输出经典IIFE脚本与内联CSS，file入口不依赖CDN。

加 `?seed=12345`可指定病例，`&trait=CARAPACE/FISSION/MIMIC`可显式指定首分支用于回归；仍需正常战斗与完整预警。训练及G1/G2 fixture是小图机制场景。`window.__viral`仅提供只读快照/投影，存档键为`viral-invasion:1:profile`，不可写时降级会话暂存并提示。

## 验证与待观察

v0.8.1 的当前构建与逐项证据集中在 [美术接入说明](Docs/ViralInvasion_v0.8.1_Art.md) 和 [验证索引](artifacts/art-v081/verification-summary.json)。最终非千会话单元回归 79 文件、635 项一次通过，Chrome/Edge、两档分辨率和两种 DPR 共 8 组画面检查通过；另有当前 Renderer 的定向遮挡、危险提示及实际 alpha 剪影检查。双浏览器原生最小化 30 秒、恢复、真实设置缩放下的有限草案选择与训练命中通过；范围及未覆盖项随报告明确登记。

本机 Chrome 离线压力采集 600.283 有效秒，标准/低特效均约 60 FPS、p95 16.8ms；两档均捕获 24 活敌与 3 只细胞同屏。当前完整器官路线、双浏览器自然五波，以及独立解压 ZIP 的两种模式断网检查通过。自然内存与后置强制 GC 分开登记，不推断所有设备或长期无泄漏。发行 ZIP 约 5.25MB；旧包保留。

历史 v0.8.0 整合包 613 项单元测试、Chrome/Edge 美术与自然五波检查通过；该版本机离线压力采集 600.233 有效秒，标准/低特效均约 60 FPS、p95 16.8 ms。独立解压 ZIP 后的两种模式也通过双浏览器断网检查。构建身份、内存观察边界和逐项报告见 [v0.8.0 验证索引](artifacts/art-v080/verification-summary.json)。这些成绩保留原构建归属。

v0.7.6 规则、绘制与UI两批合计55文件446项通过，包含1000个正式campaign-1会话的单独测试；测试策略均实际获胜，两种重放指纹一致。Chrome/Edge针对性浏览器17项通过，另5项按病例分配预定跳过，覆盖三窗口HUD、实际成长/咬击/协同通关与重试。该版压力、正式混战及离线包的原始结果记录在 [v0.7.6验证汇总](artifacts/readability-v076/verification-summary.json)，不把功能测试当作性能或真人试玩。

历史v0.7.5的同seed迁移对照、600.05有效秒压力及自然内存／后置GC分别保留在 [v0.7.5完成补充](Docs/ViralInvasion_v0.7.5_Completion_Addendum.md)。这些仍归旧规则版本；本轮因真实移动变化，另执行当前源码的正式会话、浏览器与压力验证。

分支dev-zbj，本机无Git远端。当前构建的实际来源清单随包提供于`build-meta.json`。历史[v0.7.4验收](Docs/ViralInvasion_v0.7.4_Acceptance.md)及其正式会话／浏览器／压力记录保留原版本归属，当前改动另列证据。
