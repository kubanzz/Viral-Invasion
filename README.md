# Viral Invasion · 病毒入侵

在巨人体内作战的生物幻想动作小游戏。当前为 **v0.7.1 / G4 试玩优化候选**：2400×1500心肺战场、Ⅰ–Ⅲ阶抗体进化、实体免疫细胞、跨器官抉择与双特性母巢。研究台新增诊断驱动的方向选择，让样本用于主动组织反制构筑；首次晶壳反制与有限组织冲击支点继续保留。根据玩家关于空间拥挤、成长无感和攻击单调的反馈持续改造，趣味与首玩节奏仍需复玩检验。

## 立即游玩

双击 `Start-Game.cmd`，或用 Chrome / Edge 直接打开 `dist/index.html`。发行文件完全本地运行，不需要服务器、账号或网络。交付目录中的 `dist/` 为构建产物，不进入 Git；从源码检出后先构建。

离线候选发行：[Viral-Invasion-G4-v0.7.1.zip](releases/Viral-Invasion-G4-v0.7.1.zip)。完整解压后双击其中的 `Open-Game.cmd`。改动和验证见 [v0.7.1验收](Docs/ViralInvasion_v0.7.1_Acceptance.md)，原始证据入口为 [本轮验证汇总](artifacts/research-v071/verification-summary.json)。历史版本：[v0.7.0首次反制与阶段遭遇](Docs/ViralInvasion_v0.7.0_Acceptance.md)、[v0.6.4遮挡修复](Docs/ViralInvasion_v0.6.4_Acceptance.md)、[v0.6.3稳定性](Docs/ViralInvasion_v0.6.3_Acceptance.md)、[v0.6.2围击与协攻](Docs/ViralInvasion_v0.6.2_Acceptance.md)、[v0.6.1详情与音效](Docs/ViralInvasion_v0.6.1_Acceptance.md)、[v0.6.0试玩反馈处理](Docs/ViralInvasion_PlaytestFeedback_v0.6.0.md)、[v0.5.1记录](Docs/ViralInvasion_G4_v0.5.1.md)、[v0.5.0验收](Docs/ViralInvasion_G4_Acceptance.md)。发行文件保留于本机，不进入 Git。

本轮可直接体验：开局按 **Q** 召一只短时免疫侦巡；首份进化草案选择**免疫灯塔**后，把鼠标指向附近敌群再按Q，会出现三只协同细胞。搭配**异常显影**，可观察优先围猎标记体及真实咬击提示；停火片刻更容易看清接敌过程，追逐或狭窄地形仍可能部分重叠。将**连锁净化升至Ⅱ阶**，精确净化每三次基础命中可折射邻体，Ⅲ阶缩短至两次。按 **2** 可击退可移动敌人、打断前摇。右下小地图显示设施、目标距离与镜头范围，设施已经分散到不同区域。正式地图可行动地面约为旧版 **4.23倍**；训练与阶段夹具保留小图。

点击成长面板或暂停菜单中的**当前配装详情**，查看每个协议的实际阶数、校准、触发次数、效果、代价和用法。面板支持Tab与方向键，阅读时暂停；Esc返回之前的战场、暂停、手册或战术记录页面。

1. 按 WASD 移动，鼠标瞄准，左键使用当前工具。先用 **Q** 诊断，用 **1 精确净化**处理感染源，停止增援。首次晶壳有完整预警、阀门指向和两条反制提示，实际命中弱点才记录掌握；可随时从提示或手册跳过。
2. 看清变异的能力、代价和弱点。晶壳可绕后或用冲流破壳；裂殖小体用 **2 范围裂解**；潜伏体可 Q 显形并直接射击。
3. 根据小地图找到节律阀门，瞄准后按 **E** 发动定向冲流。冲流消耗 4 点组织完整度，冷却 8 秒。隔离闸可按 E 截断传播。
4. 用 **3 组织修复**点击医疗十字组织。近距离修复有效受损组织还能少量恢复战士耐久；不会因对满血组织重复操作刷取收益。
5. 清除感染源、击败精英和首次诊断可收集经验与样本。升级三选一；靠近**抗体研究台**按 E，先选通用或本局已诊断的方向，确认才消耗3样本，确认前可免费取消。晶壳／裂殖方向保证共振与连锁候选，潜伏方向保证显影与灯塔候选；可自由选任意一项，生成后放弃不退样本。四种协议、三个槽位，已有协议可升至Ⅱ/Ⅲ阶，满阶后才侧向校准。后续草案混合进阶与新路线，卡片显示前后数值与用法，HUD显示阶数与实际触发次数。三槽满后可替换或放弃草案；所有选择期间战场暂停。
6. 共振裂解与连锁净化搭配，破绽目标清除可多一跳（最多三跳）；异常显影与免疫灯塔搭配，细胞优先追踪 Q 标记体和裂殖小体。细胞需要实际靠近敌人才能咬击，不能穿过组织障碍，也不能直接攻击受核膜保护的母巢。细胞随寿命结束或器官旅行撤离。
7. 第二次变异后，12 秒内选择：根据小地图到出口 E **追击**，或到隔离闸 E 留守两秒**封锁**。放任会让肺部新增感染源，仍可救援；提前关闸会自动封锁，并在心脏留下新源。
8. 肺部吸气聚拢、呼气分散。气道 E 会切断传播和气流，关闭消耗 3 点完整度，开启消耗 1 点；玩家出口可双向返回。器官图显示另一器官的状态与离场风险。
9. 迁移后处理新出现的**组织危机支点**：它每8秒冲击6点完整度、最多三次。可直接拆源，也可用心脏 E 冲流打断或肺部关闭气道暂停蓄能，争取抢修窗口；净化支点后进入核心阶段。清除主要感染源和两次精英，到母巢所在器官的**复测终端**按 E 唤醒核心。母巢带有本局两种特性；躲开攻击或 Q 打断侵蚀，逐层打开核膜，再将其净化。
10. 母巢清除、所有激活器官完整度 ≥50%、感染 <35% 后，主动 E 复测获胜。菜单与结算中的**局外档案**可查看发现、成就、最近 10 局及同种子重试。每局的耐久、损伤、经验和装备都会重新开始。

| 按键 | 操作 |
|---|---|
| WASD | 八向移动，斜向速度归一 |
| 鼠标 / 左键 | 360° 瞄准 / 使用工具，可按住连续施放 |
| Space | 冲刺，1.5 秒冷却 |
| Q | 扫描并召唤短时免疫侦巡；装备灯塔后召三只协同细胞，扫描3秒冷却 |
| 1 / 2 / 3 | 精确净化 / 范围裂解 / 组织修复 |

| Esc | 暂停 / 继续 |

感染体会移动并在攻击前显示危险轮廓；冲刺可以避开攻击。组织隆起有真实碰撞，需要绕行；遮住后方身体时上半部会淡化，底座和接地轮廓保留；装饰前景可以穿行，挡住玩家时会淡化。感染到 100 后有 15 秒恢复窗口，净化或有效修复可解除危机；器官危机会先警报再影响全身稳定。暂停、失焦和重开清除持续输入，暂停冻结传播与危机。游戏内可查看作战手册和战术记录、关闭声音或切换低特效。

## 从源码运行

需要 Node.js **22.12+ 或 24+** 与 npm。依赖仅用于开发，浏览器发行包无运行时依赖。

```sh
npm ci
npm run dev       # http://127.0.0.1:5173
npm test          # 核心规则、边界、存档及1000种子完整系统仿真
npm run build     # TypeScript检查 + classic/IIFE离线包
npm run test:e2e  # 安装了系统Chrome与Edge时，运行真实浏览器回归
```

浏览器测试使用本机 Chrome / Edge，缺少对应浏览器会明确失败。可用 `npm run test:e2e -- --project=chrome` 单独运行；不可把单浏览器结果当作双浏览器通过。

当前机器的 Codex 运行环境提供 Node、未提供全局 npm。本次在忽略目录 `.tools/` 内临时引导 npm，并将 `.tools/node_modules/.bin` 加入当前命令的 PATH；没有修改系统 PATH。普通安装了 Node/npm 的电脑不需要这个引导目录。

## 工程结构

```text
src/core/          固定步长、seed RNG、有类型事件总线
src/game/          共享会话、战斗导演、集中参数、确定性规则
src/actors/        二维碰撞与射线检测
src/input/         实际键鼠输入与统一键位帮助
src/render/        可逆投影、稳定Y排序、前景淡化、原创Canvas插画
src/ui/            战斗HUD、预警、手册、战术回看
src/meta/          版本化局外档案、结果去重与会话回退
src/main.ts        菜单、HUD、暂停、结算与宿主循环
tests/unit/        确定性和规则测试
tests/e2e/         真实键鼠输入的离线发行包回归
scripts/           离线构建、发行验证、性能与证据采集
DesignDoc_v1.3/    原始设计文件，完整保留
Docs/              设计副本、实施计划、验收证据与真人试玩记录
artifacts/         本次实际测试报告、截图与录屏
dist/              index.html + game.js，无ES模块、CDN或远程资源
```

开发入口使用 Vite ES 模块；正式构建会替换入口为经典脚本，并将 CSS 内联。模拟固定 60Hz，世界 XY 与显示高度分离；跟随镜头的平移、缩放与屏幕 Y 压缩0.72共用正逆变换接收鼠标。DPR 仅影响 Canvas 像素密度。

在浏览器地址添加 `?seed=12345` 可指定病例；`&trait=CARAPACE`、`FISSION` 或 `MIMIC` 可覆盖首个分支用于回归，仍需经历完整预警和正常战斗。首次未完成／跳过的局默认固定晶壳引导；确认后新病例按近90秒有效行动产生温和进化偏置，单候选概率上限55%，每局最多两种主特性。相同病例重试保留该局变体；档案和最佳记录保存配置及显式覆盖，旧无配置记录会标为按当前规则再访。`?scenario=training` 与 `?fixture=G1/G2` 是快速机制夹具，正式战役采用 campaign-1 配置。`window.__viral` 仅提供只读快照、坐标转换和图层诊断。局外存档键为 `viral-invasion:1:profile`；不可写时明确提示会话暂存，损坏或旧档不会阻止游玩。

## 验收边界

G0–G3 功能与 G4 存档、档案和首次迁移指引已实现。真实浏览器、离线发行包与设备性能的最终证据见测试矩阵；原始设计文件完整保存在 `DesignDoc_v1.3/`。

v0.7.1：318项非批次单元通过，另有1000个完整正式模拟会话全部通过。最终包19项浏览器检查首轮通过：2项定向研究胜局、10个不同种子胜局、5次实际耐久0失败与重试、2个存储故障循环；17项浏览器分配跳过不计通过。这1000局不调用研究API，研究事务由专项机制、正式会话及浏览器证明；不是全部历史E2E重跑。

本版补齐诊断→定向研究→选择/进阶，及危机出现／装置中断／实际清除的持久战术回看；大地图、实体小队和组织遮挡淡化继续保留。最终研究浏览器检查包括免费取消、双击唯一扣3样本、主协议与伙伴候选、1100×560与800×600布局及干净重试。预去重包的研究胜局和中止资格批次单独保存，不计入最终包19项；预去重后只有main界面去重变化，29项模拟源逐字节一致。

本包Chrome155 headless独占600.183有效游戏秒，标准／低效各约300秒，均约60FPS／p95 16.8ms；两模式均有24活体＋3细胞实图，实际密度有波动。117条自然内存样本与终后GC／10重开分列，V8容量扩张和差值如实保留，不宣称完整内存稳定。首次画质切换断言抢读失败单独保留，修正驱动等待后完整重跑通过。ZIP五文件解压一致、双浏览器断网冒烟通过。详情见[v0.7.1验收](Docs/ViralInvasion_v0.7.1_Acceptance.md)。

[首次反制与阶段遭遇](Docs/ViralInvasion_EncounterDirector_Plan.md)的本轮技术实现已交付。1000熟练模拟平均54.07秒，只证明合法快速路线，不代表真人首局；标准五人盲测仍0/5，首玩10–15分钟、反制理解、复玩意愿及商业价值仍待真人观察。物理OS失焦／最小化与真实Ctrl缩放也仍待验收。
